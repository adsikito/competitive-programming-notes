# 流程控制

## 一、为什么需要它

先体验一次没有流程控制的编程：题目要求输出 1 到 100 的每个整数。没有循环，你只能写 100 行 `cout << 1 << endl; cout << 2 << endl; ...`——写完手就废了，而且改成"输出 1 到 10000"时整个程序推倒重写。再看第二个场景：猜数字游戏里程序要根据"猜大了 / 猜小了 / 猜对"三种情况做不同反应，没有分支，程序只会一条路走到黑。**碰壁的根源：顺序结构只会"从上到下逐行执行"，没有判定、没有重复。**

流程控制补上这两块：分支控制让程序"有选择地执行"（选择结构.pdf p4），循环控制让程序"重复执行直到条件不满足"（循环结构.pdf p4）。本篇讲 4 个知识点：分支结构与边界意识、循环三件套与 break/continue、嵌套循环与暴力枚举骨架、随机数与猜数字实战。顺序理由：先立单次判定（知识点 1），再立重复结构（知识点 2），两者组合出枚举骨架（知识点 3，直接通往 [[枚举与模拟]]），最后综合实战（知识点 4）。

## 二、知识点逐讲（每个知识点一节，共 4 节）

### 1. 分支结构与边界意识：if 家族与 switch

前置依赖：运算符与表达式（同批）、数据类型与内存表示（同批）
后续衔接：本篇 ### 2. 循环三件套与 break、continue（循环体里的条件判定）、本篇 ### 4. 随机数与猜数字实战

**① 它解决什么问题**

分支控制回答"程序走到岔路口该走哪条路"。选择结构.pdf p4 定义：分支控制就是让程序有选择地执行，主要三种形式——单分支（if）、双分支（if-else）、多分支（if-else if-else）。另有两个变体：switch-case 处理"整型变量等于哪个常量"的离散选择（p17-18），三目运算符 `?：` 处理"二选一取值"（p14）。单次判定的时间代价是 $O(1)$——分支不产生计算量，只决定哪些代码被执行。

**② 直觉理解**

模型级类比：**岔路口的路标**。程序是一条流水线，if 是路口的检查员：条件为真放行进支路，为假跳过；else if 是排队的一串检查员，**从上往下逐个问，问到一个为真就放行并且不再问后面的人**；else 是兜底通道，前面全不匹配才走它。这个"逐个问、命中即停"的顺序性是多分支的核心机制，也是边界意识的第一课——条件的排列顺序本身就是逻辑的一部分。

小数据推演（选择结构.pdf p10 的例子）：num3 = 0。问 `num3 > 0`？0 > 0 为假，跳过；问 `num3 < 0`？0 < 0 为假，跳过；走 else，输出"num3 等于 0"。三个条件恰好把整数轴切成三段互不重叠的区间——写多分支时主动检查"区间是否互斥且并集覆盖全定义域"，这就是边界意识。

**③ 原理与推导**

三分支的严格语义：`if (c1) A; else if (c2) B; else C;` 等价于嵌套 `if (c1) A; else { if (c2) B; else C; }`（选择结构.pdf p13 给出嵌套语法）——**else 总是与它上面最近的未配对 if 结合**。这个结合规则回答了一个设计动机类问题：为什么教材强烈要求 if/else 体一律加大括号？因为省略大括号时"else 配对歧义 + 缩进误导"是经典事故源：缩进让你以为 else 配第一个 if，编译器却按最近原则配第二个 if，代码的行为与读代码人的直觉分道扬镳。

switch 的语义（p18 规则）：expression 必须是整型或枚举型；case 常量必须与它同类型；**命中一个 case 后一路往下执行直到 break**——不带 break 就是"继续执行后续 case"。为什么不把 switch 设计成自动各 case 隔离？历史原因是它编译后就是一张跳转表，"贯穿"让相邻 case 共享一段代码成为可能（如多个 case 共用同一处理），代价是忘记 break 时的静默贯穿。三目 `c = (a > b) ? a - b : b - a;`（p16）与 if-else 等价，优势是"表达式有值"，可直接赋值。

**④ 代码演示**

块一「核心代码」——三目与多分支（取自选择结构.pdf p16、p20 课堂案例，自编整合为可编译程序，注明：自编示例，判定逻辑取自素材）：

```cpp
#include <iostream>
using namespace std;
int main() {
    // 案例一（p16）：求两数之差，结果总是大减小
    int a, b, c;
    cin >> a >> b;
    c = (a > b) ? a - b : b - a;   // 三目：条件真取前者，假取后者
    cout << c << endl;

    // 案例二（p20）：switch 检查等级 10/20/30
    int num;
    cin >> num;
    switch (num) {
        case 10: cout << "等级 10" << endl; break;   // break：命中后跳出 switch
        case 20: cout << "等级 20" << endl; break;   // 漏 break 会贯穿到 case 30
        case 30: cout << "等级 30" << endl; break;
        default: cout << "等级不是 10, 20 or 30" << endl; break;
    }
    return 0;
}
```

块二「执行追踪表」（案例一，输入 a=3, b=5；随后 switch 输入 num=20）：

| 步骤 | 当前元素 | 结构状态 | 动作 | 结果 |
|:---:|:---:|:---|:---|:---|
| 1 | 读入 a=3, b=5 | c 未初始化 | 求值 `a > b`，3 > 5 为假 | 走三目第三段 |
| 2 | 三目表达式 | 条件为假 | 计算 b - a = 5 - 3 | c = 2 |
| 3 | 输出 c | c = 2 | cout << c | 输出 2 |
| 4 | 读入 num=20 | 进入 switch | 20 与 case 10 比较，不等 | 落到下一个 case |
| 5 | 命中 case 20 | 匹配成功 | 输出"等级 20"，遇 break | 跳出 switch（case 30 不执行） |

块三「错误写法对照」：

```diff
- if (a > b)
-     cout << "a大" << endl;
-     cout << "a - b = " << a - b << endl;   // 坑1：无大括号，第二行不属于 if，a<=b 时也会执行，且此时 b-a 才是正确差值（答案错）
+ if (a > b) {
+     cout << "a大" << endl;
+     cout << "a - b = " << a - b << endl;   // 大括号明确作用域，两行同属 if 体
+ }
- switch (num) {
-     case 10: cout << "等级 10" << endl;    // 坑2：漏 break，num=10 时贯穿执行 case 20、30、default 的全部输出（答案错，多输出）
-     case 20: cout << "等级 20" << endl;
+ switch (num) {
+     case 10: cout << "等级 10" << endl; break;   // 每个 case 末尾补 break，除非刻意贯穿
- if (x = 0) { ... }    // 坑3：赋值=当比较==，x 被改写为 0，条件恒为假，else 分支永远走（答案错且变量被污染）
+ if (x == 0) { ... }   // 比较 用==；把常量写左边 if (0 == x) 可让笔误直接编译报错
```

**⑤ 典型应用**

- 课堂案例（选择结构.pdf p16）：求两数差且总为大减小——三目"二选一取值"的最小应用，无 OJ 题，素材为课件练习。
- 课堂案例（选择结构.pdf p20）：switch 检查等级 10/20/30——离散值派发的标准写法。
- 竞赛衔接：多分支的"区间互斥且覆盖"意识直接服务于模拟题的状态判定；离散派发的 switch 在读入指令种类固定（如 `1 x y` / `2 x y`）的题里派发操作。竞赛衔接说明：本知识点是后续所有模拟与枚举题的状态分拣器，建议完成下面自编练习题检验。

**⑥ 坑点与边界**

> **【易错】** `if (x = 0)` 把赋值当比较。后果：条件恒为假（赋值表达式的值就是被赋的值 0），且 x 被污染（答案错）。正解 `x == 0`。

> **【易错】** switch 漏 break。后果：命中后贯穿后续所有 case（多输出，WA），见④对照坑 2。

> **【注意】** 多分支条件要"互斥且覆盖"：`num > 0` / `num < 0` / else 覆盖全定义域；若漏掉 else 兜底，num == 0 时三个分支全不执行，程序静默跳过（逻辑漏洞）。

> [!example]-
> **边界数据集（先自己跑一遍，再展开对照）**
> 1. 空输入：无输入直接 EOF，cin >> a 失败，a/b 为未定义值，程序不崩但输出不可信（预期：竞赛中输入规模由题面保证，此处用于理解 cin 失败行为）。
> 2. 单元素：a = b = 5 → 三目条件 5 > 5 为假，c = b - a = 0（预期：输出 0，相等时取哪边结果相同）。
> 3. 全相同：switch 输入 20 连续 10 次 → 每次命中 case 20 即 break（预期：输出 10 行"等级 20"）。
> 4. 严格递增：输入 1,2,...,9 → 全落 default（预期：9 行"等级不是 10, 20 or 30"）。
> 5. 严格递减：输入 30,20,10 → 各命中对应 case（预期：3 行等级输出，顺序随输入）。
> 6. 极值：num = 2147483647（INT_MAX）→ 不匹配任何 case，落 default（预期：default 兜底，不崩不越界；switch 对任意 int 值安全）。

回扣开场：岔路口有了路标，"猜大了/猜小了/猜对"三种反应已经能写——但"输出 1 到 100"还是 100 行。现在解决重复执行的问题。

### 2. 循环三件套与 break、continue：while / do-while / for

前置依赖：本篇 ### 1. 分支结构与边界意识：if 家族与 switch、运算符与表达式（同批）
后续衔接：本篇 ### 3. 嵌套循环与暴力枚举骨架（水仙花数）、[[质数筛法]]（循环 + 标记数组筛质数）

**① 它解决什么问题**

循环控制回答"同一块代码要执行很多遍怎么办"。循环结构.pdf p4：循环语句允许多次执行一个语句或语句组，直到条件不满足。三种形态各有分工（p13 给出选型原则）：**迭代次数固定用 for；次数不确定用 while；必须先做一次再判定用 do-while**。break 立即终止整个循环，continue 跳过本轮进入下一轮（p22）。单层循环执行 n 轮就是 $O(n)$，循环是竞赛程序计算量的主要来源——数清循环层数与每层次数是复杂度分析的基本功。

**② 直觉理解**

模型级类比：**跑步机上的计时圈**。for 是"计划跑 10 圈"：起点（express1 设 i=1）、终点表（express2 判 i<=10）、每圈结束走一步（express3 更新）三样写在一张卡片上，一眼看全。while 是"跑到教练喊停"：只看条件，初值和更新散落在循环体前后。do-while 是"至少先跑一圈再问教练"：先执行后判定（p9：不管条件是否为真，do-while 至少会执行一次）。

小数据推演（循环结构.pdf p8 的例子）：num = 0，条件 `num <= 5`。第 1 轮：0<=5 真，输出 num = 0，num 变 1；……第 6 轮：5<=5 真，输出 num = 5，num 变 6；第 7 轮判定 6<=5 假，退出。共输出 6 行——**边界条件 `<=` 让 5 也被包含**，写成 `<` 就少打一行，这就是循环边界的开闭区间意识。

**③ 原理与推导**

for 的四步执行序（p13-14）：express1（只执行一次）→ express2 判定，假则退出 → 循环体 → express3 → 回到 express2。三要素"初值、条件、更新"缺一即残废：**为什么 continue 在 for 和 while 里行为不同？** for 的 continue 之后仍执行 express3（更新），while 的 continue 直接跳回条件判定、若更新语句写在 continue 之后就永远执行不到——死循环。这一差异是设计出来的：for 把更新从循环体里剥离，结构上就不怕 continue 跳过它；while 把更新交给循环体作者，就得自己保证任何路径都可达更新。

break 与 continue 的作用范围：只作用于**最内层**的循环或 switch——嵌套循环里想一次跳出多层，需要标志变量或 goto（后者不推荐）。do-while 的 while 后面有分号：`do { ... } while (cond);`，这是语法要求，漏写分号编译不过（编译错误，是好事——当场暴露）。

**④ 代码演示**

块一「核心代码」——三种循环与 break/continue（取自循环结构.pdf p8/p12/p16/p23/p24，自编整合，注明：自编示例，逻辑取自素材并修复 p24 缺陷，见 A-3 登记 1）：

```cpp
#include <iostream>
using namespace std;
int main() {
    // for（p16）：固定次数，打印 1-10
    for (int i = 1; i <= 10; i++) cout << i << " ";
    cout << endl;

    // break（p23 改小数据）：从 1 开始，遇到第一个能被 2 和 3 整除的数立即终止
    int num = 1;
    while (true) {                        // 无限循环：次数不可预知时用，内部必须 break
        if (num % 2 == 0 && num % 3 == 0) break;   // num=6 触发
        num++;
    }
    cout << "first = " << num << endl;    // 输出 6

    // continue（p24）：打印 1-6 中的偶数
    for (int i = 1; i <= 6; i++) {
        if (i % 2 == 1) continue;         // 奇数跳过本轮（for 仍执行 i++）
        cout << i << " ";                 // 输出 2 4 6
    }
    cout << endl;
    return 0;
}
```

块二「执行追踪表」（continue 段，i 从 1 到 6）：

| 步骤 | 当前元素 | 结构状态 | 动作 | 结果 |
|:---:|:---:|:---|:---|:---|
| 1 | i=1 | 已输出：空 | 1%2==1 为真，continue | 跳过输出，i++ 到 2 |
| 2 | i=2 | 已输出：空 | 2%2==0，不 continue | 输出 2 |
| 3 | i=3 | 已输出：2 | 3 为奇，continue | 跳过输出，i 到 4 |
| 4 | i=4 | 已输出：2 4 | 偶数 | 输出 4 |
| 5 | i=5 | 已输出：2 4 | 奇数，continue | 跳过输出，i 到 6 |
| 6 | i=6 | 已输出：2 4 | 偶数 | 输出 6，随后 6>6 退出 |

块三「错误写法对照」（含素材 p24 原笔误，此处作为活教材）：

```diff
- for (int i = 1; i <= 10; ) {          // 坑1：循环结构.pdf p24 原文漏写更新表达式 i++——i 恒为 1，1%2==1 恒真 continue，死循环
+ for (int i = 1; i <= 10; i++) {       // 三要素齐全，continue 也绕不开 i++
- while (true) { cout << num; }         // 坑2：无限循环体内无 break 且 num 不更新——永不退出（TLE 在本机的等价物是卡死）
+ while (true) { if (命中) break; num++; }   // 无限循环必须内置出口
- do { cout << i; i++; } while (i <= 10)   // 坑3：do-while 的 while 后漏分号，编译错误
+ do { cout << i; i++; } while (i <= 10);   // 补分号
```

**⑤ 典型应用**

- 课堂案例（循环结构.pdf p8/p12/p16）：while 打印 0-5、do-while 打印 1-10、for 打印 1-10——三形态同一题面的对照。
- 课堂案例（循环结构.pdf p23/p24）：break 找第一个公倍数、continue 筛偶数——两语句的最小演示。
- 竞赛衔接：[[质数筛法]] 的标记筛是"循环 + 分支"的组合拳——外层 for 扫 2 到 n，内层 for 划掉倍数，复杂度 $O(n \log \log n)$ 来自对每层循环次数的求和。竞赛衔接说明：数循环层数、估算总次数（如 $10^8$ 次约为 1 秒）是判断做法能否通过的第一道闸。

**⑥ 坑点与边界**

> **【易错】** while 循环忘更新。后果：条件永真，死循环（评测机上 TLE）。对策：写循环先默念三要素"初值、条件、更新"，更新语句是否在所有路径上可达（continue 会不会跳过它）。

> **【易错】** 边界差一：`i <= n` 与 `i < n` 少打一圈或多打一圈。后果：少遍历一个元素（答案错）或多访问越界下标（RE，呼应同批数组篇）。对策：用 n=1、n=2 手推验证开闭。

> **【注意】** break 只跳最内层；嵌套循环里 break 无法直接终止外层。do-while 至少执行一次的特性决定了"条件初值就不满足"时它仍跑一轮——不想跑就别用它。

> [!example]-
> **边界数据集（先自己跑一遍，再展开对照）**
> 1. 空输入：无输入，循环次数由常量决定（预期：程序正常跑完，无输入依赖）。
> 2. 单元素：`for (i = 1; i <= 1; i++)` 恰跑 1 轮（预期：输出 1；边界 <= 开闭自查的最小样本）。
> 3. 全相同：循环体内输出同一常量 10 次（预期：10 行相同输出，验证次数不出错）。
> 4. 严格递增：i 从 1 到 10 输出 i（预期：1 2 ... 10，10 个值）。
> 5. 严格递减：`for (i = 10; i >= 1; i--)`（预期：10 9 ... 1；更新方向反转时条件不等号也要反转）。
> 6. 极值：`for (int i = 0; i <= 2147483647; i++)` 数到 INT_MAX 后 i++ 溢出为负，条件恒真，死循环（预期：暴露"上界取极值 + 自增"的溢出陷阱；竞赛中循环上界比极值小一格）。

回扣开场：循环三件套就位，"输出 1 到 10000"只要改一个数字。现在解决"重复里还要套重复"的枚举骨架。

### 3. 嵌套循环与暴力枚举骨架：水仙花数

前置依赖：本篇 ### 2. 循环三件套与 break、continue、运算符与表达式（同批，取余 / 整除拆位）
后续衔接：[[枚举与模拟]]（枚举骨架的正式登场）、[[排序]]（遍历与最值查找的数组版，同批下一篇讲）

**① 它解决什么问题**

暴力枚举的通用骨架：**外层循环扫遍候选空间，内层用分支检验每个候选**。循环结构.pdf p17-19 给出嵌套语法：for 里再嵌 for，"循环 1 每走一步，循环 2 完整跑一轮"。水仙花数.cpp 是这个骨架的课堂实例（循环结构.pdf p26 作业）：三位数 n，各位数字的 3 次幂之和等于它本身，如 $1^3 + 5^3 + 3^3 = 153$。候选空间是 100-999 共 900 个数，每个数拆 3 位做常数次运算，总复杂度 $O(900 \times 3) = O(2700)$——毫秒级。把 900 换成题目给的数据规模 n，"枚举是否可行"就看这个乘积落不落在 $10^8$ 量级以内。

**② 直觉理解**

模型级类比：**质检流水线**。外层循环是传送带，把 100 到 999 每个候选送上来；内层检验台做两件事——拆位（取余拿个位、整除拿高位）、算三次幂之和比对。传送带不负责判断，检验台不负责送件，职责分离。这个"传送带 + 检验台"模型管住一大类题：枚举与模拟的全部骨架题（检验台可以换成"回文判定""约数计数""模拟规则"）。

小数据推演（水仙花数.cpp 逻辑，n=153）：g = 153 % 10 = 3（个位）；s = 153 / 10 % 10 = 15 % 10 = 5（十位）；b = 153 / 100 = 1（百位）。检验：3^3 + 5^3 + 1^3 = 27 + 125 + 1 = 153，等于 n 本身，命中输出。反例 n=100：1 + 0 + 0 = 1 不等于 100，不输出。

**③ 原理与推导**

拆位推导：任意三位数 $n = 100b + 10s + g$，其中 $b, s, g \in [0,9]$。则 $g = n \bmod 10$（余数恰是个位）；$n / 10 = 10b + s$（整数除法丢弃个位），再 $\bmod\ 10$ 得 $s$；$n / 100 = b$。三步各是常数次运算，与 n 的大小无关——这正是"内层检验是 $O(位数)$"的原因，也是拆位通法对任意位数成立的原因（循环拆位：`while (n) { digit = n % 10; n /= 10; }`，属补充，资料未覆盖，属补充）。

设计动机：为什么外层用 do-while（素材选择）而不是 for？水仙花数.cpp 用 `int n = 100; do { ...; n++; } while (n < 1000);`——首个候选 100 无需判定即可进检验台，语义上"从 100 起至少检验一次"。for 版 `for (int n = 100; n < 1000; n++)` 行为等价且三要素显式（实测两者输出一致，附录 B-5）。竞赛推荐 for 版：更新不写在循环体里，continue 不会跳过它（知识点 2③ 的结论直接复用）。

**④ 代码演示**

块一「核心代码」——取自素材 水仙花数.cpp（逻辑逐行原样，仅补注释与精简空行）：

```cpp
#include <iostream>
using namespace std;
int main() {
    int n = 100;                        // 候选空间起点：最小的三位数
    int g, s, b;
    do {
        g = n % 10;                     // 个位：余数
        s = n / 10 % 10;                // 十位：先丢个位再取余
        b = n / 100;                    // 百位：整除直接得到
        if (n == g*g*g + s*s*s + b*b*b) {   // 检验台：三次幂之和 == 本身
            cout << n << endl;
        }
        n++;                            // 传送带前进一格
    } while (n < 1000);                 // 终点：999 之后停止（边界 n<1000 覆盖 999）
    return 0;
}
// 实测输出：153 370 371 407（附录 B-5）
```

- 课堂案例（循环结构.pdf p26 作业 + 水仙花数.cpp）：三位水仙花数，实测输出 153 / 370 / 371 / 407（附录 B-5）。
- 迁移题（自编）：统计 [1, n] 中各位数字之和能被 7 整除的数的个数。数据范围 $n \le 10^6$。输入一行一个整数 n；输出个数。题解：外层 for 扫 1 到 n（传送带），内层 while 拆位累加（检验台），计数器命中即加一；总复杂度 $O(n \times 6)$，$n = 10^6$ 时约 $6 \times 10^6$ 次运算，安全。建议先独立做，再对照题解——骨架与水仙花数完全同构，只换了检验台。

**⑥ 坑点与边界**

> **【易错】** 候选空间端点写错（`n <= 1000` 多一圈、`n < 900` 少样）。后果：枚举不完整（答案错）。对策：先写下空间的数学表示 [100, 999]，再翻译成循环条件。

> **【易错】** 内层检验引用了外层循环变量之外的未初始化变量（如忘给 g,s,b 赋值就使用）。后果：读到随机值，结果不可复现（WA 且难查）。对策：检验台用到的每个量都在本轮内现算。

### 4. 随机数与猜数字实战：rand / srand 与范围通式

前置依赖：本篇 ### 1. 分支结构与边界意识：if 家族与 switch、本篇 ### 2. 循环三件套与 break、continue
后续衔接：[[枚举与模拟]]（随机数据构造与对拍）、[[质数筛法]]（随机大数测试的正确性压力源）

**① 它解决什么问题**

程序怎么"出题"？随机数.pdf p2：C++ 没有自带 random 函数，用 `rand()` 和 `srand()`（头文件 `<cstdlib>`）。rand 返回 $[0, RAND\_MAX]$ 的伪随机整数（p3）；srand 设置随机数种子——**种子相同，序列就完全相同**（p5：通过设置不同的种子，我们可以获取不同的随机数序列）。配 `srand((unsigned)time(NULL))` 用系统时钟做种子（需 `<ctime>`），每次运行序列不同。取值映射靠取余通式（p8）：$[0,n)$ 用 `rand()%n`；$[a,b]$ 闭区间用 `rand() % (b-a+1) + a`。单次调用 $O(1)$。猜数字三版（1.0 只判对错、2.0 加大小提示、升级本加次数限制、终极版加再来一局）是分支循环综合实战。

**② 直觉理解**

模型级类比：**洗好的扑克牌序**。rand 是从一摞按固定牌序码好的牌里逐张抽；srand 是选哪一摞——种子定了，"随机"序列其实从头到尾都写死了，所以叫伪随机；time(NULL) 是"每次开新摞"，让两次运行抽到的顺序不同。**为什么竞赛里反而常写 srand(固定值)？** 因为对拍与调试需要可复现：同一份数据跑出同一个结果才查得动 bug——"每次不一样"是游戏要的，"每次一样"是调试要的，srand 的参数决定你要哪个。

小数据推演（随机数.pdf p6 结构）：注释掉 srand 时，每次运行 rand 序列完全相同（g++/MinGW 下首次调用等价于 srand(1)）；放开 `srand((int)time(0))` 后两次运行各不相同。同种子的可复现性已实测断言（附录 B-5 PASS2）。

**③ 原理与推导**

范围通式的推导（p8）：`rand()%n` 把 $[0, RAND\_MAX]$ 均匀压进 $[0, n-1]$（余数分布）；要 $[a, b]$ 闭区间，先平移：区间长度 $L = b - a + 1$，`rand()%L` 得 $[0, L-1]$，加 a 得 $[a, a+L-1] = [a, b]$——**为什么必须 +1？** 闭区间含两端，元素个数是 b-a+1 而非 b-a；漏 +1 就永远取不到 b，猜数字写 `rand()%100` 则 100 永远不出（范围悄悄变成 [0,99]，答案域错）。素材另一变式（p10）：`rand() % 10 / 10.0` 先取 0-9 整数、再除以 10.0 浮点化，得一位小数——整数除法与浮点除法的分界就在除数写不写 `.0`。

设计动机：为什么猜数字 1.0 用 `while(true)` 而不是 for？玩家几次猜中无法预知，次数上界不存在——"次数不确定用 while"（知识点 2① 的选型原则），无限循环的出口必须内置于 break（猜中即出）。升级本的 for 版把"最多 level 次"变成显式上界，循环结束后用 `if (i > level)` 区分"跑满没猜中"与"中途 break 猜中"——break 跳出时 i 停在命中轮次，未 break 时 i 增到 level+1，一个变量状态同时编码两种结局，这是循环变量复用的典型技巧。

**④ 代码演示**

块一「核心代码」——取自素材 升级本.cpp（逻辑逐行原样，仅精简空行与注释）：

```cpp
#include <iostream>
#include <cstdlib>
#include <ctime>
using namespace std;
int main() {
    srand((unsigned)time(NULL));        // 时钟种子：每次运行序列不同
    int guess = rand() % 100 + 1;       // 通式 [1,100]：%100 得 [0,99]，+1 平移（含 100）
    int num = 0;

    int level = 0;
    char c = 0;
    cout << "等级选择：（容易a；中等b；困难c）" << endl;
    cin >> c;
    if (c == 'a') level = 10;           // 多分支：难度 -> 次数上限
    else if (c == 'b') level = 5;
    else if (c == 'c') level = 2;

    int i = 1;
    for (; i <= level; i++) {           // 次数上界显式化
        cout << "请输入数字（1-100）：" << endl;
        cin >> num;
        if (num == guess) {
            cout << "恭喜你，猜对了" << endl;
            break;                      // 命中出口：i 停在命中轮次
        } else if (num > guess) {
            cout << "猜大了" << endl;
        } else {
            cout << "猜小了" << endl;
        }
    }
    if (i > level) {                    // 跑满未 break：i == level+1
        cout << "失败了,你才的数字是" << guess << endl;   // 素材原文"你才"应为"你猜"（A-3 登记 2）
    }
    return 0;
}
```

|:---:|:---:|:---|:---|:---|

- 课堂案例（随机数.pdf p4-p7）：`rand()%100` 取数、时钟播种、宏 `#define random(x) rand()%(x)`——三段递进的最小演示（宏属于预处理知识，同批《预处理命令》展开）。
- 课堂案例（猜数字 1.0 / 2.0 / 终极版.cpp）：无提示版 -> 大小提示版 -> 多轮重玩版，逐版加功能的迭代式开发。终极版在最外层再套 `while(1)`，用 `Y/N` 选择控制整个游戏重开——双层循环 + 分支的综合体。
- 竞赛衔接：随机数在竞赛的用途不是做游戏而是**造数据与对拍**——用固定种子生成随机数组喂给两个程序比对输出，是验证暴力解与优化解一致性的标准手段。竞赛衔接说明：[[枚举与模拟]] 篇的对拍流程以此为基础；注意造数据用固定种子保证可复现。

**⑥ 坑点与边界**

> **【易错】** 通式漏 +1 或平移方向反。后果：取值域与题面不一致（答案域错），且从不越界不报错，最难察觉。对策：代入端点验算——`rand()%100+1` 的最小值 0+1=1、最大值 99+1=100，两端都在 [1,100]。

> **【易错】** 忘播种或反复播种。忘播种：每次运行同一序列（游戏可预测；调试反而友好——先想清你要哪种）。一秒内多次 srand(time(NULL))：种子相同序列重启（④坑 2）。

> **【注意】** RAND_MAX 至少 32767（g++/MinGW 下即 32767）。`rand()%n` 在 n 远小于 RAND_MAX 时分布尚可，n 逼近 RAND_MAX 时低位余数分布有偏——竞赛造数据 n 在 $10^4$ 量级内可放心用；更大规模需拼接两次 rand 或用 `<random>`（延伸，非必需）。

> **边界数据集（先自己跑一遍，再展开对照）**

| 3 | `=` 当 `==`，条件恒定且变量被污染 | 比较用 ==；常量写左边可防笔误 |
| 4 | while/for 忘更新循环变量 | 默念三要素：初值、条件、更新 |
| 5 | while 里 continue 跳过更新语句 | 更新提到条件行（for 结构）或保证可达 |
| 6 | 循环边界差一（<= 与 <） | n=1、n=2 手推开闭区间 |
| 7 | 枚举端点写错（<=1000 / <900） | 先写空间的数学表示再翻译成条件 |
| 8 | do-while 的 while 后漏分号 | 语法要求补分号 |
| 9 | rand()%n 漏 +1，上端点永不可达 | 端点代入验算：min=a, max=b |
| 10 | srand 反复播种 / 忘播种 | 一次播种；调试要复现就播固定种子 |

## 四、总结与自测

### 核心内容（一页纸速览）

- **分支**：单/双/多分支 + switch + 三目；多分支条件要互斥且覆盖；switch 命中后贯穿直到 break。
- **循环**：for 三要素显式（次数固定首选）、while 条件驱动（次数不定）、do-while 先做后判（至少一轮）；break 断整层，continue 跳本轮；for 的更新不受 continue 影响，while 的会。
- **枚举骨架**：外层扫候选空间（传送带）+ 内层拆位检验（检验台）；拆位从低位到高位"整除降位、取余取位"；复杂度 = 候选数 × 单次检验代价。
- **随机数**：rand 伪随机、srand 定种子（同种子同序列）、time(NULL) 时钟种子；通式 [a,b] 闭区间 `rand()%(b-a+1)+a`，端点代入验算。
- **猜数字迭代**：1.0 无限循环 + break -> 2.0 三分支提示 -> 升级本次数上界 + 循环变量状态复用 -> 终极版双层循环重玩。

### 前置概念清单

- 运算符与表达式（同批）：比较、逻辑、取余、整除——分支条件与拆位的全部算子。
- 数据类型与内存表示（同批）：int 范围与溢出——边界数据集第 6 类的判定依据。
- 变量与赋值（C 基础）：循环变量、累计变量——本篇未再展开。
