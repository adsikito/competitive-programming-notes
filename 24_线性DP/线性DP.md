## 一、为什么需要它

先用你大概率碰过壁的暴力做法做一遍 B3637 最长上升子序列：要从一个序列里挑出"逐渐增大"的最长子序列，暴力就是枚举每个元素"取或不取"的所有组合——$2^n$ 种。n=20 时 100 万种还能忍，n=40 时就是 $10^{12}$ 量级，必超时。再看一个更直观的账：B 源引论用的斐波那契朴素递归，本机实测（-O2）fib(40) 要做 **331,160,281 次函数调用**，约 1.1 秒——而 fib(100) 朴素递归的调用量是 $10^{20}$ 量级，等宇宙热寂也算不完。

**碰壁的根源：同一批子问题被反复重算。** fib(5) 的递归树里 fib(3) 被算 2 遍、fib(2) 被算 3 遍（B 源 p4）；序列枚举里，同一前缀的"取到哪了、上一个是谁"被枚举了无数遍。动态规划的破法一句话：**每个子问题只算一次，答案存进表里，以后直接查**——这叫 DP 表。

本篇讲 6 个知识点：DP 是什么（三性质与 DP 表）、从记忆化到递推、LIS（B3637）、LCS（LCR095）、编辑距离（P2758）、DP 设计方法论。顺序理由：概念（1）先于实现路线（2），一维（3）先于二维（4、5），方法论（6）放最后做总收拢。

## 二、知识点逐讲（每个知识点一节，共 6 节）

### 1. 动态规划是什么：三性质与 DP 表

前置依赖：[[搜索优化]]（暴力搜索的视角）、C 基础递归（函数自调用）
后续衔接：[[#2. 从记忆化到递推：一维 DP 的完整降级路径]]、[[#6. DP 设计方法论：状态、转移、初始化、答案四步]]

**① 它解决什么问题**

A 源 slide 1 总纲：动态规划（DP）适用的题有两条前提——**最优子结构**、**重叠子问题**——目标是求"最值"（有时是计数）。**DP 的定义**：把原问题拆成一族参数更小的同类子问题，按依赖顺序逐个求解，结果存进一张表（DP 表），每个子问题只算一次。性质融入正文交代：操作是"定状态 → 推转移 → 建表填表 → 查表出答案"；复杂度总账 = 子问题个数 × 单个转移的决策数（一维线性 DP 常见 $O(n)$ 到 $O(n^2)$）；前提是三性质成立；返回值是表中的一个（或一行的最大值）格子。

**② 直觉理解**

模型级类比：**铺瓷砖记账**。装修要算"每种铺法 cheapest 多少钱"，直接心算全排列会疯；正确做法是做一张台账，"贴满前 k 平方米的最少花费"一行一行记——算第 k+1 行时只翻前面几行，从不重算。台账就是 DP 表，每一行就是一个子问题。

具体小数据推演（B 源 p4 的 fib(5)）：朴素递归树里 fib(5) 调 fib(4) 和 fib(3)；fib(4) 又调 fib(3)——**fib(3) 被算 2 遍，fib(2) 被算 3 遍**。若把每个 fib(k) 的结果记在表里，第二次遇到 fib(3) 直接查表，树瞬间退化成一条链。实测数据（本机 -O2）：朴素递归 fib(30) 要 269 万次调用、fib(40) 要 3.31 亿次；记忆化后每个 fib(k) 只算 1 次，总共 n 次调用。

**③ 原理与推导**

三性质逐一交代（前两条 A 源 slide 1 明示，第三条资料未明确覆盖，按通识补充并标注）：

1. **最优子结构**（A 源 slide 1）：大问题的最优解由子问题的最优解拼出。fib 的版本：fib(n) 由 fib(n-1)、fib(n-2) 的值直接相加得到——子答案对、大答案就对。
2. **重叠子问题**（B 源 fib 递归树）：不同的大问题共享同一批小问题（fib(3) 同时是 fib(4) 和 fib(5) 的子问题）。**这是 DP 省时间的根本原因**：没有重叠的话（比如二分查找的每层区间互不相同），存表毫无收益，直接分治就行。
3. **无后效性**（资料未覆盖，属补充）：状态一旦确定，"未来怎么走"只跟状态值有关，跟"怎么到达这个状态"的历史无关。fib 满足：算 fib(n) 只需要两个数值，不需要知道它们当初是怎么算出来的。**为什么 DP 题要检查这条**：不满足时，同一个"状态值"对应不同答案，表就存不住结果——必须给状态加维度。

**④ 代码演示**

块一「核心代码」：B 源 p5 斐波那契递推（Java 原码改写为 C++17，改动：`new int[]` 改静态数组、类封装去掉）：

```cpp
#include <cstdio>
long long f[1005];                       // long long：fib(47) 已超 int，见⑥极值
int main() {
    int n;
    scanf("%d", &n);
    f[0] = 0;                            // base state：最小子问题直接填
    f[1] = 1;
    for (int i = 2; i <= n; i++)
        f[i] = f[i-1] + f[i-2];          // 转移：查两个更小的格子相加
    printf("%lld\n", f[n]);              // 复杂度：O(n) 时间，O(n) 空间
    return 0;
}
```

块二「执行追踪表」（DP 表逐格填值，n=5）：

| 步骤 | 当前元素 | 结构状态 | 动作 | 结果 |

| 1 | i=0 | f=[0,?,?,?,?] | base case 直接填 | f[0]=0 |
| 2 | i=1 | f=[0,1,?,?,?] | base case 直接填 | f[1]=1 |
| 3 | i=2 | f=[0,1,?,?,?] | f[2]=f[1]+f[0] | f[2]=1 |
| 4 | i=3 | f=[0,1,1,?,?] | f[3]=f[2]+f[1] | f[3]=2 |
| 5 | i=4 | f=[0,1,1,2,?] | f[4]=f[3]+f[2] | f[4]=3 |
| 6 | i=5 | f=[0,1,1,2,3] | f[5]=f[4]+f[3] | f[5]=5 |

块三「错误写法对照」（朴素递归 vs 存表，B 源 p4-5 的对照）：

```diff
- long long fib(int n) { if (n <= 1) return n; return fib(n-1) + fib(n-2); }   // 坑1：不存表，同一子问题反复重算——实测 fib(40) 3.31 亿次调用（TLE）
+ long long f[1005]; f[0]=0; f[1]=1; for (i=2..n) f[i]=f[i-1]+f[i-2];   // 每格只算一次，O(n)
- int f[100]; f[1]=1; for (i=2..n) f[i]=f[i-1]+f[i-2];   // 坑2：漏填 f[0]=0，f[2]=f[1]+f[0] 读到随机值（答案错，且可能 WA 出诡异结果）
+ f[0] = 0; f[1] = 1;   // base case 一格都不能漏
```

**⑤ 典型应用**

- 真题：B3637 最长上升子序列（A 源 slide 2，知识点 3），一维 DP 的入门板子。
- 真题：力扣 70 爬楼梯（题号真实；"每次上 1 或 2 阶，数方案数"——转移 `f[i]=f[i-1]+f[i-2]`，与本节 fib 完全同构）。
- B 源 p9-12 求和问题（集合 {1,3,5} 凑出 n 的方案数，知识点 2 的追踪表主角）。
- 迁移题：台阶问题变体——每次可上 1、2、3 阶，求方案数。建议先独立做，再对照题解：转移就是 B 源求和问题的形状 `f[i]=f[i-1]+f[i-2]+f[i-3]`，初始 `f[0]=1, f[1]=1, f[2]=2`，答案 f[n]；复杂度 O(n)。标注：自编。

**⑥ 坑点与边界**

> **【易错】** 用 int 存 fib 或计数类 DP 的表值。fib(47)=2971215073 已超 int 上限 2147483647——计数类、求和类 DP 默认 long long。

> **【易错】** base case 漏填。转移方程只在"能从更小格子查到值"的范围内合法，最底层一格不填，整张表从某一格开始全是错值。

> **【注意】** DP 不是固定算法而是设计套路，三性质是"能不能用 DP"的检查条件：最优子结构、重叠子问题有一条不成立，就换搜索或分治；无后效性不成立时给状态加维度再检查。

> [!example]-
> **边界数据集（先自己跑一遍，再展开对照）**
> 1. 空输入：n=0 → f[0]=0 直接是 base case，输出 0（预期：不进循环、不崩溃）。
> 2. 单元素：n=1 → 输出 1（base case 命中，循环体零次）。
> 3. 全相同：不适用：fib 是单参数递推，没有"元素重复"概念。
> 4. 严格递增：n=2,3,4 递增输入 → 输出 1、2、3，每格只依赖更小下标（预期：填表方向从小到大）。
> 5. 严格递减：不适用：一维表没有"输入顺序"可言，理由同上。
> 6. 极值：n=47 → fib(47)=2971215073 超 int 上限，int 版输出负数（预期：long long 版输出 2971215073，专查溢出）。

回扣开场：朴素递归在 fib(40) 上花了 3.31 亿次调用，存表后只剩 n 次加法。现在你能解决"重复子问题爆炸"了——用的是③的重叠子问题判断与④的填表。下一节解决"两种存表路线怎么选"。

### 2. 从记忆化到递推：一维 DP 的完整降级路径

前置依赖：[[#1. 动态规划是什么：三性质与 DP 表]]、[[搜索优化]]（记忆化 = 带缓存的搜索）
后续衔接：[[#3. LIS 最长上升子序列（B3637）：一维 DP]]、[[#4. LCS 最长公共子序列（LCR095）：二维 DP]]

**① 它解决什么问题**

B 源给出实现 DP 的两条等价路线。**记忆化（备忘录法，自顶向下）**：保留朴素递归的骨架，加一张查表——算之前先查表，表里有值直接返回；B 源 p8 的做法是开 `lookup` 数组、用 NIL（-1）标记"没算过"。**递推（制表法，自底向上）**：扔掉递归，按依赖顺序把 DP 表从头填到尾。两条路线复杂度相同（状态数 × 转移代价，fib 均为 $O(n)$）；**为什么要会两条**：记忆化从暴力改起来最省脑力（考场先用它保对），递推没有递归开销、还能做滚动数组等空间优化（[[搜索优化]] 篇的搜索剪枝同思路）。

**② 直觉理解**

模型级类比：**点菜的两家店**。记忆化是"客人点啥现做啥，做过的挂黑板，再点直接端"；递推是"不管谁来，按菜谱把 1 号到 n 号菜全部预制好摆进橱窗"。黑板和橱窗都是同一张 DP 表，区别只是填表顺序：一个被"问"驱动（自顶向下），一个被"序"驱动（自底向上）。

具体小数据推演（B 源 p9-10 求和问题）：用 {1,3,5} 凑出 n，数字可重复用、计顺序（1+5 与 5+1 算两种）。n=6 有 8 种。想凑 7，枚举"最后一个数"：它是 1，则前面凑 6（8 种）；是 3，则前面凑 4（3 种）；是 5，则前面凑 2（1 种）——共 $8+3+1=12$ 种。这正是转移方程 `DP[n] = DP[n-1] + DP[n-3] + DP[n-5]`（B 源 p10 原式）。

**③ 原理与推导**

记忆化的正确性：查表返回的前提是"同参数的函数结果唯一"，这正是无后效性（知识点 1③ 性质 3）。递推的正确性核心在**遍历顺序**：DP[n] 依赖 DP[n-1]、DP[n-3]、DP[n-5]，所以必须按下标从小到大填——**为什么遍历顺序由依赖决定**：填某个格子时它依赖的所有格子必须已经填好，"依赖指向更小下标"就从小到大，若状态依赖更大下标（如 LIS 的某类变形）就得反过来。把"函数递归调小"换成"循环递增查表"，就是记忆化到递推的全部改动，B 源 p12 给出同题两版代码，转移式逐字相同。

**④ 代码演示**

块一「核心代码」：B 源 p8 备忘录（Java 原码改写为 C++17，改动：`new int[]` 改静态数组、类封装去掉）与递推版并排：

```cpp
#include <cstring>
#include <cstdio>
const int NIL = -1;
long long lookup[105];                   // 备忘录：0 是合法值，必须用 -1 标记"没算过"
long long sumMemo(int n) {
    if (n == 1 || n == 0) return 1;      // base case：先于查表（B 源原序）
    if (lookup[n] != NIL) return lookup[n];   // 查表：算过直接返回
    return lookup[n] = sumMemo(n-1) + sumMemo(n-3) + sumMemo(n-5);   // 算完回填
}
long long sumTab(int n) {                // 递推版：同一转移式，顺序填表
    long long DP[105] = {1, 1, 1, 2, 3, 5};   // DP[0..5]，B 源 p12 原值
    for (int i = 6; i <= n; i++)
        DP[i] = DP[i-1] + DP[i-3] + DP[i-5];  // 复杂度：O(n) 状态 x O(1) 转移
    return DP[n];
}
```

块二「执行追踪表」（递推版填表，n=7；DP[0..5] 为初始态）：

| 步骤 | 当前元素 | 结构状态 | 动作 | 结果 |
|:---:|:---:|:---|:---|:---|
| 1 | DP[0..5] | [1,1,1,2,3,5] | base case 直填（B 源 p12） | 初始态 |
| 2 | i=6 | [1,1,1,2,3,5,?] | DP[6]=DP[5]+DP[3]+DP[1]=5+2+1 | DP[6]=8 |
| 3 | i=7 | [1,1,1,2,3,5,8] | DP[7]=DP[6]+DP[4]+DP[2]=8+3+1 | DP[7]=12 |

块三「错误写法对照」：

```diff
- int lookup[105]; if (lookup[n] != 0) return lookup[n];   // 坑1：用 0 当"没算过"标记——0 本身是合法答案值，会把已算好的 0 当成没算（答案错或死递归）
+ memset(lookup, NIL, sizeof(lookup)); if (lookup[n] != NIL) return lookup[n];   // 用 -1 标记（B 源 NIL 法）
- for (int i = n; i >= 6; i--) DP[i] = DP[i-1] + DP[i-3] + DP[i-5];   // 坑2：递推方向反了——填 DP[7] 时 DP[6] 还没算，读到 0（答案错）
+ for (int i = 6; i <= n; i++) DP[i] = DP[i-1] + DP[i-3] + DP[i-5];   // 依赖指向更小下标，必须从小到大
```

**⑤ 典型应用**

- 真题：B 源 p9-12 求和问题（{1,3,5} 凑 n 计方案数），本节追踪表同源，DP[7]=12。
- 真题：力扣 70 爬楼梯（题号真实）——先用记忆化保正确，再改递推，同一题两条路都走一遍。
- 迁移题：把求和问题改成"求最少用几个数凑出 n"（可重复用 {1,3,5}）。建议先独立做，再对照题解：状态不变 DP[n]，转移从"计数相加"改成"取最小" `DP[n]=min(DP[n-1], DP[n-3], DP[n-5])+1`，初始 DP[0]=0；手算 DP[1..7] = 1,2,1,2,1,2,3（DP[7]=min(DP[6],DP[4],DP[2])+1=2+1=3，例如 1+3+3）。正确答案 3。复杂度 O(n)。标注：自编。

**⑥ 坑点与边界**

> **【易错】** 备忘录数组不清 -1 直接用。全局数组初值是 0，而 0 常是合法答案——"查表"永远命中假的 0。B 源 NIL=-1 的意义就在此：标记值必须取值域外的数。

> **【易错】** 递推方向与依赖方向相反。转移式确定后，循环方向没有自由度：`DP[i]` 依赖谁，谁就必须先填好（④对照坑 2）。

> **【注意】** 记忆化版递归深度 = 状态链长，n 大时（如 $10^5$）有栈溢出风险——这正是考场上"先记忆化保对、大数据换递推"的实操理由。

> [!example]-
> **边界数据集（先自己跑一遍，再展开对照）**
> 1. 空输入：n=0 → 记忆化版返回 1（base case）；递推版 DP[0]=1（预期：两边一致）。
> 2. 单元素：n=1 → 返回 1（预期：base case 命中）。
> 3. 全相同：不适用：单参数递推无"元素重复"概念。
> 4. 严格递增：n=1..7 → 表值 1,1,2,3,5,8,12（预期：与 B 源 p9-10 逐项一致）。
> 5. 严格递减：不适用：理由同 3。
> 6. 极值：n=40 → 方案数指数增长远超 int（计数类通病）——预期：long long 版正确，int 版溢出为负（专查溢出）。

回扣开场：暴力递归的重复子问题，被"查表"两刀砍掉——自顶向下加备忘录，或自底向上按序制表。现在你能把任何一个暴力递归改造成 DP 了，接下来用它刷三道线性 DP 真题。

### 3. LIS 最长上升子序列（B3637）：一维 DP

前置依赖：[[#2. 从记忆化到递推：一维 DP 的完整降级路径]]、[[枚举与模拟]]（子集枚举的暴力视角）
后续衔接：[[#4. LCS 最长公共子序列（LCR095）：二维 DP]]、[[二分]]（O(n log n) 优化）、[[#6. DP 设计方法论：状态、转移、初始化、答案四步]]

**① 它解决什么问题**

B3637（洛谷，A 源 slide 2）：给 n 个正整数，输出最长上升子序列（LIS）的长度——子序列=按下标递增挑元素、可以跳着挑；上升=严格增大。数据规模下 $O(n^2)$ 足够通过（时间限制 1 秒；具体数据范围数值见题面页，页面内嵌公式未能提取，附录 B-3 登记）。复杂度总账：$O(n^2)$ 时间、$O(n)$ 空间，$n=5 \times 10^3$ 时约 $2.5 \times 10^7$ 次转移。

**② 直觉理解**

模型级类比：**接力赛报名**。想知道"以第 i 棒选手结尾的最长上升接力链有多长"，就问遍所有排在 i 前面且比 a[i] 矮的选手："以你结尾的链最长几棒？"取最大值，i 再接上一棒。每人一张记分牌（dp[i]），牌子按下标顺序一张张写。

具体小数据推演（B3637 官方样例 `1 2 4 1 3 4`）：以 1 结尾的 LIS 是 {1} 长 1；以 2 结尾可接在 1 后，长 2；以 4 结尾可接在 2 后，长 3；以第二个 1 结尾谁也接不上（前面没有比 1 小的），长 1；以 3 结尾接在 2 后长 3；以最后的 4 结尾接在 3 后长 4。答案取全部记分牌最大值 = 4。

**③ 原理与推导**

A 源 slide 2 的推导链：任意一个上升子序列必然以某个 a[i] 结尾（"很有道理的废话"），所以只需求出**分别以每个元素结尾**的 LIS 长度，取最大。状态定义：`dp[i]` = 以 a[i] 结尾的 LIS 长度。转移推导：假设 dp[1..i-1] 已求出，以 a[i] 结尾的 LIS 要么只有 a[i] 自己（长 1），要么接在某个满足 `a[j] < a[i]`（j<i）的 a[j] 的 LIS 后面——枚举 j 取最大：

$$dp[i] = \max_{j<i,\ a[j]<a[i]}(dp[j] + 1)，下界 dp[i] = 1$$

**为什么答案是 $\max_{i} dp[i]$ 而不是 dp[n]**（设计动机）：状态定义锚定在"以 i 结尾"，但全局最优的那条 LIS 不一定以最后一个元素结尾（样例里以第 6 个元素结尾，但换个输入就不是）——定义决定答案形态，这是知识点 6 的核心口诀之一。严格性检查：转移条件是 `a[j] < a[i]` 严格小于（A 源 slide 2 原式；写成 `<=` 会把相等的元素接起来，变成"不下降子序列"，B3637 会 WA）。

**④ 代码演示**

块一「核心代码」：取自源文件 B3637.cpp，无逻辑改动（原文件自写 `max` 函数保留）：

```cpp
#include<iostream>
#include<algorithm>
using namespace std;
int dp[5005];
int a[5005];
int n;
int max(int a,int b)
{
	return a>b?a:b;
}
int main()
{
	cin>>n;
	for(int i=1;i<=n;i++)
	{
		cin>>a[i];
	}

	//初始化状态数组
	for(int i=1;i<=n;i++)
	{
		dp[i]=1;                        // 每个元素自成一条长 1 的链
	}

	for(int i=2;i<=n;i++)
	{
		//1以a[i]为结尾的最长上升子序列的长度
		for(int j=1;j<=i-1;j++)
		{
			if(a[i]>a[j])dp[i]=max(dp[i],dp[j]+1);   // 复杂度：内层 j 扫描，总 O(n^2)
		}
	}
	int ans=0;
	for(int i=1;i<=n;i++)
	{
		ans=max(ans,dp[i]);             // 答案：全表最大值，不是 dp[n]
	}
	cout<<ans<<endl;

 }
```

块二「执行追踪表」（DP 表逐格填值，官方样例 `1 2 4 1 3 4`，dp 初始 [1,1,1,1,1,1]）：

| 步骤 | 当前元素 | 结构状态 | 动作 | 结果 |
|:---:|:---:|:---|:---|:---|
| 1 | i=1, a[1]=1 | dp=[1,1,1,1,1,1] | 无前驱可比（j 范围为空） | dp[1]=1 |
| 2 | i=2, a[2]=2 | dp=[1,1,1,1,1,1] | j=1: 2>1 成立 | dp[2]=dp[1]+1=2 |
| 3 | i=3, a[3]=4 | dp=[1,2,1,1,1,1] | j=1: 4>1 得 2；j=2: 4>2 得 3，取最大 | dp[3]=3 |
| 4 | i=4, a[4]=1 | dp=[1,2,3,1,1,1] | j=1..3: 1>1、1>2、1>4 均不成立 | dp[4]=1 |
| 5 | i=5, a[5]=3 | dp=[1,2,3,1,1,1] | j=1 得 2；j=2 得 3；j=3: 3>4 不成立；j=4: 3>1 得 2，取最大 | dp[5]=3 |
| 6 | i=6, a[6]=4 | dp=[1,2,3,1,3,1] | j=3: 4>4 不成立（严格）；j=5: 4>3 得 4，取最大 | dp[6]=4 |
| 7 | 统计答案 | dp=[1,2,3,1,3,4] | max(dp[1..6]) | ans=4 |

块三「错误写法对照」：

```diff
- if(a[i]>=a[j])dp[i]=max(dp[i],dp[j]+1);   // 坑1：条件写成 >=——相等元素被串成"不下降子序列"，1 2 2 3 会输出 4 而正确 LIS 是 3（答案错）
+ if(a[i]>a[j])dp[i]=max(dp[i],dp[j]+1);   // 严格小于（A 源 slide 2 原式）
- for(int i=1;i<=n;i++) dp[i]=0;            // 坑2：初始化成 0——内层若无任何 j 满足条件，dp[i] 停在 0，"单元素链"被抹掉（答案偏小）
+ for(int i=1;i<=n;i++) dp[i]=1;            // 每个元素自身就是长 1 的链（A 源：初始认为每个元素各自为一个序列）
- cout<<dp[n]<<endl;                        // 坑3：答案读 dp[n]——LIS 不一定以最后一个元素结尾（答案偏小）
+ cout<<ans<<endl;                          // 全表取最大
```

**⑤ 典型应用**

- 真题：B3637【模板】最长上升子序列（洛谷，A 源 slide 2）——④全流程，实测官方样例输出 4（附录 B-5）。
- 真题：力扣 300 最长递增子序列（题号真实）——同一道题的英文面板，官方样例 `10 9 2 5 3 7 101 18` 答案 4，本节 O(n log n) 补充实现已实测该样例。
- 真题：P1020 导弹拦截（NOIP 1999，题号真实）——第一问就是 LIS（拦截系统高度需不增，反向求最长不升子序列），延伸练习。
- 迁移题：合唱队形（先增后减的最长"山峰"）。建议先独立做，再对照题解：正扫一遍 LIS 得 up[i]（以 i 结尾的最长上升），再反扫一遍得 down[i]（以 i 开头的最长下降），答案 `n - max(up[i]+down[i]-1)`；复杂度两次 $O(n^2)$。标注：自编。

> [!note]
> **【补充】** O(n log n) 贪心+二分优化（资料未覆盖，属补充；自编实现已实测，含力扣 300 样例，附录 B-5）。维护 tails[k] = "长度为 k+1 的上升子序列的最小可能结尾"，tails 天然有序：每个新元素用 [[二分]]（lower_bound）找它该替换的位置——替换是"同样长度、结尾更小"的贪心，追加则是链变长。复杂度 $O(n \log n)$，$n=10^5$ 级别时才需要它；B3637 规模用 $O(n^2)$ 即可。

```cpp
int tails[5005], cnt = 0;                // tails 有序；cnt = 当前最长链长
for (int i = 1; i <= n; i++) {
    int pos = (int)(lower_bound(tails, tails + cnt, a[i]) - tails);   // 二分：首个 >= a[i] 的位置（等价 C：手写二分循环）
    tails[pos] = a[i];                   // 替换：同长度换更小结尾；pos==cnt 即链变长
    if (pos == cnt) cnt++;
}
// cnt 即 LIS 长度；注意 tails 不是某条具体的 LIS，只保长度正确
```

**⑥ 坑点与边界**

> **【易错】** 严格性写错：`>` 与 `>=` 一字之差，题意"上升"变"不下降"（④对照坑 1）。审题先问一句：相等元素算不算上升？

> **【易错】** 初始化与答案读取配套错误：dp 初值 1 配全表 max；若状态定义改成"前 i 个中的 LIS"（不锚定结尾），转移就断了——以 i 结尾这个维度不可省（知识点 6 展开）。

> **【注意】** O(n log n) 版的 tails 数组只保证长度正确， tails 内容不是任何一条真实的 LIS（要还原方案得另记前驱）。

> [!example]-
> **边界数据集（先自己跑一遍，再展开对照）**
> 1. 空输入：n=0 → 主循环零次，ans 初值 0，输出 0（预期：不崩溃）。题面通常保证 n 至少为 1，此处为防御性检查。
> 2. 单元素：n=1, a={7} → dp[1]=1，输出 1（预期：单元素自成长 1 链）。
> 3. 全相同：a={2,2,2} → 任何 a[i]>a[j] 均不成立，全 dp=1，输出 1（预期：严格上升不含相等）。
> 4. 严格递增：a={1,2,3,4,5} → 每个 dp[i]=dp[i-1]+1，输出 5（预期：dp 单调增长）。
> 5. 严格递减：a={5,4,3,2,1} → 无任何可接前驱，全 dp=1，输出 1（预期：与全相同同答案）。
> 6. 极值：a_i=10^9 量级 → int 可存（上限约 21.4 亿），比较不溢出；真正要防的是 n 上限改题后 dp/a 数组开小（数组按题面 n 上限重算，防 RE）。

回扣开场：暴力枚举 $2^n$ 的子序列组合，被"以 i 结尾"这一个状态定义压成 $O(n^2)$ 的填表。现在你能解决开场那个 B3637 了——用的是③的状态定义与④的逐格填表。下一节把一维表升级成二维表。

### 4. LCS 最长公共子序列（LCR095）：二维 DP

前置依赖：[[#2. 从记忆化到递推：一维 DP 的完整降级路径]]、字符串下标基础
后续衔接：[[#5. 编辑距离（P2758）：二维 DP 决策取最小]]、[[#6. DP 设计方法论：状态、转移、初始化、答案四步]]

**① 它解决什么问题**

LCR 095（力扣，A 源 slide 3 链接 qJnOS7 同题，见 A-3 登记 3）：求两串的**最长公共子序列**（LCS）长度——两串都按下标递增挑字符，挑出的串要完全相同。复杂度总账：$O(nm)$ 时间、$O(nm)$ 空间（两串各长千级时约 $10^6$ 格）。

**② 直觉理解**

模型级类比：**两份课程表找公共选课**。两人在不同学期选课（顺序都保留），求"共同选过、且先后顺序一致"的最长课程串。比较到"第 i 门对第 j 门"时只有两种局面：这两门相同（接上，各退一步）或不同（至少有一门不进公共串，退其中一步试试）。

具体小数据推演（LCR 095 官方示例 `abcde` / `ace`）：手算逐格填表见④追踪表，结果 3（`ace`）。第一行 `a` 对 `ace`：a 匹配上，公共串 `a` 长 1；第二行 `ab` 对 `ace`：b 没匹配上，公共串仍 `a` 长 1；第三行 `abc` 对 `ace`：c 匹配，`ac` 长 2；第五行 `abcde` 对 `ace`：e 匹配，`ace` 长 3。

**③ 原理与推导**

A 源 slide 3 的思路："一句话描述问题"→ 状态定义 `dp[i][j]` = 第一串前 i 位与第二串前 j 位的 LCS 长度。转移推导（设 a[i]、b[j] 为两串第 i、j 个字符）：

- 若 a[i] == b[j]：这个公共字符必然同时是两串"当前对齐位"的最优选择之一，`dp[i][j] = dp[i-1][j-1] + 1`。
- 若 a[i] != b[j]：公共子序列不可能同时以 a[i] 和 b[j] 结尾，那么它至少不使用其中一个——不用 a[i] 的方案是 dp[i-1][j]，不用 b[j] 的方案是 dp[i][j-1]，取最大：`dp[i][j] = max(dp[i-1][j], dp[i][j-1])`。

初始化：`dp[0][j] = dp[i][0] = 0`——空串与任何串的 LCS 为 0（A 源 slide 3："初始状态：一开始认为没有 LCS"），这也是整张表能填起来的"第 0 行第 0 列"。**为什么 else 分支不需要比较 dp[i-1][j-1]+1**（设计动机）：dp[i-1][j-1] 的任何公共子序列不使用 a[i]（或不用 b[j] 亦然），其长度被 dp[i-1][j] 或 dp[i][j-1] 覆盖——即恒有 dp[i-1][j-1] ≤ max(dp[i-1][j], dp[i][j-1])，三项取 max 与两项取 max 等价，省一项。

**④ 代码演示**

块一「核心代码」：取自源文件 LC LCR 095.cpp，改动：`int dp[1005][1005]={0}` 为函数内局部数组约 4MB，Windows 默认栈 1MB 下运行即栈溢出（实测见 A-3 登记 1），改为 `static`（其余逐行原样）：

```cpp
#include<iostream>
#include<algorithm>
#include<string>
using namespace std;
int longestCommonSubsequence(string text1, string text2)
{
	int n=text1.size();
	int m=text2.size();
	static int dp[1005][1005]={0};   // 改动：原为局部数组（4MB 栈溢出），static 移入静态区
	text1=" "+text1;//[1]~~[n]           // 技巧：前插空格，让下标从 1 开始对齐"前 i 位"
	text2=" "+text2;//[1]~~[m]
	for(int i=1;i<=n;i++)
	{
		for(int j=1;j<=m;j++)
		{
			if(text1[i]==text2[j])
			{
				dp[i][j]=dp[i-1][j-1]+1;             // 复杂度：两重循环 O(nm)
			}
			else
			{
				dp[i][j]=max(dp[i][j-1],dp[i-1][j]); // 不用其一，取最大
			}
		}
	}
	return dp[n][m];
}
int main()
{
	string s,p;
	cin>>s;
	cin>>p;
	int ans= longestCommonSubsequence(s, p);
	cout<<ans<<endl;
}
```

块二「执行追踪表」（DP 表逐格填值，官方示例 `abcde` / `ace`；表中 R1..R5 为 dp 第 i 行填完后的状态，行内三格对应 j=1,2,3）：

| 步骤 | 当前元素 | 结构状态 | 动作 | 结果 |
|:---:|:---:|:---|:---|:---|
| 1 | 第 0 行/列 | dp[0][j]=dp[i][0]=0 | 空串初始化（"没有 LCS"） | 边界就绪 |
| 2 | i=1 (a) | R1=[1,1,1] | j=1: a==a 退左上+1；j=2,3: 不等取两侧最大 | dp[1]=[1,1,1] |
| 3 | i=2 (b) | R2=[1,1,1] | j=1..3: b 与 a/c/e 均不等 | dp[2]=[1,1,1] |
| 4 | i=3 (c) | R3=[1,2,2] | j=2: c==c 退 dp[2][1]+1=2；j=1,3 取最大 | dp[3]=[1,2,2] |
| 5 | i=4 (d) | R4=[1,2,2] | d 与 a/c/e 均不等，全部取最大 | dp[4]=[1,2,2] |
| 6 | i=5 (e) | R5=[1,2,3] | j=3: e==e 退 dp[4][2]+1=3 | dp[5]=[1,2,3] |
| 7 | 统计答案 | dp[5][3] | 直接读表（定义是"前 i 位对前 j 位"） | ans=3 |

块三「错误写法对照」：

```diff
- dp[i][j]=dp[i-1][j-1]+1;   // 坑1（else 分支误加）：不等时也"退左上+1"——a[i]、b[j] 没匹配上却把它算进公共串，abc/def 会算出正数（答案偏大）
+ dp[i][j]=max(dp[i][j-1],dp[i-1][j]);   // 不等时只能"不用其一"（③推导）
- for(int i=1;i<=n;i++)       // 坑2：漏初始化第 0 行/第 0 列——dp[i][1]=dp[i-1][0]+1 读到随机值（答案错且不可复现）
+ dp[0][j]=0; dp[i][0]=0;     // static 数组恰好清零是运气不是保障，显式初始化才可靠
- int dp[1005][1005];         // 坑3：写在函数内（局部）——约 4MB 超过 Windows 默认 1MB 栈，实测运行栈溢出（A-3 登记 1）
+ static int dp[1005][1005];  // 移入静态区（或改为全局数组）
```

**⑤ 典型应用**

- 真题：LCR 095 最长公共子序列（力扣，A 源 slide 3）——④全流程，实测三组官方示例 3 / 3 / 0（附录 B-5）。
- 真题：力扣 1143 最长公共子序列（题号真实，与 LCR 095 同题）——双面板互通，一套代码两处提交。
- 迁移题：两串的"最长公共子串"（要求连续）。建议先独立做，再对照题解：状态同为 dp[i][j]，转移改为只在 a[i]==b[j] 时 `dp[i][j]=dp[i-1][j-1]+1`、否则清 0，答案为全表最大值而非 dp[n][m]；复杂度不变 $O(nm)$。标注：自编。

**⑥ 坑点与边界**

> **【易错】** else 分支多加一项或 +1（④对照坑 1）：不匹配时不消耗任何字符，长度只能"继承"不能"增长"。

> **【易错】** 空串边界没初始化就开填（④对照坑 2）：第 0 行第 0 列是全部转移的"地基"，`" "+text1` 技巧正是为了让第 0 位代表空串。

> **【注意】** 大二维表别放函数局部：$1005 \times 1005 \times 4B \approx 4MB$，Windows 默认栈 1MB 直接栈溢出——实测源文件即踩此坑（A-3 登记 1）。全局或 static 才安全。

> [!example]-
> **边界数据集（先自己跑一遍，再展开对照）**
> 1. 空输入：两串全空 → n=m=0 双循环零次，dp[0][0]=0，输出 0（预期：不崩溃）。
> 2. 单元素：`a` / `x` → 输出 0；`a` / `a` → 输出 1（预期：单字符匹配与否一目了然）。
> 3. 全相同：`aaa` / `aaa` → 三次匹配全退左上，输出 3（预期：整串公共）。
> 4. 严格递增：`abc` / `abc` → 输出 3；`abc` / `cba` → 输出 1（预期：顺序不同只剩单字符公共）。
> 5. 严格递减：`cba` / `abc` → 输出 1（预期：LCS 与"逆序"无关，只认子序列）。
> 6. 极值：两串各长 1000 → 表 $10^6$ 格约 4MB，全局数组可行、局部数组栈溢出（预期：static 版正常出答案，呼应 A-3 登记 1）。

回扣开场：一维状态装不下"两个串各到哪了"的信息，二维表 dp[i][j] 把局面参数化后转移依旧只有两三条。现在你能解决 LCR 095 了——用的是③的两条转移与④的逐格填表。下一节给转移加上"决策与代价"。

### 5. 编辑距离（P2758）：二维 DP 决策取最小

前置依赖：[[#4. LCS 最长公共子序列（LCR095）：二维 DP]]
后续衔接：[[#6. DP 设计方法论：状态、转移、初始化、答案四步]]、背包（同批，素材未含，另篇）

**① 它解决什么问题**

P2758（洛谷，A 源 slide 4-5）：把串 A 变成串 B 的**最少**操作次数，操作三种——删除一个字符、插入一个字符、把一个字符改成另一个。与 LCS 同为二维表，区别是把"公共长度取最大"换成"操作代价取最小"。复杂度总账：$O(nm)$ 时间、$O(nm)$ 空间，与 LCS 同级。

**② 直觉理解**

模型级类比：**两份手稿校对**。编辑到"手稿 A 的前 i 行 vs 目标 B 的前 j 行"时，看最后一行：末行相同就不用动（代价继承左上角）；不同则三选一付钱——在 A 后面**插** B 的末行（对应左格 +1）、把 A 的末行**删**掉（上格 +1）、把 A 的末行**改**成 B 的末行（左上格 +1），取最便宜的。

具体小数据推演（自编小数据 `abc` → `ac`，官方样例过大不便逐格展示）：删掉 b 即可，答案应为 1——追踪表④会逐格验证。官方样例 `sfdqxbw` / `gfdgw` 答案 4（洛谷题面，断言程序实测一致，附录 B-5）。

**③ 原理与推导**

A 源 slide 4 的推导链：状态定义 `dp[i][j]` = 将 A[1..i] 变成 B[1..j] 的最少操作数。转移推导（设 a[i]、b[j] 为第 i、j 个字符）：

- 若 a[i] == b[j]：第 i、j 位不用动，`dp[i][j] = dp[i-1][j-1]`（A 源 slide 4 情况 1："什么都不干"）。
- 若 a[i] != b[j]，三种决策各推一遍（A 源 slide 4 情况 2）：
  1. **插入**：`dp[i][j-1] + 1`——先把 A 前 i 位变成 B 前 j-1 位，再在 A 末尾插入 b[j]；
  2. **删除**：`dp[i-1][j] + 1`——先把 A 前 i-1 位变成 B 前 j 位，再把多余的 a[i] 删掉；
  3. **替换**：`dp[i-1][j-1] + 1`——先把前缀变好，再把 a[i] 改成 b[j]。

  取三者最小：`dp[i][j] = min(dp[i][j-1], dp[i-1][j], dp[i-1][j-1]) + 1`。

初始化（A 源 slide 5）：`dp[i][0] = i`（B 为空串，A 只能全删，删 i 次）、`dp[0][j] = j`（A 为空串，只能插 j 次）——"全部删除和全部插入，空串的情况"。**为什么 a[i]==b[j] 时不需要再取三种决策的 min**（设计动机）：不动末位的方案代价 dp[i-1][j-1] 不会更差——任何"动了末位"的方案都可以调整成不动末位而不增加代价（插入/删除/改末位的三类方案分别可归约为前缀方案 +1 代价），归纳可得直接继承左上角就是最优，这也是三份源码一致采用的写法。

**④ 代码演示**

块一「核心代码」：取自源文件 P2758.cpp，无逻辑改动（注释为原文件所有）：

```cpp
#include <cstdio>
#include <cstring>
#include <algorithm>
using namespace std;
char a[2005], b[2005];
int n, m, dp[2005][2005];                // 全局数组：约 16MB，静态区放得下（局部必栈溢出）
int main()
{
    scanf("%s%s", a + 1, b + 1);//从下标1开始读入。
    n = strlen(a + 1);
	m = strlen(b + 1);
    for (int i = 1; i <= n; i++) dp[i][0] = i;//初始化，a字符串前i（包括第i个）个字符至少要通过删除字符i个变成b字符串前0个字符，即a字符串全删没了需要操作i次。
    for (int j = 1; j <= m; j++) dp[0][j] = j;//初始化，a字符串从0个字符至少要通过添加i个字符变成b字符串前i个字符（包括第i个），即a字符串从0扩充为b字符串需要操作i次。
    for (int i = 1; i <= n; i++)//开始dp
        for (int j = 1; j <= m; j++){
            if (a[i] == b[j])//如果a第i个字符与b字符串第j个字符相等
                dp[i][j] = dp[i - 1][j - 1];//那么在a前i - 1个字符串最少能通过dp[i - 1][j - 1]次操作转化为b前j - 1个字符串的基础上什么都不干，dp[i][j] 自然与 dp[i - 1][j - 1] 相等。
            else dp[i][j] = min(min(dp[i][j - 1], dp[i - 1][j]), dp[i- 1][j - 1]) + 1;
        }                                    // 复杂度：O(nm) 时间与空间
    printf("%d\n", dp[n][m]);
}
```

块三「错误写法对照」：

```diff
- if (a[i] == b[j]) dp[i][j] = dp[i-1][j-1] + 1;   // 坑1：相等也 +1——字符相同不需要操作，P2758 样例会直接算大（答案偏大）
+ if (a[i] == b[j]) dp[i][j] = dp[i-1][j-1];       // 相等：什么都不干（A 源 slide 4 情况 1）
- for (int i = 1; i <= n; i++) dp[i][0] = i;       // 坑2：漏掉 dp[0][j]=j 那一行——dp[1][1] 的三个候选里 dp[0][1] 读到 0，"空串变 B"被白送（答案偏小）
+ for (int i = 1; i <= n; i++) dp[i][0] = i;
+ for (int j = 1; j <= m; j++) dp[0][j] = j;       // 两条边界初始化缺一不可（A 源 slide 5）
- min(dp[i][j-1], dp[i-1][j]) + 1                  // 坑3：替换漏比——a[i]!=b[j] 时"改一个字符"常是最便宜的一步，漏掉会答案偏大
+ min(min(dp[i][j-1], dp[i-1][j]), dp[i-1][j-1]) + 1   // 三种决策取最小（A 源 slide 4 情况 2）
```

**⑤ 典型应用**

- 真题：P2758 编辑距离（洛谷，A 源 slide 4-5）——④全流程，实测官方样例 `sfdqxbw`/`gfdgw` 输出 4（附录 B-5）。
- 真题：力扣 72 编辑距离（题号真实）——同题英文面板，官方示例 `horse`/`ros` 答案 3、`intention`/`execution` 答案 5，可作自测数据。
- 迁移题：只有"插入与删除"两种操作（无替换）的最少步数（力扣 583 两个字符串的删除操作，题号真实）。建议先独立做，再对照题解：本质是 `n + m - 2 * LCS(A, B)`——保留公共部分，其余各删各的；也可直接二维 DP，转移去掉替换项。复杂度 $O(nm)$。标注：自编（题号真实）。

**⑥ 坑点与边界**

> **【易错】** 边界只初始化一半（④对照坑 2）：dp[i][0] 与 dp[0][j] 是"空串语义"的落地，缺任一条，转移的第一行/列全错。

> **【易错】** 相等分支误 +1（④对照坑 1）：`dp[i-1][j-1]` 与 `dp[i-1][j-1]+1` 一字之差，样例就过不了。

> **【注意】** 素材 P2758.cpp 的 dp 是全局数组（约 16MB），源自 LCS 篇的教训（A-3 登记 1）；n、m 上限 2000 时操作数不超过 max(n,m)=2000，int 存得下。

> [!example]-
> **边界数据集（先自己跑一遍，再展开对照）**
> 1. 空输入：A、B 均为空串 → n=m=0，双循环零次，dp[0][0]=0，输出 0（预期：不崩溃）。
> 2. 单字符：`a` / `b` → 不等，min(dp[1][0]=1, dp[0][1]=1, dp[0][0]=0)+1=1（替换），输出 1（预期）。
> 3. 全相同：`same` / `same` → 全程相等退左上，输出 0（预期：零操作）。
> 4. 严格递增：`abc` / `abcd` → 末尾插入 1 次，输出 1（预期：扩长只增 1）。
> 5. 严格递减：`dcba` / `a` → 删除 3 次，输出 3（预期：dp[4][1]=3）。
> 6. 极值：n=m=2000（素材数组 2005 贴线）→ 表约 16MB 须全局/static；答案上界 max(n,m)=2000，int 无溢出风险（预期：正常出解，防的是数组开小 RE）。

回扣开场：二维表 + 三种决策取最小，"最少操作数"从无从下手变成机械填表。现在你能解决 P2758 了——用的是③的三条转移与④的逐格追踪。最后一节把四道题的共性提炼成方法论。

### 6. DP 设计方法论：状态、转移、初始化、答案四步

前置依赖：[[#3. LIS 最长上升子序列（B3637）：一维 DP]]、[[#4. LCS 最长公共子序列（LCR095）：二维 DP]]、[[#5. 编辑距离（P2758）：二维 DP 决策取最小]]
后续衔接：背包（同批）、区间DP（同批，A 源 slide 5 预告 P4170）、树形DP / 状压DP（同批）

**① 它解决什么问题**

A 源 slide 1 给出五步：确定状态 → 确定转移方程 → 初始化 → 写转移代码 → 输出答案；B 源 p8 给出四步：判断是否 DP 问题 → 确定状态 → 建立转移方程 → 求状态表的值。两源步骤一一对应（对账见 A-3 登记 2），合并成本节的**四步法**：定义状态、推转移方程、安全初始化、读答案定遍历顺序。它解决的问题是"拿到一道新题，从哪里下手"——前三节的三道真题全部按这四步重放一遍，无一例外。复杂度账也在这里结：状态数 × 转移决策数就是总代价，四步法的第一步定状态时就该估出来。

**② 直觉理解**

模型级类比：**盖楼四问**。开工前依次回答：一层楼是什么（状态定义）？从下面哪几层、用什么结构接上来（转移方程）？地基打多深（初始化）？顶楼哪一间是交付房、电梯怎么层层往上（答案与遍历顺序）？四问问完，楼就能盖——跳过任何一问，盖到一半返工。

具体小数据推演（用 LIS 复盘，官方样例 `1 2 4 1 3 4`）：定义状态"以 i 结尾的最长上升子序列长度"（一层楼）→ dp[i] 从满足 a[j]<a[i] 的 dp[j]+1 接来（接楼方式）→ dp 全 1（地基：单元素自成一链）→ 答案 max(dp) 而非 dp[n]（交付房是全楼最大值，因为"以 i 结尾"的楼层每层都可能是冠军）。

**③ 原理与推导**

四步的推导与设计动机：

1. **定义状态**：A 源 slide 1 原话——"尝试用一句话来描述问题，其中涉及到的参数就是状态数组的下标"。LIS 的一句话是"以第 i 个元素结尾的 LIS 长"，参数只有 i，所以一维；LCS 的一句话是"两串前 i 位与前 j 位的 LCS"，参数 i、j，所以二维。**为什么状态定义必须"恰好充分"**：信息少了转移推不动（LIS 若定义成"前 i 个中的 LIS"就缺"结尾是谁"，无法判断 a[i] 能不能接上）；信息多了表开不下（给 LCS 加"用了哪些字符"维度就是 2^26）。
2. **推转移方程**：枚举"最后一步的决策"。LCS/LIS 枚举"接在谁后面"，编辑距离枚举"末字符是插入、删除还是替换"。**为什么从最后一步枚举**：最后一步把大局面拆成"更小局面 + 一个确定性动作"，正是最优子结构的工作方式。
3. **安全初始化**：初始化 = 依赖链的根 + 物理意义正确的值。dp[0][j]=j 是"空串变 B 要插 j 次"，不是"随便填个 0"。
4. **读答案定遍历顺序**：答案形态由状态定义决定——"以 i 结尾"要全表 max（LIS），"前 i 位对前 j 位"读 dp[n][m]（LCS/编辑距离）；遍历顺序由依赖方向决定（知识点 2③）。**为什么这步容易错**：定义与答案的对应关系在换题时会变，照抄上一题的答案行是高频事故。

**④ 代码演示**

块一「核心代码」：四步法骨架（自编，以编辑距离为示例填空）：

```cpp
// 第 1 步 定义状态：dp[i][j] = A[1..i] 变成 B[1..j] 的最少操作数
// 第 2 步 转移方程：相等退左上；不等 min(左, 上, 左上) + 1
// 第 3 步 安全初始化：dp[i][0]=i（全删），dp[0][j]=j（全插）
// 第 4 步 答案与顺序：读 dp[n][m]；依赖左/上/左上，故 i、j 均从小到大
int dp[2005][2005];                      // 复杂度：状态 O(nm) x 决策 O(1)
int editDistance(const char* A, const char* B) {
    int n = strlen(A + 1), m = strlen(B + 1);
    for (int i = 0; i <= n; i++) dp[i][0] = i;   // 第 3 步
    for (int j = 0; j <= m; j++) dp[0][j] = j;   // 第 3 步
    for (int i = 1; i <= n; i++)                 // 第 4 步：顺序
        for (int j = 1; j <= m; j++)
            dp[i][j] = (A[i] == B[j]) ? dp[i-1][j-1]
                     : min(min(dp[i][j-1], dp[i-1][j]), dp[i-1][j-1]) + 1;
    return dp[n][m];                     // 第 4 步：答案
}
```

块二「执行追踪表」（用四步法重放 LCS 的设计过程，逐格填值细节见知识点 4④）：

| 步骤 | 当前元素 | 结构状态 | 动作 | 结果 |
|:---:|:---:|:---|:---|:---|
| 1 | 第 1 步：定义状态 | 一句话"前 i 位对前 j 位" | 参数数出 i、j 两个 | dp[i][j] 二维表 |
| 2 | 第 2 步：推转移 | 相等/不等两种局面 | 从"末字符用不用"枚举决策 | 两条转移式 |
| 3 | 第 3 步：安全初始化 | 第 0 行/第 0 列 | 空串语义 = 0 | 地基就绪 |
| 4 | 第 4 步：答案与顺序 | 依赖左/上/左上 | i、j 从小到大；读 dp[n][m] | ans=dp[5][3]=3 |

块三「错误写法对照」（状态定义不充分导致转移断裂，LIS 的反面教材）：

```diff
- // 状态：dp[i] = 前 i 个元素中的 LIS 长度   （错误定义）
- // 转移：dp[i] = dp[i-1] + ???             ——a[i] 能不能接上取决于"前 i-1 个里的链以谁结尾"，状态里没存这个信息，转移推不出（卡死）
+ // 状态：dp[i] = 以 a[i] 结尾的 LIS 长度   （正确定义，知识点 3）
+ // 转移：dp[i] = max(dp[j]+1 | a[j]<a[i], j<i)，初始 dp[i]=1，答案 max(dp)
```

**⑤ 典型应用**

- 真题复盘：B3637 / LCR 095 / P2758 三题的四步重放（②③④已完成两题，LIS 见②）。
- 真题：力扣 53 最大子数组和（题号真实）——四步法自测题：一句话"以 i 结尾的最大子段和"，转移 `dp[i]=max(a[i], dp[i-1]+a[i])`（前面的和为负就另起炉灶），初始化 dp[1]=a[1]，答案全表 max。见⑥迁移题完整题解。
- 迁移题：力扣 53（同上题号）。建议先独立做，再对照题解：状态 `dp[i]` = 以 i 结尾的最大子段和；转移"要么续上前一段，要么自立门户"取较大者；初始化 dp[1]=a[1]；答案 max(dp[1..n])（不锚定结尾，与 LIS 同理）；复杂度 $O(n)$。手算 `{-2,1,-3,4,-1,2,1,-5,4}`：dp 依次 -2,1,-2,4,3,5,6,1,5，答案 6（子段 [4,-1,2,1]）。标注：自编（题号真实）。

**⑥ 坑点与边界**

> **【易错】** 状态定义偷懒缺维度（④对照）：LIS 不锚定"以 i 结尾"、LCS 不锚定"两串各到哪"，转移直接推不动。定义阶段的 5 分钟省不得。

> **【易错】** 初始化填 0 万能论：编辑距离的 dp[i][0]=i、dp[0][j]=j 有物理意义，写成 0 答案偏小；初始化的每个值都要能说出"它代表什么局面"。

> **【注意】** 答案形态跟着定义走：定义"以 i 结尾"读全表 max（LIS、最大子段和），定义"前 i 位对前 j 位"读 dp[n][m]（LCS、编辑距离）——换题先核对再抄答案行。

> [!example]-
> **边界数据集（先自己跑一遍，再展开对照；载体取⑤的最大子段和）**
> 1. 空输入：n=0 → 不适用：题面保证至少 1 个元素（dp[1] 无从定义）。
> 2. 单元素：{-3} → dp[1]=-3，答案 -3（预期：必须选一个元素，不能"什么都不选"得 0）。
> 3. 全相同：{-1,-1,-1} → 全表 -1，答案 -1（预期：与单元素同理）。
> 4. 严格递增：{-3,-2,-1} → dp=-3,-2,-1，答案 -1（预期：全负数组答案是最大单元素，不是 0）。
> 5. 严格递减：{-1,-2,-3} → dp=-1,-1,-3（dp[2]=max(-2, -1-2)=-1，dp[3]=max(-3, -1-3)=-3），答案 -1（预期：另起炉灶优于硬续）。
> 6. 极值：10^5 个 10^9 → 子段和达 10^14，int 必溢出（预期：dp 与答案均 long long，专查溢出）。

回扣开场：B3637 的暴力 $2^n$、fib(40) 的 3.31 亿次调用，都倒在同一个根源——重复子问题。四步法把"定状态、推转移、初始化、读答案"变成可复用的检查流程，现在你能解决开场那个问题，也能用同一套流程去啃背包（同批）、区间DP（同批）的新题了。

## 三、全篇坑点总表

| # | 坑 | 正解 |
|---|-----|------|
| 1 | 计数/求和类 DP 用 int | 默认 long long（fib(47) 已超 int） |
| 2 | base case 漏填 | 最底层格子必须显式初始化 |
| 3 | 备忘录用 0 当"没算过"标记 | 用值域外的 NIL=-1（B 源做法） |
| 4 | 递推方向与依赖方向相反 | 依赖谁先填谁，循环方向无自由度 |
| 5 | LIS 条件写成 >= | 题意"上升"是严格 <，相等不接 |
| 6 | LIS 初始化为 0 / 答案读 dp[n] | 初始 dp=1，答案全表 max |
| 7 | LCS else 分支误 +1 | 不匹配只能继承不能增长 |
| 8 | 漏初始化第 0 行/列 | 空串语义是转移的地基 |
| 9 | 大 dp 数组放函数局部 | 4MB 超默认 1MB 栈，用 static/全局（实测栈溢出） |
| 10 | 编辑距离相等分支 +1 | 相等时零操作，直接退左上 |
| 11 | 状态定义不充分缺维度 | 一句话描述法，参数=下标，信息恰好充分 |

## 四、总结与自测

### 核心内容（一页纸速览）

- **DP 是什么**：最优子结构 + 重叠子问题（+ 无后效性，补充）三性质；每个子问题只算一次存进表；复杂度 = 状态数 × 决策数（A 源 slide 1 / B 源引论）。
- **记忆化 vs 递推**：同一转移式的两条路线——自顶向下查表（NIL 标记）与自底向上按序填表；遍历顺序由依赖方向决定（B 源 p8-12）。
- **LIS（B3637）**：dp[i] = 以 i 结尾的最长上升子序列长度；dp[i]=max(dp[j]+1 | a[j]<a[i])，初始 1，答案全表 max；O(n^2)，O(n log n) 贪+二分为补充。
- **LCS（LCR095）**：dp[i][j] = 两串前 i 位与前 j 位的公共子序列长度；相等退左上 +1，不等取右/下继承；O(nm)。
- **编辑距离（P2758）**：dp[i][j] = A 前 i 位变 B 前 j 位的最少操作；相等退左上，不等 min(插, 删, 改)+1；dp[i][0]=i、dp[0][j]=j；O(nm)。
- **四步法**：一句话定义状态（参数=下标）→ 枚举最后一步推转移 → 有物理意义的初始化 → 答案形态随定义、遍历顺序随依赖。
