## 一、为什么需要它

先用你大概率碰过壁的方式做一遍 P3375【模板】字符串匹配（A 源 slide 2 给出题号）：主串 $n \le 10^6$、模式串 $m \le 10^6$，问模式串在主串的所有出现位置。暴力做法是拿模式串对齐主串每个起点逐字符比对，最坏每次都比到最后一位才失败——$O(nm)$，$10^6 \times 10^6 = 10^{12}$ 次比较，必超时。构造一个必死场景：主串是 $10^6$ 个 `A`，模式串是 `AAAAB`——每个起点都要比对 5 次才失败，全程约 $5 \times 10^6$ 次还算侥幸；把模式串换成 `AAAA...AB`（长 $10^6$），每个起点几乎比满 $m$ 位，$10^{12}$ 次比较直接爆炸。**碰壁的根源：主串指针 i 每次失配都回头重走（B 源 p2 原话："一旦出现失配时，主串的扫描指针 i 经常回溯"）。**

KMP 的破法一句话：**失配时主串指针 i 永不回退，只把模式串指针 j 挪到"还能接得上"的位置**——这个位置预先算好存在 next 数组里。预处理的代价是 $O(m)$，匹配全程 $O(n)$，总账 $O(n+m)$。

本篇讲 5 个知识点：暴力困境、next 数组、匹配主过程、P3375 实战、周期应用 P4391。顺序理由：痛点（知识点 1）先于工具（知识点 2），工具先于组装（知识点 3、4），最后看变体（知识点 5）。

## 二、知识点逐讲（每个知识点一节，共 5 节）

### 1. 字符串匹配与暴力困境

前置依赖：[[枚举与模拟]]（枚举起点逐位验证的思想）、C 数组与字符串基础（char 数组、strlen）
后续衔接：[[#2. 前缀函数 next 数组：最长相等前后缀与不失配位置]]、[[#3. KMP 匹配主过程：主串指针不回溯]]

**① 它解决什么问题**

字符串模式匹配（B 源 p1 定义）：在主串中找到与模式串相同的子串，并返回其所在位置。它是本篇全部内容的问题底座：P3375 要所有位置，P4391 要周期，KMP.c 要首个位置（B 源 KMP.c 的 main 就是一个"找首个匹配位置"的完整程序）。性质总账：暴力匹配实现最简（10 行内），单次最坏 $O(nm)$；KMP 预处理 $O(m)$、匹配 $O(n)$。

**② 直觉理解**

模型级类比：**拉链对齿**。模式串是拉链的一排齿，主串是另一排齿；对齐某个起点后从第一齿往下对，对不上就整体右移一格、从第一齿重新对。暴力就是这个动作——每换一个起点，之前对过的齿全部作废重来。

用具体数字跑一遍（B 源 p2 的例子）：模式串 `abcabd`，主串 `abcabxxxx`。从主串下标 0 对齐：`abcab` 五位全对，第 6 位 `d` 对 `x` 失配。暴力把起点挪到 1，从 `bcabx` 重新比——但主串前 5 位我们已经知道是 `abcab`，起点 1 对齐意味着模式串的 `abcabd` 要对上 `bcabx`，第 1 位 `a` 对 `b` 就错。起点 2、3 同理一眼死。**只有起点 3 有戏**（主串的 `ab` 接着模式串的 `abcab` 后缀）。暴力把这些"一眼死"的起点也各比了一场。

**③ 原理与推导**

暴力匹配的结构（B 源 p2）：对每个起点 $k \in [0, n-m]$，逐字符比 `p[k+j]` 与 `s[j]`，全对则成功，任一位错则换下一个起点。最坏复杂度推导：主串 `AAAA...A`、模式串 `AAAAB` 时每个起点比满 $m$ 位才失败，共 $(n-m+1) \cdot m$ 次比较，即 $O(nm)$。

关键观察（B 源 p2，KMP 思想的种子）："不匹配的字符之前，一定是和模式串一致的"——失配发生在第 $j$ 位时，主串窗口里的前 $j$ 位就是模式串的前 $j$ 位，**这是已经花钱买到、却不该扔掉的信息**。暴力每换起点就把这 $j$ 位信息全扔了。为什么 KMP 能不扔？因为"窗口里是什么"只由模式串自己决定，模式串对自己的前缀了如指掌——这正是知识点 2 的 next 数组。

**④ 代码演示**

取自源文件 KMP.c（B 源；改动：将注释块中的暴力版本展开为独立函数并加返回类型说明，逻辑逐行原样）：

```c
// 暴力匹配：返回 s 在 p 中首个出现位置（0-based），无则 -1
// 复杂度：最坏 O(n*m)，n、m 为主串与模式串长度
int brute(char* p, char* s) {
    int pl = strlen(p), sl = strlen(s);
    if (pl < sl) return -1;               // 边界：模式串比主串长，必不匹配
    for (int k = 0; k <= pl - sl; k++) {  // 枚举起点 k
        int i = k, j = 0;                 // p[k] 和 s[0] 对齐
        while (j < sl) {
            if (p[i] == s[j]) { i++; j++; }   // 当前位对上，双双前进
            else break;                       // 失配：本轮作废，换起点
        }
        if (j == sl) return k;            // 模式串走完：k 是匹配位置
    }
    return -1;
}
```

**执行追踪表**（p=`abcabxxxx`，s=`abcabd`，失配在第 6 位）：

| 步骤 | 当前元素 | 结构状态 | 动作 | 结果 |
|:---:|:---:|:---|:---|:---|
| 1 | 起点 k=0 | i=0, j=0 | 逐位比 abcab 五位全对 | j=5 |
| 2 | p[5]=x | i=5, j=5 | s[5]=d 失配，本轮作废 | 换起点 k=1 |
| 3 | 起点 k=1 | i=1, j=0 | s[0]=a 对 p[1]=b，第 1 位即错 | 换起点 k=2 |
| 4 | 起点 k=2 | i=2, j=0 | s[0]=a 对 p[2]=c，第 1 位即错 | 换起点 k=3 |
| 5 | 起点 k=3 | i=3, j=0 | 从头比 abcab…… | 已浪费 2+5 次比较 |

**错误写法对照**：

```diff
- for (int k = 0; k < pl - sl; k++)   // 坑1：边界漏等号，最后一个起点 k = pl-sl 被跳过，模式串贴着主串末尾的匹配漏报（答案错）
+ for (int k = 0; k <= pl - sl; k++)   // 起点区间是闭区间 [0, pl-sl]
- while (j < sl) { if (p[i++] == s[j++]) ... }   // 坑2：失配时 i 已自增越过窗口，起点与指针状态混乱（答案错）
+ if (p[i] == s[j]) { i++; j++; } else break;   // 对上才前进，失配本轮立刻终止
```

**⑤ 典型应用**

- 真题：洛谷 P3375【模板】字符串匹配（A 源 slide 2，链接 https://www.luogu.com.cn/problem/P3375 ）。$n \le 10^6$，暴力 $O(nm)$ 最坏 $10^{12}$ 次比较超时，它是本篇碰壁题，也是知识点 4 的正解对象。
- 真题：B 源 KMP.c 的同构练习（读两个串，输出首个匹配位置，样例 `abeababeabf` / `abeabf`）——与暴力版同一 main，只是内核换 KMP。
- 迁移题：统计模式串在主串中的出现次数。数据范围 $n, m \le 10^5$；暴力 $O(nm)$ 最坏 $10^{10}$ 超时。输入输出：两行字符串，输出一个整数。思路：每个起点验证成功计数加一。标注：自编，用于体会"多起点全验证"的代价。

**⑥ 坑点与边界**

> **【易错】** 起点循环上界写成 `k < pl - sl`。最后一个起点被跳过，贴尾匹配漏报，见④对照坑 1。

> **【注意】** 空模式串的语义约定：暴力里 `sl == 0` 时 `while` 直接过、`j == sl` 成立，返回起点 0——"空串匹配任何位置"。竞赛题面通常保证串非空，但自定义测试要想到这一层（本篇模板代码 scanf 读不到空串，见知识点 4 边界数据集）。

> [!example]-
> **边界数据集（先自己跑一遍，再展开对照）**
> 1. 空输入：主串空或模式串空 → scanf 读不到空串，素材模板不适用此形态；逻辑上空模式串约定为在位置 0 匹配（预期：约定先于代码）。
> 2. 单元素：p=`a`，s=`a` → 起点 0 一位命中，输出 0（预期：0）。
> 3. 全相同：p=`AAAAA`，s=`AAAAB` → 每个起点比满 4 位才失败，共 (5-4+1)*4=8 次比较，无匹配输出 -1（预期：-1；这就是暴力最坏形态的微缩版）。
> 4. 严格递增：p=`abcde`，s=`cde` → 起点 2 命中（预期：2）。
> 5. 严格递减：p=`edcba`，s=`dc` → 无匹配（预期：-1）。
> 6. 极值：$n=m=10^6$ 且全 `A` 对 `A...AB` → 约 $10^{12}$ 次比较，1 秒时限必超（预期：TLE，即"为什么需要 KMP"的量级证据）。

回扣开场：暴力把钱浪费在"每个起点从零重比"上。现在你能说清它慢在哪一步——下一步就是把扔掉的信息捡回来。

### 2. 前缀函数 next 数组：最长相等前后缀与不失配位置

前置依赖：[[#1. 字符串匹配与暴力困境]]（失配时窗口内容 = 模式串前缀的观察）
后续衔接：[[#3. KMP 匹配主过程：主串指针不回溯]]、[[#5. 应用与周期 P4391：L - net[L]]]；字符串哈希是匹配的另一条路线（同批笔记，待产出，先文字锚定）

**① 它解决什么问题**

next 数组（本篇代码统一叫 net，原因见④坑 1）是"失配后模式串指针回退到哪"的备忘录。A 源 slide 1 定义（0 下标存串）：`next[j] = x`，令 `a = s[0..j-1]`，则 **x 是 a 的最长相同前后缀的长度**——"相同前后缀"指存在长度为 x 的真前缀与真后缀逐字符相等；当 s[j] 与主串失配时，j 应回退到 x（即 s[x])继续匹配。B 源 p3 从另一侧定义：当第 j 位失配，已匹配段 S = 前 j-1 个字符，回退位置由 S 的最长相等前后缀决定（B 源是 1 下标口径，数值差 1，见 A-3 登记 1）。性质：net 只跟模式串有关（B 源 p2："模式串前面已经成功匹配的字符，就表示子串中已经包含了这些字符"）；预处理 $O(m)$；复杂度字样记账：求 net 的均摊复杂度 $O(m)$，论证同知识点 3 的 j 单调性。

**② 直觉理解**

模型级类比：**拉链的可复用咬合段**。已咬合的 j 个齿里，若开头 net[j] 个齿的图案与结尾 net[j] 个齿完全相同，那么拉链滑到"让开头那段对准刚才结尾那段"的新位置时，这 net[j] 个齿**自动咬合**，不用重对——失配重对时，可复用段越长，浪费越少，所以取"最长"。

用具体数字跑一遍（A 源 slide 1 的手算例子 `abeabf`）：整串的最长相等前后缀——前缀 `abeab` 与后缀……逐位看：长度 1：`a` 对 `f` 错；长度 2：`ab` 对 `bf` 错；……整串没有相等前后缀。但前 5 位 `abeab` 有：前缀 `ab` = 后缀 `ab`，长度 2。所以 net[5] = 2——第 5 位（0 下标）失配时 j 退到 2，前 2 位 `ab` 自动接上。

**③ 原理与推导**

先回答设计动机：**为什么"最长"相等前后缀蕴含"不失配位置"？** 设失配发生在模式串下标 j，此时主串窗口中 `s[0..j-1]` 已逐位匹配。令 `net[j] = x`，按定义有

$$s[0..x-1] = s[j-x..j-1]$$

右边那段 `s[j-x..j-1]` 是窗口的**尾部**，它已经和主串对应段匹配成功；而左边那段恰好是模式串的**头部**。把模式串整体右移 $j - x$ 格，头部 `s[0..x-1]` 正好落在刚才尾部占过的主串段上——**这 x 位不需要重新比较，比较直接从 s[x] 与原失配位继续**。取"最长"是因为：若存在更短的相等前后缀 x' < x，跳到 x' 会跳过 x'..x-1 这些**本可以不比**的位置，漏掉中间可能存在的匹配起点；最长 x 保证所有"窗口内可能成功的起点"一个不漏地按从左到右顺序被检查。真前后缀（不含整个串）保证 x < j，j 严格下降，回退必终止。

递推求 net（A 源 slide 1-2 的动态规划思路）：算 net[i] 时 net[0..i-1] 已知，设 y = net[i-1]，含义是 `s[0..y-1] = s[i-1-y..i-1]`。若 `s[y] == s[i-1]`，前后缀各延长一位，`net[i] = y + 1`；否则"y 位置失配"，令 y = net[y] 换次长候选再试——**即 s 自己匹配自己**（A 源 slide 2 原话），一直退到 y = -1（无候选）为止。

文本图（`abeabf`，求 net[5] 的候选链）：

```text
s = a b e a b f
    0 1 2 3 4 5
net[4]=1：s[0..0]="a" = s[3..3]="a"
候选 y=1：s[1]='b' vs s[4]='b' 相等 → net[5]=2   （"ab" = "ab"）
若不等则 y=net[1]=0 → 试 s[0]='a'；再不等则 y=net[0]=-1 → net[5]=0
```

**④ 代码演示**

取自源文件 KMP.c（B 源，改动：仅去掉 malloc 改为传入数组参数以便复用，逻辑逐行原样；KMP模板.cpp 与 P3375.cpp 内含同款循环）：

```c
// 求net：0 下标口径，net[0]=-1 是哨兵，net[i] = s[0..i-1] 的最长相等真前后缀长度
// 复杂度：均摊 O(m)，m 为模式串长度
void GetNext(char* sub, int* net, int lenSub) {
    net[0] = -1;
    int j = 0;              // 当前下标
    int k = -1;             // 前一项回退到的候选下标（即 net[j]）
    while (j + 1 < lenSub) {
        if (k == -1 || sub[j] == sub[k]) {  // k 越界（无候选）或对上：长度 +1
            j++;
            net[j] = k + 1; // 对上时前后缀各延长一位
            k++;
        }
        else {
            k = net[k];     // 失配：换次长候选，s 自己匹配自己
        }
    }
}
```

**执行追踪表**（s=`abeabf`，lenSub=6，全程逐行；net 最终 = [-1, 0, 0, 0, 1, 2, 0]）：

| 步骤 | 当前元素 | 结构状态 | 动作 | 结果 |
|:---:|:---:|:---|:---|:---|
| 1 | j=1, k=0 | net=[-1,0,...] | s[1]=b 对 s[0]=a 失配 | k=net[0]=-1 |
| 2 | j=1, k=-1 | 同上 | k 越界分支：j=2, net[2]=0, k=0 | net[2]=0 |
| 3 | j=2, k=0 | net=[-1,0,0,...] | s[2]=e 对 s[0]=a 失配 | k=net[0]=-1 |
| 4 | j=2, k=-1 | 同上 | j=3, net[3]=0, k=0 | net[3]=0 |
| 5 | j=3, k=0 | net=[-1,0,0,0,...] | s[3]=a 对 s[0]=a 对上 | net[4]=1, k=1 |
| 6 | j=4, k=1 | 同上 | s[4]=b 对 s[1]=b 对上 | net[5]=2, k=2 |
| 7 | j=5, k=2 | net[5]=2 | s[5]=f 对 s[2]=e 失配 | k=net[2]=0 |
| 8 | j=5, k=0 | 同上 | s[5]=f 对 s[0]=a 失配 | k=net[0]=-1 |
| 9 | j=5, k=-1 | 同上 | j=6, net[6]=0, k=0；j+1=7>6 退出 | 求解完成 |

+ net[j] = k + 1;   // 对上后前后缀长度是旧候选 k 加上新对上的一位
- while (j < lenSub)   // 坑2：循环条件少 +1，net[lenSub] 求不出来——P4391 恰恰要用 net[n]（答案错，周期题 WA）

**⑥ 坑点与边界**

> **【易错】** 对上分支写 `net[j] = k` 漏加一。net 整体缩一位，回退位置系统性偏短，匹配漏解，见④对照坑 1。

> [!example]-
> **边界数据集（先自己跑一遍，再展开对照）**

回扣开场：现在你有了"失配后模式串该退到哪"的完整备忘录——它为什么对（前后缀对齐自动接上）、为什么取最长（不漏起点）都说清了。接下来把备忘录接进主匹配循环。

### 3. KMP 匹配主过程：主串指针不回溯

前置依赖：[[#2. 前缀函数 next 数组：最长相等前后缀与不失配位置]]（net 的语义与求法）
后续衔接：[[#4. 模板题 P3375 实战：全部匹配位置与 net 输出]]、[[搜索优化]]（同为"不重走回头路"的剪枝思想）

**① 它解决什么问题**

KMP 匹配主过程（B 源 p2 命名，由 D.E.Knuth、J.H.Morris 和 V.R.Pratt 提出）：i 扫主串**只前进不回退**，失配时只把 j 退到 net[j] 继续比。解决的就是知识点 1 的暴力困境：$O(nm)$ 压到 $O(n+m)$。性质：需要预处理 net（$O(m)$）；匹配均摊 $O(n)$；返回所有匹配位置时逐个报告（知识点 4）。

**② 直觉理解**

模型级类比：**磁带播放头与可倒带歌词单**。检查员（主串指针 i）像磁带播放头，只许往前走，绝不倒带；对歌词的人（模式串指针 j）手里有一张"卡壳对照表"（net），每次跟丢了就按表退到"还能接上唱"的那句，而不是从歌名重新开始。磁带走完，歌词最长对上一整遍，就是一次匹配。

用具体数字跑一遍（素材样例，KMP.c 注释与 KMP模板.cpp 文件尾同款数据）：主串 `abeababeabf`、模式串 `abeabf`。i 走到 5、j 走到 5 时 `a` 对 `f` 失配——j 退到 net[5]=2（`ab` 自动接上），再退到 0，然后 `a` 接上继续，一路走到 j=6=模式串长，匹配位置 i-j=5（0 下标）。**全程 i 没有回过头**：失配两次，i 一直停在 5 等模式串换姿势。

**③ 原理与推导**

主循环只有两条腿（B 源 p2 KMP 思想）："i 与 j 对上就双双前进；失配时 j = net[j]"。为什么 j 退到 net[j] 是安全的——知识点 2③ 已推导：窗口尾部与模式串头部的相等前后缀自动接上。这里补回答第二个设计动机：**为什么总复杂度是 $O(n)$ 而不是 $O(nm)$？** 看 j 的账本：j 每次"对上"加 1，全程 i 只前进不回退，所以 j 的总增加量至多 n；而每次"失配回退"都让 j 严格变小（真前后缀保证 net[j] < j），j 又不能变成负数以下（net[0]=-1 是地板，j=-1 时强制双双前进）——**回退总量不超过增加总量**，故回退总次数 $O(n)$，加上 i 的 n 步，全程 $O(n)$。求 net 时 k 的账本完全同构：总增加 m，总回退不超过 m，均摊 $O(m)$。

匹配成功后想找"下一处"：令 j = net[n]（而不是清零）——已匹配整段的尾部还能接上头部的部分继续用，与失配回退同一逻辑（素材 P4391.cpp 匹配循环内 `j == n` 分支正是这么写的）。

**④ 代码演示**

取自源文件 KMP.c（B 源，改动：把 malloc 换成传入数组、合并为可复用函数形态，逻辑逐行原样）：

```c
// KMP 匹配：返回 s 在 p 中首个出现位置（0 下标），无则 -1
// 复杂度：预处理 O(m) + 匹配均摊 O(n)
int kmp(char* p, char* s, int* net) {
    int lp = strlen(p), n = strlen(s);
    if (lp == 0 || n == 0) return -1;    // 边界：空串不匹配（素材原判断）
    GetNext(s, net, n);                  // 预处理备忘录
    int i = 0, j = 0;
    while (i < lp && j < n) {
        if (j == -1 || p[i] == s[j]) {   // j==-1：退无可退，强制前进一格重新对齐
            i++; j++;
        }
        else {
            j = net[j];                  // 失配：i 不动，j 按表回退
        }
    }
    if (j >= n) return i - j;            // 模式串走完：起点 = i - j
    return -1;
}
```

**执行追踪表**（p=`abeababeabf`，s=`abeabf`，net=[-1,0,0,0,1,2,0]；这是全篇最能看见算法灵魂的一张表——盯住 i 列，它在失配时永远不动）：

| 步骤 | 当前元素 | 结构状态 | 动作 | 结果 |
|:---:|:---:|:---|:---|:---|
| 1 | i=0, j=0 | 对上 a | i=1, j=1 | 前进 |
| 2 | i=1..4, j=1..4 | 对上 beab | 逐位前进 | i=5, j=5 |
| 3 | i=5, j=5 | p[5]=a 对 s[5]=f **失配** | j=net[5]=2 | i 不动 |
| 4 | i=5, j=2 | p[5]=a 对 s[2]=e 失配 | j=net[2]=0 | i 不动 |
| 5 | i=5, j=0 | p[5]=a 对 s[0]=a 对上 | i=6, j=1 | `ab` 已自动接上 |
| 6 | i=6..9, j=1..4 | 对上 beab | 逐位前进 | i=10, j=5 |
| 7 | i=10, j=5 | p[10]=f 对 s[5]=f 对上 | i=11, j=6 | j=n=6，匹配 |
| 8 | 结束 | j=6 | 起点 = i-j = 5 | 输出 5（0 下标） |

**错误写法对照**：

```diff
- else { i++; j = net[j]; }   // 坑1：失配时也推进 i——主串指针回不了头也停不下，跳过的窗口里可能藏着匹配（答案错/漏解）
+ else { j = net[j]; }         // 素材原样：失配只动 j
- if (j >= n) return i - j + 1;   // 坑2：0 下标函数返回 1 下标位置——调用方口径混乱，差一错误（答案错）
+ return i - j;               // 0 下标口径返回 i-j；1 下标口径才是 i-j+1（P3375 用后者，见知识点 4）
- else { j = 0; }             // 坑3：失配退回 0（退化为暴力）——功能对但复杂度回到 O(n*m)（TLE）
+ else { j = net[j]; }        // 回退到"还能接上"的位置，这正是 KMP 的全部意义
```

**⑤ 典型应用**

- 真题：P3375（知识点 4 全流程实战）——$10^6$ 规模下 $O(n+m)$ 轻松通过。
- 真题：B 源 KMP.c 的"首个匹配位置"题（素材自带样例，答案 5）——kmp 函数原样可用。
- 迁移题：判断 s2 是否为 s1 的子串，是则输出首次位置否则输出 -1。数据范围 $|s1|, |s2| \le 10^6$；思路与 kmp 函数完全一致，只改读入与输出。建议先独立做，再对照题解：题解即④代码，把 main 换成读两个串、调 kmp、输出返回值。出处：B 源 KMP.c 原题形态。

**⑥ 坑点与边界**

> **【易错】** 失配分支顺手写 `i++`。主串指针一退一进，窗口滑动语义被破坏，漏解，见④对照坑 1。

> **【易错】** 位置口径混用：0 下标函数返回 i-j，题面要 1 下标时输出 i-j+1。P3375 要 1 下标，KMP.c 是 0 下标，差一就 WA，见④对照坑 2。

> **【注意】** j==-1 的分支不能删：j 退到 -1 说明模式串开头都对不上当前主串位，此时必须 i 前进、j 归 0 重新对齐；删掉分支 j=-1 时访问 s[-1] 越界（RE）。

> [!example]-
> **边界数据集（先自己跑一遍，再展开对照）**
> 1. 空输入：模式串空（n=0）→ 素材判断直接返回 -1（预期：-1；空串语义由题面约定，模板按非空设计）。

> 3. 全相同：p=`aaaa`，s=`aa` → 位置 0、1、2 三处全中；断言程序实测 {0,1,2}（预期：全位置命中，报告逻辑见知识点 4）。
> 4. 严格递增：p=`abcde`，s=`cde` → i=2 起对上，返回 2（预期：2；失配直接退到 -1 重新对齐，无中间回退）。
> 5. 严格递减：p=`edcba`，s=`cde` → 无匹配（预期：-1）。
> 6. 极值：n=10^6 全 `A` 主串找 `A`×999999 → j 沿 net 一路递增不回退，$O(n)$；数组开 1000005 防越界（预期：位置 0，瞬间完成）。

回扣开场：主串指针不回溯 + 按表回退，$O(nm)$ 的账本被改写成 $O(n+m)$。现在你能解释开场那个"必死场景"为什么活了——用知识点 2 的表与知识点 3 的单调性论证。下一节把两段代码按题面组装。

### 4. 模板题 P3375 实战：全部匹配位置与 net 输出

前置依赖：[[#2. 前缀函数 next 数组：最长相等前后缀与不失位位置]]、[[#3. KMP 匹配主过程：主串指针不回溯]]
后续衔接：[[#5. 应用与周期 P4391：L - net[L]]]；字符串哈希（待产出，文字锚定）是"先算指纹再比对"的另一条匹配路线

**① 它解决什么问题**

洛谷 P3375【模板】字符串匹配（A 源 slide 2"思路：模板题"）：给定主串 A（长 n）与模式串 B（长 m），输出 B 在 A 中**所有**出现位置（1 下标，每行一个），最后一行输出 net 口径数组 net[1..m]。数据 $1 \le n \le 10^6$，$m \le n$。它把知识点 2、3 的两段代码组装成完整提交：预处理 net → 扫描主串 → 每次命中报告位置 → j=net[n] 续找 → 末尾打印 net。复杂度总账 $O(n+m)$。

**② 直觉理解**

模型级类比：**质检流水线**。net 预处理是给工件（模式串）贴上"卡壳对照表"标签（第一工位）；主扫描是传送带（第二工位），每卡一次按标签快调；每合格一次就打一个位置钢印（报告），并且**不停线**——按表快调后继续找下一个合格品（j=net[n]），直到传送带走完（第三工位出 net 清单）。

用具体数字跑一遍（官方样例）：A=`ABABABC`，B=`ABA`。匹配位置 1、3（1 下标）；net[1..3] = 0 0 1。断言程序复刻素材算法实测一致（附录 B-5）。

**③ 原理与推导**

两处口径推导要过一遍，这是本题最容易翻车的暗礁。其一，**位置口径**：素材匹配循环里 `j == n` 时输出 `i - n + 1`——i、j 都是 0 下标，命中时窗口起点是 i-n，题面要 1 下标，所以 +1。其二，**net 输出口径**：题面要求"子串 B[1..i] 的最长相等真前后缀长度"。本篇 net[i] = border(s[0..i-1])（0 下标前 i 个字符的最长相等真前后缀），而 s[0..i-1] 恰是 1 下标的 B[1..i]——**两个口径在数值上完全重合**，net[0]=-1 哨兵不输出即可（输出从 i=1 开始）。为什么素材能把"失配回退表"直接当答案输出：因为"失配在下一位 i 时退到 net[i]"与"B[1..i] 的 border 长度"本就是同一个量的两种说法（知识点 2① 的双重身份）。

**④ 代码演示**

取自源文件 P4391.cpp（注意：该文件名与内容交叉，内容实为 P3375 解法，见 A-3 登记 2。改动：删去 getchar 与文件尾注释、printf 的 `\n` 并为紧凑输出，主逻辑逐行原样）：

```c
#include <stdio.h>
#include <string.h>
// KMP 模板：输出所有匹配位置(1 下标)与 net 数组；复杂度 O(n+m)
int net[1000005];
char p[1000005];   // 主串
char s[1000005];   // 模式串
int main()
{
    scanf("%s", p);
    scanf("%s", s);
    int n = strlen(s);
    // 求 net 数组：与知识点 2 同款
    net[0] = -1;
    net[1] = 0;
    int k = 0, j = 1;
    while (j + 1 <= n) {
        if (k == -1 || s[j] == s[k]) { net[j+1] = k+1; k++; j++; }
        else k = net[k];
    }
    // 匹配：j==n 报告位置并按表续找
    int lp = strlen(p);
    int i = 0; j = 0;
    while (i < lp) {
        if (j == -1 || p[i] == s[j]) { i++; j++; }
        else j = net[j];
        if (j == n) {
            printf("%d\n", i - n + 1);   // 1 下标位置
            j = net[n];                  // 不清零：尾部接头部，续找下一处
        }
    }
    for (i = 1; i <= n; i++) printf("%d ", net[i]);   // net[1..n]，口径推导见③
    return 0;
}
```

**执行追踪表**（官方样例 A=`ABABABC`，B=`ABA`，net=[-1,0,0,1]；net 求解段已在知识点 2 演练过，这里只追匹配段）：

| 步骤 | 当前元素 | 结构状态 | 动作 | 结果 |
|:---:|:---:|:---|:---|:---|
| 1 | i=0..2, j=0..2 | ABA 三位全对上 | 前进三次 | i=3, j=3=n |
| 2 | j==n | 命中 | 输出 i-n+1=1；j=net[3]=1 | 报位置 1 |
| 3 | i=3, j=1 | p[3]=B 对 s[1]=B 对上 | i=4, j=2 | 续扫 |
| 4 | i=4, j=2 | p[4]=A 对 s[2]=A 对上 | i=5, j=3=n | 再命中 |
| 5 | j==n | 命中 | 输出 i-n+1=3；j=net[3]=1 | 报位置 3 |
| 6 | i=5, j=1 | p[5]=B 对 s[1]=B 对上 | i=6, j=2 | 续扫 |
| 7 | i=6, j=2 | p[6]=C 对 s[2]=A 失配 | j=net[2]=0 | i 不动 |
| 8 | i=6, j=0 | C 对 A 失配 | j=net[0]=-1 → i=7, j=0 | i 出界结束 |
| 9 | 收尾 | — | 输出 net[1..3] | 0 0 1 |

+ if (j == n) { printf("%d\n", i - n + 1); j = net[n]; }   // 素材原样：按表续找，均摊 O(n) 保住

**⑤ 典型应用**

- 真题：P3375 本题。官方样例实测输出 `1` `3` `0 0 1`（附录 B-5 断言一致）。
- 真题：B 源 KMP.c 同构题（首个位置版）——把"报所有位置"改成"报第一个后停"，④代码删掉续找分支即得。

**⑥ 坑点与边界**

> **【易错】** 命中后 `j = 0` 清零。全相同字符（主串全 A、模式串 AAA）时每次命中重扫整段，最坏 $O(nm)$ 退回暴力，见④对照坑 1；正确做法 j=net[n]。

> **【易错】** net 输出从下标 0 开始。哨兵 -1 混入答案且漏掉 net[n]，双重错，见④对照坑 2。

> **【注意】** 题面样例的输入顺序是"先主串后模式串"，素材代码 scanf 顺序 p 在前 s 在后——读反了样例对不上还以为算法错，先对输入顺序再怀疑算法。

> [!example]-
> **边界数据集（先自己跑一遍，再展开对照）**
> 1. 空输入：竞赛保证两串非空（n>=1）；scanf 读不到空串，空模式串不在本题定义域（预期：不测空串，约定见知识点 1）。
> 2. 单元素：A=`a`，B=`a` → 位置 1；net[1]=0，输出 `1` 与 `0`（预期：1 / 0）。
> 3. 全相同：A=`aaaa`，B=`aa` → 位置 1、2、3；net[1..2]=`0 1`（预期：3 个位置 + `0 1`；命中续找分支在此压力最大）。
> 4. 严格递增：A=`abcdeabcde`，B=`cde` → 位置 3、8；net 全 0（预期：两报一表）。
> 5. 严格递减：A=`edcba`，B=`ba` → 位置 4；net 全 0（预期：4 / 0 0）。
> 6. 极值：n=m=10^6，A 全 `A`，B=`A`×(10^6-1)+`B` → 一次都不命中，匹配 i 一路走完 $O(n)$；数组 1000005 开满（预期：无位置输出 + 一行 net，不 TLE 不 RE）。

回扣开场：暴力 $10^{12}$ 的死局，被"贴标签（net）+ 不回头（i）+ 按表续找（j=net[n]）"拆成 $O(n+m)$。现在你能解决开场那个 P3375 了——用的是知识点 2 的求表（步骤前段）与知识点 3 的主循环（追踪表全部步骤）。

### 5. 应用与周期 P4391：L - net[L]

前置依赖：[[#2. 前缀函数 next 数组：最长相等前后缀与不失位位置]]（net 的 border 身份）、[[#3. KMP 匹配主过程：主串指针不回溯]]
后续衔接：扩展 KMP/Z 函数、AC 自动机（待产出，文字锚定）；A 源 slide 3 预告下一块内容为动态规划（对应批次笔记待产出，文字锚定）

**① 它解决什么问题**

洛谷 P4391 无线传输（A 源 slide 2-3）：已知串 s（长 L）是由某个字符串 ss **无限循环**拼接得到的前缀，求最短 ss 的长度。样例：L=8，s=`cabcabca`，答案 3（周期 `cab`，`cabcabca` 是 `cabcabcab` 去掉尾字符——A 源 slide 2 原话的理解方式）。结论（A 源 slide 3）：**答案 = L - net[L]**。复杂度 $O(L)$，一次求 net 加一次减法。

**② 直觉理解**

模型级类比：**印章盖条**。长条是同一枚印章（周期串）不断盖出来的；印章每重复一次，串身就多出一段与开头相同的"影子"。最长相等前后缀 net[L] 量到的正是"除去最后一次盖印后，开头与结尾重合的部分"——总长减去重合部分，剩下的就是一次盖印的宽度。

用具体数字跑一遍（样例）：s=`cabcabca`。net[8]=5：前缀 `cabca`（5 位）与后缀 `cabca`（末 5 位）相等。答案 8-5=3。验证：位移 3 后 `cabcabca` 的前 5 位 `cabca` 与后 5 位逐位相等（c-a-b-c-a 对 c-a-b-c-a），正是 `cab` 在循环。

**③ 原理与推导**

推导"答案 = L - net[L]"，分两步走，每步给依据。

第一步：**位移 p = L - net[L] 是一个合法周期**。net[L]=b 的定义：s[0..b-1] = s[L-b..L-1]。代入 p = L - b，即 s[i] = s[i+p] 对所有 i ∈ [0, b-1] = [0, L-1-p] 成立——这恰好是"位移 p 自匹配到头"：s 去掉前 p 位与去掉后 p 位完全相同。对 i 从 0 到 L-1-p 都有 s[i]=s[i+p]，意味着 s 是"周期为 p 的无限循环串"的前缀（每一位都由它前方 p 位的那位决定），所以 p 是一个可行印章宽度。

第二步：**p 是最短的**。设 q 是任一可行周期（s 是宽度 q 的无限循环前缀），则 s[q..L-1] = s[0..L-1-q]（同一枚印章，只差起点错位 q），即 border >= L - q；而 net[L]=b 是**最长**相等前后缀，b >= L - q，于是 p = L - b <= q。所有可行周期里 p 最小。

对照 A 源 slide 2 的直觉（原话意译）：求 net 时"s 自己匹配自己，是空过一个周期开始匹配的。因为周期内肯定匹配不上，所以是第 i 个周期和第 i+1 个周期匹配"——自匹配时错一位比，只有位移恰好等于周期才能一路比到底，最大 border 自然对应"空过一个周期"的那个位移。

设计动机收尾：为什么不用枚举每个约数去试周期？枚举是 $O(L \cdot d(L))$ 且要处理"不整除"情形；net[L] 一次 $O(L)$ 同时回答了"可行"与"最短"两问——这正是 next 数组 border 身份的红利（知识点 2① 的双重身份在应用侧的兑现）。

**④ 代码演示**

取自源文件 P3375.cpp（文件名与内容交叉：内容实为 P4391 解法，见 A-3 登记 2。改动：删 getchar 与注释，主逻辑逐行原样）：

```c
#include <stdio.h>
#include <string.h>
// P4391：最短循环节长度 = L - net[L]；复杂度 O(L)
int l;
char s[1000005];
int net[1000005];
int main()
{
    scanf("%d", &l);
    scanf("%s", s);
    // 求 net：与知识点 2、4 同款循环
    net[0] = -1;
    net[1] = 0;
    int k = 0, j = 1;
    while (j + 1 <= l) {                       // 注意算到 net[l]
        if (k == -1 || s[j] == s[k]) { net[j+1] = k+1; k++; j++; }
        else k = net[k];
    }
    printf("%d\n", l - net[l]);                // 答案就一行
    return 0;
}
```

**执行追踪表**（样例 L=8，s=`cabcabca`，只列 net 求解的关键步）：

| 步骤 | 当前元素 | 结构状态 | 动作 | 结果 |
|:---:|:---:|:---|:---|:---|
| 1 | j=1..3, k=0→-1 | net[1..3]=0 | a、b 对 c 逐个失配退到 -1 | net[2]=net[3]=0 |
| 2 | j=3, k=0 | s[3]=c 对 s[0]=c 对上 | net[4]=1, k=1 | 周期影子的开头 |
| 3 | j=4..7, k=1..4 | 逐位对上 | net[5]=2, net[6]=3, net[7]=4, net[8]=5 | 一路顺延无回退 |
| 4 | 收尾 | net[8]=5 | 输出 8 - 5 | 答案 3 |

**错误写法对照**：

```diff
- printf("%d\n", net[l]);   // 坑1：把 border 长度当答案——net[l] 是"重合部分"不是"印章宽度"，样例会输出 5 而非 3（答案错）
+ printf("%d\n", l - net[l]);   // 素材原样：印章宽度 = 总长 - 重合部分
- while (j < l)             // 坑2：循环少推一位，net[l] 没算出来——用到未赋值内存（WA，值随机）
+ while (j + 1 <= l)        // 素材原样：net[l] 必须求到
- if (l % p == 0) printf...   // 坑3：想当然"周期必整除"——样例 8 不被 3 整除，s 只是无限循环串的前缀（答案错）
+ l - net[l]                // 正确口径天然允许不整除（见③第一步推导）
```

**⑤ 典型应用**

- 真题：P4391 无线传输（官方样例 L=8、`cabcabca` → 3，断言实测通过，附录 B-5）。
- 真题：P3375 的 net 输出——本质同源：net[i] 的 border 身份被直接当答案输出（知识点 4③），P4391 是 border 身份的"减法用法"。
- 迁移题：给串 s 末尾追加一个字符 c，问新串的最短循环节长度变化。数据范围 $|s| \le 10^6$；输入 s 与 c 两行，输出新串答案。建议先独立做，再对照题解：追加 c 后 net 最多延长一位（复用原 net 推一步），答案为 (L+1) - net'[L+1]；也可直接对新串重跑④代码求 net 后作差。标注：自编。

**⑥ 坑点与边界**

> **【易错】** 答案写成 net[L]。那是重合长度不是周期长度，样例直接暴露（输出 5 对 3），见④对照坑 1。

> **【易错】** 默认周期整除串长。P4391 的 s 是无限循环串的前缀，样例 L=8、周期 3 就不整除，见④对照坑 3。

> **【注意】** L=1 时答案恒为 1（net[1]=0，1-0=1）：单字符自己的最短周期是它自己；全相同串 `AAAA` 答案也是 1——这两个边界都在断言与下表中实测。

> [!example]-
> **边界数据集（先自己跑一遍，再展开对照）**
> 1. 空输入：L=0 → 素材代码 net[1]=0 的写法依赖 L>=1（数组不越界但语义无效）；竞赛保证 L>=1（预期：定义域外，约定先于代码）。
> 2. 单元素：L=1，s=`a` → net[1]=0，答案 1-0=1（预期：1）。
> 3. 全相同：L=4，s=`AAAA` → net=[-1,0,1,2,3]，答案 4-3=1（预期：1，印章是单个 `A`）。
> 4. 严格递增：L=5，s=`abcde` → net[5]=0，答案 5（预期：5，无周期，印章是整串）。
> 5. 严格递减：L=5，s=`edcba` → 同上答案 5（预期：5）。
> 6. 极值：L=10^6 全 `A` → net 递增不回退 $O(L)$，答案 1；数组 1000005 开满（预期：1，瞬间完成）。

回扣开场：从"匹配在哪"到"周期多长"，同一个 net 数组的两副面孔——回退表（知识点 2、3、4）与重合尺（本节）。现在你既能在 $10^6$ 规模下报出 P3375 的全部位置，也能一句话算出 P4391 的最短印章宽度。

## 四、总结与自测

### 核心内容（一页纸速览）

- **暴力匹配**：枚举起点逐位比，最坏 $O(nm)$；病根是失配后主串指针回头、已匹配信息全扔（B 源 p2）。
- **next 数组（net）**：net[i] = s[0..i-1] 的最长相等真前后缀长度；失配在 i 时 j 退到 net[i]——窗口尾部与模式串头部因相等前后缀自动接上（A 源 slide 1 定义，B 源 p3 手算逻辑同源差一口径）。
- **递推求 net**：s 自己匹配自己（A 源 slide 2）；对上长度加一，失配 y=net[y] 换次长候选；均摊 $O(m)$。
- **匹配主过程**：i 不回溯，失配只退 j；j 的总增加 <= n 且每次回退严格变小，总账 $O(n+m)$（B 源 p2 思想，复杂度论证为本篇通识补账）。
- **P3375**：求 net + 扫描报位（i-n+1）+ j=net[n] 续找 + 输出 net[1..n]；官方样例 `1` `3` `0 0 1`。
- **P4391**：最短循环节 = L - net[L]；s 允许是无限循环串的不整除前缀；样例 8、`cabcabca` → 3。

### 前置概念清单

- C 数组与字符串（char 数组、strlen）：本篇全部代码的载体。
- [[枚举与模拟]]：暴力匹配就是"枚举起点 + 模拟比对"。
- 双指针扫描（[[尺取法]] 的指针单调性思想）：匹配主循环里 i 单调前进、j 单调性记账的雏形。
