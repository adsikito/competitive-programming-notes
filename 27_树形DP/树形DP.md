## 一、为什么需要它

先用你大概率碰过壁的方式做一遍 P1352 没有上司的舞会：n 个职员，父子结点（直接上下级）不能同时参加宴会，求最大快乐指数。暴力做法是枚举每个职员去或不去，$2^n$ 种方案——n=6000 时是 $2^{6000}$，天文数字，必死。

再试线性 DP：想按编号 1 到 n 顺次推 f[i]，却发现 f[i] 依赖它的直接上司 f[parent(i)]——而上司的编号可能比 i 小也可能比 i 大，**一条线性扫描根本找不到合法的计算顺序**；就算把树强行拍平成序列，"依赖"也是分叉的（一个上司多个下属），线性 DP 的前驱结构装不下它。**碰壁的根源：决策依赖长在树上，不长在序列上。**

树形 DP 的破法只有一句话：**把"以 x 为根的子树"当成状态，在 DFS 的后序位置把孩子的答案归并给父亲**。因为树是递归定义的（课件 slide 1 原话："动态规划本质就是记忆化搜索，是基于递归的，而树也是基于递归定义的，所以树形结构天然适合用于动态规划"），整套流程写出来就是一次 DFS。

本篇讲 4 个知识点：树形 DP 与后序归并、P1352 两状态、P2014 树上背包、通用套路总结。顺序理由：思想（知识点 1）先于两状态模板（知识点 2），两状态先于背包（知识点 3），最后收束成套路（知识点 4）。

## 二、知识点逐讲（每个知识点一节，共 4 节）

### 1. 树形 DP 与后序归并：把 DP 搬到树上

前置依赖：[[二叉树竞赛篇]]（递归世界观与后序位置归并子树信息）、[[DFS]]（递归遍历骨架）、线性 DP 的"阶段与转移"思想（同批笔记，先文字锚定）
后续衔接：[[#2. P1352 没有上司的舞会：选与不选的两状态]]、[[#3. P2014 选课：树上背包与虚拟源点]]、[[#4. 树形 DP 通用套路总结：三步法与题型对照]]

**① 它解决什么问题**

课件 slide 1 定义：树形 DP 是一种 DP 的思想，**把 DP 建立在树状结构的基础上**——用树形结构存储数据，在树上进行状态转移。slide 1 给出状态设计口径："通常把**一个结点或者一棵子树**看成一个状态，状态转移发生在**父子结点 / 兄弟结点 / 树及其子树**之间"。slide 2 给出实现口径："树形 DP 的关键和实现方法是 DFS，代码通常采用备忘录写法"。复杂度总账先给出：树形 DP 的主流程就是一次 DFS，每条树边恰好下行一次、上行一次，所以不含背包合并时整体 $O(n)$（即每个结点常数次转移）；带背包合并的量级在知识点 3 细算。存树上，slide 3 指出"树其实是一种特殊的图，一般选用链式前向星存储"——vector 邻接表与链式前向星（[[图的概念存储与遍历]]）都常见，素材两份源码恰好各用一种。

**② 直觉理解**

模型级类比：**公司年报汇总**。每个部门经理的年报只有一句话——"我的数据 + 我所有下属部门的报表"。下属没交齐，经理的表就填不了；所以填表的时机永远是"下属全交齐之后"。放在 DFS 里：递归下行是去收表，回溯到当前结点的那一刻是"下属全交齐了"——**后序位置就是归并时机**。

用具体数字跑一遍（子树大小统计，这是信息归并最直白的例子，也是 P2014.cpp 里 sumu/sumv 的机制）：树 1 的孩子是 2 和 3，3 的孩子是 4。dfs(2) 是叶子直接返回 1；dfs(4) 返回 1，dfs(3) 把它加进自己得 2；回到 dfs(1) 时两个孩子的账本 1 和 2 都齐了，加起来得 3。每个数字都是"孩子全齐之后"才算出来的。

**③ 原理与推导**

为什么状态必须定义在子树上（设计动机）：父结点做决策时，能依赖的只有"某棵子树内部已经最优"这个**封闭的结论**——子树内部怎么排列组合父结点不需要关心。子树正好是树上天然封闭的决策域，所以"以 x 为根的子树的某种最优值"成为树形 DP 的标准状态形状（slide 3 原话："状态可以定义为以当前节点为根的子树的某种性质"）。

为什么转移必须在后序位置：状态转移方程是"父 = 孩子的函数"（slide 1：转移发生在父子结点之间），代入函数前孩子的值必须是最终值；前序位置孩子还没算，只有后序位置天然满足。一次 DFS 的结构如下（文本图）：

```text
dfs(x):
  1. 初始化 dp[x]（只含 x 自己的局部信息）      —— 进入时刻
  2. for 每个孩子 y: dfs(y)                     —— 下行
  3. dp[x] += 归并 dp[y]                        —— 后序位置（回溯时刻），唯一合法的转移点
  4. return                                     —— 把 x 的完整账本交给父亲
```

文字版推导链：初始化只放局部信息，是为了让第 3 步的"+="可以逐个孩子累加；第 2 步递归保证第 3 步读到的是最终值；第 4 步的返回值（如子树大小 sumu）还服务于剪枝。复杂度 $O(n)$ 的原因：第 2、3 步合起来对每条边只做一次下行一次上行，全树 n-1 条边就是 $2(n-1)$ 次动作。

**④ 代码演示**

自编骨架（无源文件对应，机制取自 P2014.cpp 的 sumu/sumv）：统计每个结点的子树大小，即"后序位置归并"的最小可运行样例。

```cpp
#include <iostream>
#include <vector>                        // C 等价：vector<int> g[N] ≈ int g[N][MAXK] + int len[N] 记每行个数
using namespace std;
int n, sz[100005], hasPar[100005];       // sz[x]：x 的子树结点个数
vector<int> g[100005];                   // g[x]：x 的所有孩子（邻接表存树）

void dfs(int x) {
    sz[x] = 1;                           // 初始：只含自己（对应 P2014 的 sumu = 1）
    for (int i = 0; i < (int)g[x].size(); i++) {   // C 等价：for (i = 0; i < len[x]; i++)
        int y = g[x][i];
        dfs(y);                          // 下行：先把孩子的账本算完
        sz[x] += sz[y];                  // 后序位置：归并（复杂度：每条边只走这一来回）
    }
}
int main() {
    cin >> n;
    for (int i = 1; i < n; i++) {
        int l, k; cin >> l >> k;         // l 的父亲是 k
        hasPar[l] = 1;
        g[k].push_back(l);               // C 等价：g[k][len[k]++] = l
    }
    int root = -1;
    for (int i = 1; i <= n; i++)
        if (!hasPar[i]) { root = i; break; }   // 没有父亲的结点是根（slide 5 的找根法）
    dfs(root);
    cout << sz[root] << "\n";            // 全树大小 = 后序归并的最终账本
    return 0;
}
```

**执行追踪表**（树：1 的孩子 [2, 3]，3 的孩子 4；n=4）：

| 步骤 | 当前元素 | 结构状态 | 动作 | 结果 |
|:---:|:---:|:---|:---|:---|
| 1 | 进入 dfs(1) | sz[1]=1 | 初始化后遍历孩子 [2,3] | 先递归 dfs(2) |
| 2 | dfs(2) | sz[2]=1 | 叶子无孩子，直接返回 | 子树 2 的账本=1 |
| 3 | 回到 dfs(1) 后序位置 | sz[1]=2 | sz[1] += sz[2] | 孩子账本 2 并入 |
| 4 | dfs(3)、dfs(4) | sz[4]=1, sz[3]=2 | dfs(4) 返回后 dfs(3) 归并 | 子树 3 的账本=2 |
| 5 | 回到 dfs(1) 后序位置 | sz[1]=3 | sz[1] += sz[3] | 全树账本=3，归并完成 |

**错误写法对照**（转移时机写错——树形 DP 最常见的死法）：

```diff
- void dfs(int x) {
-     for (int i = 0; i < (int)g[x].size(); i++) {
-         int y = g[x][i];
-         sz[x] += sz[y];              // 坑1：递归前就归并——sz[y] 还是初值 0，读到的是空账本（答案错，WA）
-         dfs(y);
-     }
- }
+ void dfs(int x) {
+     sz[x] = 1;
+     for (int i = 0; i < (int)g[x].size(); i++) {
+         int y = g[x][i];
+         dfs(y);                      // 对：先递归下行，孩子账本算完
+         sz[x] += sz[y];              // 再在后序位置归并
+     }
+ }
- void dfs(int x) { if (g[x].empty()) return; }   // 坑2：只写叶子出口，忘给 sz[x] 初始化——非叶结点 sz 从 0 起加（答案错）
+ void dfs(int x) { sz[x] = 1; /* 再遍历孩子 */ }  // 初始化对每个结点都要做，且在归并之前
```

**⑤ 典型应用**

- 真题：洛谷 P1352 没有上司的舞会（slide 4 例题），本篇知识点 2 全流程实战——两状态版的后序归并。
- 真题：洛谷 P2014 [CTSC1997] 选课（slide 5-7 例题），本篇知识点 3——背包合并版的后序归并。
- 迁移题（自编）：从任意根出发输出每个结点的子树大小。思路：即本节骨架，把 `sz[x] = 1` 加上 `+=` 归并即可，P2014.cpp 的 dfs 返回值 sumu 正是它（出处：P2014.cpp L21-L41）。建议先独立做，再对照题解：与骨架逐行同构，答案存在 sz 数组中直接输出。

**⑥ 坑点与边界**

> **【易错】** 转移写在递归之前。后果：读到的孩子状态全是初值（WA），且这种错编译器不报——见④对照坑 1。

> **【易错】** 忘记初始化当前结点的状态就归并。后果：部分结点从 0 或脏值起算（WA）——初始化、递归、归并三件事的顺序是固定的。

> **【注意】** 找根必须用"有没有父亲"标记（slide 5 原话："没有上司（父亲）的结点"）。从任意点开始 DFS 会漏掉整棵子树——树形 DP 的输入是森林或单树，根错了后面全错。

> [!example]-
> **边界数据集（先自己跑一遍，再展开对照）**
> 1. 空输入：不适用：题面保证 n ≥ 1（树至少一个结点）；n=0 属输入违约，找根循环找不到根，不构造。
> 2. 单元素：单结点树 n=1，无边 → root=1，sz[1]=1（预期：输出 1，不崩）。
> 3. 全相同：n=7 满二叉树（每个非叶结点都恰有 2 个孩子）→ 各子树大小全由形状决定，根 sz=7（预期：7）。
> 4. 严格递增：链状树 1-2-3-4（1 为根）→ sz[i] = 5-i，从 4 递减到 1，归并逐层进行（预期：根账本=4）。
> 5. 严格递减：星形树（根连 4 个叶）→ 每个孩子 sz 全为 1，大小序列无递减区分度，对"子树大小"这一信息不适用（理由：它由形状决定，与键序无关）；换成权值型 DP（知识点 2）即适用。
> 6. 极值：n=10^5 的链状树 → 递归深度 10^5 层，默认栈有溢出风险（RE）——大 n 链状数据优先改手写栈的非递归 DFS（[[栈与队列]]），或换层序递推。

回扣开场：现在你能解决"线性扫描找不到计算顺序"的困境了——用的正是本节结论：计算顺序由 DFS 的后序天然给出，根本不需要人为排序。

### 2. P1352 没有上司的舞会：选与不选的两状态

前置依赖：[[#1. 树形 DP 与后序归并：把 DP 搬到树上]]（后序位置归并）
后续衔接：[[#3. P2014 选课：树上背包与虚拟源点]]（两状态升级为"每棵子树选几个"的背包）、[[二叉树竞赛篇]]（树上最值问题的同族题）

**① 它解决什么问题**

slide 4 题意：树中一个结点代表一个人，父结点是子结点的顶头上司，结点权值是快乐指数 r。**父与子（直接上下级）不能同时选**，选一些结点使权值和最大。洛谷 P1352（普及难度，n ≤ 6000，数组按素材 6005 开）。对每个结点 x，slide 4 定义两状态：**f[x][0] 表示 x 不参加时，以 x 为根的子树的最大快乐值；f[x][1] 表示 x 参加时的同口径最大值**。复杂度：两状态 × n 个结点，每次转移对每个孩子常数次加法取 max，总体 $O(n)$（n=6000 时约 1.2 万次动作，1 秒限制内绰绰有余）。

**② 直觉理解**

模型级类比：**每个经理记红蓝两本账**。红账记"我不去时我管辖范围的最大快乐值"，蓝账记"我去时"。我去，下属全部被禁止，蓝账只能收下属的红账；我不去，下属去不去自由，红账收下属两本账里较大的一本。最后只要看总经理（根）哪本账厚。

用具体数字跑一遍（三结点链 1←2←3，权值 1、2、3，即 2 的上司是 1、3 的上司是 2）：叶子 3 的账 f[3]=[0,3]；中层的红账 = max(0,3)=3、蓝账 = 2+0=2，f[2]=[3,2]；根的红账 = max(3,2)=3、蓝账 = 1+3=4，f[1]=[3,4]。答案 max(3,4)=4——选 1 和 3（不同时选相邻），1+3=4。

**③ 原理与推导**

转移方程推导（slide 4 + 源码 P1352.cpp）。设 y 是 x 的孩子：

1. x 不去（f[x][0]）：孩子 y 去不去都不违反约束，取两本账中大的——`f[x][0] += max(f[y][0], f[y][1])`。
2. x 去（f[x][1]）：y 被直接禁止，只能收 y 的红账——`f[x][1] += f[y][0]`。

初始状态（slide 4 原话："初始状态：每个人都认为只有自己去"）：`f[x][0]=0, f[x][1]=r[x]`——先假设子树里只有 x 自己，再逐个孩子归并。答案（slide 4）：找唯一树根 root，`ans = max(f[root][0], f[root][1])`。

**设计动机**：为什么状态要两维、不能一维？因为"x 参不参加"这件事决定孩子可选的范围——父亲的状态不同，孩子的最优决策完全不同，一维信息不足以让父结点做选择。这正是树形 DP"状态定义在子树上"的第一次升级：**在子树维度外再挂一个"本结点怎么选"的维度**。

找根（slide 5）：没有父亲的结点是根；建树时给每个结点标记有没有父亲（源码 v[l]=1），最后扫描一遍即可。

**④ 代码演示**

取自源文件 P1352.cpp（改动：无，逐行原样，54 行完整版即此）：

```cpp
#include<iostream>
#include<cstdio>
#include<vector>
using namespace std;
//vector模拟邻接表存树
int n;
int r[6005];
int dp[6005][2];
int v[6005];//v[i]=1  i点有父亲
vector <int> g[6005];
void dfs(int x)
{//求以x为根的子树中 选若干个点的最大权之和
 dp[x][0]=0;//一个点都不选
 dp[x][1]=r[x];//根结点选 其他点不选
 int y;
 for(int i=0;i<g[x].size();i++)
 {
    y=g[x][i];
    dfs(y);                            // 先递归：孩子的两本账算完
    dp[x][1]+=dp[y][0];                // x 选，孩子必不选：收红账
    dp[x][0]+=max(dp[y][0],dp[y][1]);  // x 不选，孩子自由：收较大账
 }
}
int main()
{
    cin>>n;
    for(int i=1;i<=n;i++)
    cin>>r[i];
    int l,k;
    for(int i=1;i<n;i++)
    {
        cin>>l>>k;                     // l 的上司是 k
        v[l]=1;                        // 标记 l 有父亲
        g[k].push_back(l);             // k 是父亲，l 挂进 k 的孩子表
    }
    int root;
    for(int i=1;i<=n;i++)
    {
        if(v[i]==0) { root=i; break; } // 没有父亲的就是根
    }
    dfs(root);
    cout<<max(dp[root][1],dp[root][0]);
    return 0 ;
}
```

**执行追踪表**（官方样例：n=7，权值全 1；边（孩子,父亲）为 (1,3)(2,3)(6,4)(7,4)(4,5)(3,5)，树形为 5 的孩子 [4,3]、4 的孩子 [6,7]、3 的孩子 [1,2]；记 dp[x]=[红,蓝]）：

| 步骤 | 当前元素 | 结构状态 | 动作 | 结果 |
|:---:|:---:|:---|:---|:---|
| 1 | 进入 dfs(5) | dp[5]=[0,1] | 初始化后下行 | 递归 dfs(4) |
| 2 | 进入 dfs(4) | dp[4]=[0,1] | 下行至叶 6、7 | dp[6]=dp[7]=[0,1] |
| 3 | 回到 dfs(4) 后序位置 | dp[4]=[2,1] | 蓝 += 红账 0+0；红 += max 各 1 | 子树 4 账本齐 |
| 4 | dfs(3) 同构归并 | dp[3]=[2,1] | 叶 1、2 归并方式同上 | 子树 3 账本齐 |
| 5 | 回到 dfs(5)：归并孩子 4 | dp[5]=[2,3] | 蓝 1+2=3；红 0+max(2,1)=2 | 5 选则 4 必不选 |
| 6 | 归并孩子 3 | dp[5]=[4,5] | 蓝 3+2=5；红 2+max(2,1)=4 | 两本账齐 |
| 7 | root=5 | max(4,5) | 取较大账 | 输出 5，与官方样例一致 |

**错误写法对照**：

```diff
- dp[x][1] += max(dp[y][0], dp[y][1]);   // 坑1：x 选时还收孩子"选"的账——父子同选违反约束，答案偏大（WA）
+ dp[x][1] += dp[y][0];                  // 对：x 选，孩子被禁止，只能收红账
- v[k] = 1;                              // 坑2：父亲标记写反——根被误标有父亲，找根循环找到别的结点（WA：漏整棵子树或 dp 未算）
+ v[l] = 1;                              // 对：是孩子 l 拥有父亲 k
- dp[x][0] += dp[y][1];                  // 坑3：x 不选时只收孩子"选"的账——漏掉孩子也不选的选项（WA：负向丢解）
+ dp[x][0] += max(dp[y][0], dp[y][1]);   // 对：孩子两种选择取较大
```

**⑤ 典型应用**

- 真题：P1352 本题。实测官方样例输出 5（附录 B-5 断言 1-3），追踪表第 5-6 步展示了"两本账"逐层归并的全过程。
- 真题：洛谷 P1122 最大子树和（资料未覆盖，属补充，题号真实）。思路一行：每个结点可裁掉整棵子树，`dp[x] = val[x] + Σ max(dp[y], 0)`——同样是"子树内最优，后序归并"，只是归并用 max(dp[y], 0) 表达"裁与不裁"。
- 迁移检验题（自编）：最小顶点覆盖——树 n ≤ 2000，选最少结点使每条边至少有一端被选。建议先独立做，再对照题解：状态 `g[x][0] = Σ g[y][1]`（x 不选则孩子全被迫选）；`g[x][1] = 1 + Σ min(g[y][0], g[y][1])`（x 选则孩子自由）。在官方样例的树上手算：叶 g=[0,1]，g[4]=g[3]=[2,1]，根 g[5]=[2,3]，答案 min(2,3)=2（选 3 和 4，覆盖全部 6 条边）。转移骨架与 P1352 同族，只是"最大"换"最少"。

**⑥ 坑点与边界**

> **【易错】** 坑 1 的"父子同选"变体：把两条转移写反或都写 max。后果：答案偏大（WA）。检验口诀——蓝账只收红账，红账两本挑大的。

> **【易错】** 找根的标记方向写反（v[k]=1）。后果：根定位错，DFS 只覆盖部分树或读到未计算的 dp（WA）。建树后可加一步自检：确认恰好一个 v[i]==0。

> **【注意】** 快乐指数若为 0 或负（题面范围资料未给出，这一段我不确定），f[x][1] 初始 r[x] 仍正确——状态定义本身允许"选了反而更小"，答案取 max 时自动排除；但把 f[x][1] 初始写成 0 就错了（把"x 参加"偷换成"x 不参加"）。

> [!example]-
> **边界数据集（先自己跑一遍，再展开对照）**
> 1. 空输入：不适用：题面 n ≥ 1（无人的舞会无意义），不构造。
> 2. 单元素：单结点树 n=1，r=7 → f=[0,7]，输出 7（实测断言 4 通过，附录 B-5）。
> 3. 全相同：链状树 n=3 全 1 权 → f[叶]=[0,1]，f[中]=[1,1]，f[根]=[2,2]，输出 2（预期：隔一个选一个）。
> 4. 严格递增：链 1←2←3 权 1,2,3 → 输出 4（选 1 和 3，放弃中间的 2；实测断言 5 通过）。
> 5. 严格递减：星形树根权 10、三个孩子各 5 → 选根 f[根][1]=10，弃根 f[根][0]=15，输出 15（实测断言 6 通过；权值从根向外递减时"不选根"反超）。

### 3. P2014 选课：树上背包与虚拟源点

前置依赖：[[#2. P1352 没有上司的舞会：选与不选的两状态]]（子树状态 + 后序归并）、[[链表]]（链式前向星的 next 指针本质是数组模拟链表）、[[DFS]]
后续衔接：[[#4. 树形 DP 通用套路总结：三步法与题型对照]]、依赖背包进阶（延伸，资料未覆盖）

**① 它解决什么问题**

洛谷 P2014 [CTSC1997] 选课（slide 5-7 例题，普及+/提高−）：n 门课各有学分，每门课至多一门直接先修课，选 M 门课使学分最大。slide 5 抓住关键类比："每门课最多只有一门先修课，与有根树中一个点最多只有一个父亲结点的特点类似"——于是课程组成**森林**；再新增一门 0 学分的虚拟课程（编号 0）当所有无先修课课程的先修课，森林变成一棵以 0 为根的树，问题变成"n+1 个结点选 M+1 门（0 号必选）"。状态（slide 7 降维版）：**dp[u][j] = 以 u 为根的子树中选 j 个结点的最大学分和**。复杂度：状态 $O(n \cdot M)$ 个；素材代码带两处 min 剪枝（名额不超过子树大小、不超过剩余预算），按教材通识，这样的树上背包总转移量为 $O(n \cdot M)$（每对结点只在它们公共祖先处合并一次；严格证明资料未覆盖，属补充，量级结论供判断能不能过题用）。

**② 直觉理解**

模型级类比：**分组购物车**。每棵子树是一个购物车组：组内选几件、选哪几件自由，但各组共享总预算 M；并且想买组里任何东西，必须先连带买下组根（先修课）。dp[u][j] 就是"以 u 为根的这个组群、预算 j 时的最大折扣"。

用具体数字跑一遍（官方样例的子树 7：7 的孩子是 6 和 5，val[7]=2, val[6]=6, val[5]=1）：初始 dp[7]=[_,2]；归并孩子 6 后 dp[7][2]=6+2=8（选 7 和 6）；再归并孩子 5 后 dp[7][3]=1+8=9（选 7、6、5）。每一步都是"先拿孩子账本，再决定从它这买几件"。

**③ 原理与推导**

第一步，为什么森林能加虚拟源点（slide 5 原话："为了方便起见，我们可以新增一门 0 学分的课程（设这个课程的编号为 0），作为所有无先修课课程的先修课，这样我们就将森林变成了一棵以 0 号课程为根的树"）。设计动机：多棵树没有公共根，DFS 无法一次跑完；虚拟源点学分 0、必选，它不改变任何最优决策（任何合法选课组合加上 0 号都合法且学分不变），却让"一次 dfs(0) 出全部答案"成立——代价仅是把"选 M 门"改写成"选 M+1 门"（源码 `m++`）。

第二步，从三维到二维（slide 6-7）。朴素状态是 slide 6 的 `dp[u][i][j]`：u 的前 i 棵子树里选 j 个的最优值，第 i 棵子树里选 k 个时 `dp[u][i][j] = max(dp[u][i-1][j-k] + dp[v][k])`。slide 7 指出"i 只有 i-1 行得到，且 j 和 j 之前的值有关，所以可以和 01 背包一样降维：i 不要了，j 要倒着维护"——得到源码形式：

$$dp[u][j] = \max(dp[u][j],\ dp[v][k] + dp[u][j-k])$$

文字版结论：在第 v 棵子树里选 k 个（花费 k 个名额），与"前若干棵子树已选 j-k 个"的旧账合并；j 必须倒序枚举，防止同一棵子树的方案被重复计入（与 01 背包一维化同理——正序会让 dp[u][j-k] 已经掺入本子树的收益，等于一件商品买多次）。

第三步，边界细节的推导：初始 `dp[u][0]=0, dp[u][1]=val[u]`（slide 7 原话："在 u 的前 0 棵子树中选择 1 个结点"——只能选 u 自己）；k 的上界是 `min(j-1, sumv)`——k 最大 j-1 是因为 **u 自己必须占一个名额**（选子树里任何课都得连带 u），k 不超过 sumv 是因为第 v 棵子树总共只有 sumv 个结点（剪枝）。文本图（子树 7 的归并）：

```text
dp[7] 初始:  [_, 2]                 ← 只有 7 自己
归并孩子 6:  dp[7][2] = max(_, dp[6][1] + dp[7][1]) = 6 + 2 = 8
归并孩子 5:  dp[7][3] = max(_, dp[5][1] + dp[7][2]) = 1 + 8 = 9
返回 sumu=3  ← u 的完整账本交给父亲 2
```

文字版推导链：每归并一棵子树，名额 j 的每一档都更新一次"该子树买 k 件的最优组合"；三步之后 dp[7] 就是整棵子树 7 的购买方案表。

**④ 代码演示**

取自源文件 P2014.cpp（改动：无，逐行原样，59 行完整版即此；链式前向星 = 数组模拟链表，[[链表]]）：

```cpp
#include<iostream>
#include<cstdio>
#include<vector>
using namespace std;
//链式前向星
struct Edge
{
    int to,next;
}e[305];
int head[305],cnt=0;
void add(int u,int v)
{
    ++cnt;
    e[cnt].next=head[u];
    e[cnt].to=v;
    head[u]=cnt;
}
int n,m;
int val[305];
int dp[305][305];
int dfs(int u,int d)//根结点u  以及u的深度d
{
    int sumu=1;//以u为根的树中的结点的个数
    dp[u][0]=0;
    dp[u][1]=val[u];
    for(int i=head[u];i>0;i=e[i].next)
    {
        int v=e[i].to;
        int sumv=dfs(v,d+1);//sumv是以v为根结点的子树的结点个数
        sumu+=sumv;//sumu就是u前i棵子树的结点总数（包含u）
        for(int j=min(m-d,sumu);j>0;j--)      // 名额倒序 + 不超过剩余预算/子树大小（剪枝）
        {
            for(int k=0;k<=min(j-1,sumv);k++) // k≤j-1：u 自己占一个名额
            {
                dp[u][j]=max(dp[u][j],dp[v][k]+dp[u][j-k]);
            }
        }
    }
    return sumu;
}
int main()
{
    cin>>n>>m;
    m++;                               // 虚拟源点 0 号必选：选 M 门变选 M+1 门
    int fa;
    for(int i=1;i<=n;i++)
    {
        cin>>fa>>val[i];               // 第 i 门课的先修课 fa 与学分
        add(fa,i);                     // fa 是父亲：从 fa 挂边到 i
    }
    dfs(0,0);                          // 根结点是 0（虚拟源点）
    cout<<dp[0][m]<<endl;              // 从整棵树（含 0 号）选 M+1 门的最优
    return 0 ;
}
```

**执行追踪表**（官方样例 dfs(7) 内部：m=4 输入后变 5，结点 7 深度 d=2，val[7]=2；孩子遍历顺序 6 先 5 后——头插法；记 dp[7] 为名额 0..3 的账）：

| 步骤 | 当前元素 | 结构状态 | 动作 | 结果 |
|:---:|:---:|:---|:---|:---|
| 1 | 进入 dfs(7,2) | dp[7][0]=0, dp[7][1]=2 | 初始化，sumu=1 | 下行 dfs(6) |
| 2 | dfs(6) 返回 | dp[6]=[_,6], sumv=1, sumu=2 | j=2,k=1：dp[7][2]=6+2 | dp[7][2]=8（7+6） |
| 3 | 归并孩子 6 完毕 | dp[7][1]=2 | j=1,k=0 无更优 | 子树 6 账并入 |
| 4 | dfs(5) 返回 | dp[5]=[_,1], sumv=1, sumu=3 | j=3,k=1：dp[7][3]=dp[5][1]+dp[7][2] | dp[7][3]=9（7+6+5） |
| 5 | 返回给父亲 2 | 返回值 sumu=3 | 子树 7 的账本与大小交割 | 父结点继续背包合并 |

**错误写法对照**：

```diff
- for(int j=min(m-d,sumu);j>0;j--)        // 坑1：把 j 循环写成正序 j=1..min(...)——dp[u][j-k] 已掺入本子树收益，
+ for(int j=min(m-d,sumu);j>0;j--)        //   同一棵子树的方案被重复叠加，答案偏大（WA）；倒序保证旧账是"前 i-1 棵子树"的
- cin>>n>>m;  dfs(0,0);  cout<<dp[0][m];  // 坑2：漏 m++——把"选 M+1 门（含 0 号）"当"选 M 门"，答案系统性偏差（WA）
+ cin>>n>>m;  m++;                        // 对：虚拟源点占一个名额
- for(int k=1;k<=min(j-1,sumv);k++)       // 坑3：k 从 1 起——强制每棵子树都必须选课，"整棵子树一个不选"的方案被漏（WA）
+ for(int k=0;k<=min(j-1,sumv);k++)       // 对：k=0 表示这组购物车空着（dp[v][0]=0 恰好是加 0）
```

**⑤ 典型应用**

- 真题：P2014 本题。实测官方样例（n=7, m=4）输出 13，且与"祖先闭包"暴力对拍一致（附录 B-5 断言 7、10）；追踪表第 2、4 步即"分组购物车"的两次归并。
- 真题：洛谷 P1064 金明的预算方案（NOIP2006 提高组，资料未覆盖，属补充，题号真实）。关键思路一行：主件-附件的依赖构成森林，加虚拟源点后与本篇完全同构；因每件至多 2 个附件，工程上也常转成"每组枚举 不买/买主/主+附1/主+附2/全买 五种组合"的分组背包写法。
- 迁移检验题（自编）：三门课 1、2，先修关系 1 的先修是 0（虚拟）、2 的先修是 1，学分 val[1]=3, val[2]=4，预算 m=1（选 2 门含 0 号）。建议先独立做，再对照题解：dp[2]=[_,4]；dfs(1) 归并孩子 2：j=2,k=1 时 dp[1][2]=4+3=7；dfs(0) 归并孩子 1：j=2,k=1 时 dp[0][2]=dp[1][1]+dp[0][1]=3，最终 dp[0][3] 中 dp[0][2]=3、dp[0][3]=7——但名额只有 m+1=2，答案是 dp[0][2]=3（选 0 和 1；想选 2 必须连带 1，共 3 门超预算）。这题专门检验"k 必须 ≤ j-1 且名额含 0 号"两个细节。

**⑥ 坑点与边界**

> **【易错】** j 正序枚举。后果：同一子树方案重复叠加，答案偏大（WA）——这是树上背包与 01 背包共享的"倒序"纪律，原因见③第二步。

> **【易错】** 漏 m++。后果：所有答案系统性偏差（WA）。虚拟源点占名额这件事在两处体现：m++ 与 k ≤ j-1，漏一处样例都可能过（若样例恰好不卡），对抗数据必错。

> **【注意】** 素材数组按本题 n ≤ 300 开（dp[305][305]）；换题先按新题面重算数组规模——n=3000 的树上背包开 305 就是 RE（数组开小）。另外 sumu/sumv 剪枝依赖"返回子树大小"，把 dfs 返回值删掉会退化成慢版（可能 TLE），不建议。

> [!example]-
> **边界数据集（先自己跑一遍，再展开对照）**
> 1. 空输入：不适用：题面保证至少一门课无先修课（n ≥ 1），不构造。
> 2. 单元素：n=1，(0,5)，m=0 → 只选 0 号，输出 0；m=1 → 输出 5（实测断言 8、9 通过）。
> 3. 全相同：所有课学分相同（如全 1）→ dp 退化为"名额用满尽量多选"，dp[0][m+1] = m（预期：与选哪几门无关）。
> 4. 严格递增：链 0→1→2 学分 1、2，m=1 → 只能选 0+1=1；m=2 → 3（预期：学分沿链递增时答案被"连带"关系锁死）。
> 5. 严格递减：链 0→1→2 学分 4、1，m=1 → 4；对比若 2 的学分更高就得连带买到 j=3（预期：递减链上深课几乎不可选）。
> 6. 极值：学分 10^6 量级、n=300 → 总和 3×10^8 在 int 内；若换 n=10^5、学分 10^9 的题面，总和 10^14 必须换 long long（防溢出检查），且 dp[305][305] 必须重开——数组与类型都跟题面走。

回扣开场：现在你能解决"选课依赖"问题了——虚拟源点把森林钉成一棵树（本节③第一步），分组背包合并把"每棵子树选几个"逐层归并（③第二步）。知识点 2 的两状态正是 k 只能取 0 的特例。

### 4. 树形 DP 通用套路总结：三步法与题型对照

前置依赖：[[#1. 树形 DP 与后序归并：把 DP 搬到树上]]、[[#2. P1352 没有上司的舞会：选与不选的两状态]]、[[#3. P2014 选课：树上背包与虚拟源点]]
后续衔接：树上问题进阶——树的直径、换根 DP（延伸，资料未覆盖，待产出后双链补上）

**① 它解决什么问题**

本节把前三节收束成查得着、背得动的方法论。slide 3 原话："万变不离其宗：1. 确定结点所代表的状态，一般来说，状态可以定义为以当前节点为根的子树的某种性质；2. 确定状态的转移关系：父子、兄弟；3. 备忘录写法写代码。"slide 3 同时给出题型分野：**选择节点类问题（最大独立集）**——相邻结点（父子）不能同时选，取最值，即知识点 2；**树上背包问题**——"一个物品 x 只有选择了它的主件（根节点）才能选择该物品"，即知识点 3。slide 3 还有一句定心丸："树形 DP 的老套路就那么多，难的还是怎么想出转移方程。"复杂度口径：两状态型 $O(n)$；树上背包带子树大小剪枝 $O(n \cdot M)$（见知识点 3①，属补充结论）。

**② 直觉理解**

模型级类比：**填组织架构报表的三问**。拿到任何树上最值/计数题，先问三个问题：每个部门的报表记什么（状态维度）；经理怎么从下属报表填出自己的（转移方程）；什么时候填（后序位置）。三问问完，代码只是机械翻译。

用具体数字跑一遍（自编迁移题：公司部门树，每部门有利润 val，可正可负，总部必须保留，可整体裁撤任一子部门，求最大总利润。树：1 的孩子 [2,3]，2 的孩子 4；val = [_, 5, -2, 3, -4]）：叶子 4 的账 -4；部门 2 选择裁掉 4，账 = 5 + max(-4, 0) = 5；部门 3 账 = 3；总部 = 5 + 5 + 3 = 13。

**③ 原理与推导**

三步法的依赖链与设计动机：第一步把状态钉在子树上（子树是封闭决策域，理由见知识点 1③）；第二步转移方程必然是"父 = f(孩子们的答案)"（子树只通过父子边交互）；第三步备忘录写法即 DFS（树本身递归定义，slide 1）。三步各错一点的后果链：状态少一维 → 转移信息不足（知识点 2③ 的设计动机反例）；转移漏分支 → 后序归并丢解（知识点 2④ 坑 3）；位置错 → 读空账本（知识点 1④ 坑 1）。两方向补充（slide 2）："叶到根"是本篇主线；"根到叶"往往先从叶往根 dfs 一遍做预处理，再重新向下更新各结点状态——这类"换根"题 slide 3 未给例题，属延伸，本篇不展开。

**④ 代码演示**

自编模板（无赛题对应；把两状态与树上背包两种形状并排，便于合卷默写。改动说明：为紧凑把读入省略，模板只含骨架）：

```cpp
#include <iostream>
#include <vector>
using namespace std;
int val[6005], f[6005][2], m, dp[305][305];
vector<int> g[6005];

void dfs2(int x) {                            // 形状一：两状态（最大独立集，知识点 2）
    f[x][0] = 0; f[x][1] = val[x];            // 初始：只算自己
    for (int i = 0; i < (int)g[x].size(); i++) {
        int y = g[x][i];
        dfs2(y);                              // 后序位置：孩子账本先齐
        f[x][0] += max(f[y][0], f[y][1]);     // x 不选：孩子自由
        f[x][1] += f[y][0];                   // x 选：孩子被禁
    }
}
int dfsBag(int u) {                           // 形状二：树上背包（选课型，知识点 3）
    int sumu = 1;                             // 返回子树大小（剪枝依赖）
    dp[u][0] = 0; dp[u][1] = val[u];
    for (int i = 0; i < (int)g[u].size(); i++) {
        int v = g[u][i];
        int sumv = dfsBag(v);
        sumu += sumv;
        for (int j = min(m, sumu); j > 0; j--)        // 名额倒序
            for (int k = 0; k <= min(j - 1, sumv); k++)
                dp[u][j] = max(dp[u][j], dp[v][k] + dp[u][j - k]);
    }
    return sumu;
}
int main() { return 0; }   // 组装口诀：找根 → dfs(根) → 根上取答案（max(f[root][0/1]) 或 dp[root][M+1]）
```

**执行追踪表**（把三步法套在②的迁移题上，val=[_,5,-2,3,-4]）：

| 步骤 | 当前元素 | 结构状态 | 动作 | 结果 |
|:---:|:---:|:---|:---|:---|
| 1 | 第 1 步：定状态 | dp[x] = 子树 x、保留 x 的最大利润 | 为什么定义在子树上：裁撤只影响整棵子树，子树封闭 | 状态一维足够 |
| 2 | 第 2 步：定转移 | dp[x] = val[x] + Σ max(dp[y], 0) | max 里的 0 = "裁掉整棵子树"选项 | 方程成立 |
| 3 | 第 3 步：备忘录写码 | dfs 后序归并 | 找根 → dfs(root) → 输出 dp[root] | 代码完成 |
| 4 | 手算叶子 4 | dp[4] = -4 | 叶子直接取 val | 负账出现 |
| 5 | 手算归并 | dp[2]=5+max(-4,0)=5, dp[3]=3 | 根 dp[1]=5+5+3 | 答案 13 |

**错误写法对照**（套模板时最常见的两处"想当然"）：

```diff
- dp[x] = val[x] + dp[y];                 // 坑1（负权题）：孩子的负账照单全收——裁撤选项丢失，答案偏小（WA）
+ dp[x] = val[x] + max(dp[y], 0);         // 对：max(dp[y], 0) 就是"裁掉整棵子树"
- f[x][0] += f[y][0];                     // 坑2（两状态题）：x 不选却只收孩子"不选"的账——孩子想选的自由被剥夺（WA）
+ f[x][0] += max(f[y][0], f[y][1]);       // 对：x 不选时孩子两种选择都合法
```

**⑤ 典型应用**

- 真题：P1122 最大子树和（补充，题号真实）——即②迁移题的原型：负权子树可裁，`dp[x]=val[x]+Σmax(dp[y],0)`，答案在所有结点上取 max（答案可能不在根——注意与两状态型"答案在根"的差异）。
- 真题：P1064 金明的预算方案（补充，题号真实）——树上背包在"附件最多两层"场景的退化版，见知识点 3⑤。
- 迁移检验题：②的部门裁撤题即完整迁移题，题解见②推演与④追踪表（数据：树 1-[2,3]、2-[4]，val=[_,5,-2,3,-4]，答案 13）。标注：自编。

**⑥ 坑点与边界**

> **【易错】** 负权场景漏 max(dp[y], 0) 裁枝。后果：答案偏小（WA）——只要题目允许"不要某棵子树"，归并处就必须有"整组放弃"的选项。

> **【易错】** 答案默认取在根上。两状态型（P1352）答案在根；P1122 型答案可能是任何结点的 dp 值（中间某棵子树最优）。套模板前先确认"全局最优出现在哪个位置"。

> **【注意】** slide 2 的"根到叶"方向（换根）本篇未展开（资料无例题，属延伸）；遇到"每个结点作根的答案"类题先跳过，学完换根再回来。

> [!example]-
> **边界数据集（先自己跑一遍，再展开对照）**
> 1. 空输入：不适用：树至少一个结点（n ≥ 1），不构造。
> 2. 单元素：单结点树 → 两状态型输出 val[根]；背包型 m=0 输出 0、m≥1 输出 val[根]（套路退化为常量，验证初始化）。
> 3. 全相同：n 个结点全 1 权的星形树 + 独立集型 → 输出 n-1（选全部叶子，弃根；预期：结构直觉题）。
> 4. 严格递增：链状树权值沿深度递增 → 两状态型答案是隔一个选一层的交错和（预期：验证链是最坏递归深度）。
> 5. 严格递减：星形树根权最小、叶权大 → "不选根"几乎必胜（预期：与知识点 2 断言 6 同构）。

## 四、总结与自测

### 核心内容（一页纸速览）

- **树形 DP**：把"以 x 为根的子树"当状态，DFS 后序位置把孩子答案归并给父亲；转移发生在父子之间（slide 1-2）。
- **后序归并**：初始化 → 递归孩子 → 后序位置 += 归并，三步顺序固定；每条边一下一上，基础复杂度 $O(n)$。
- **P1352 两状态**：f[x][0/1] = 子树内 x 不选/选的最优；蓝账收红账、红账挑大账；找根 = 没有父亲的结点；答案 max(f[root][0], f[root][1])。
- **P2014 树上背包**：森林加 0 号虚拟源点变一棵树，选 M 门变选 M+1 门；dp[u][j] 分组背包式合并，j 倒序、k ≤ min(j-1, sumv)。
- **三步法**（slide 3）：定状态（子树性质）→ 定转移（父子）→ 备忘录写码；题型分野：选点类（独立集）与树上背包类。
- **正负权差异**：允许裁撤就 max(dp,0)；答案位置看题型（根上 or 全局 max）。
