## 一、为什么需要它

先用你熟悉的方式判断一个数是不是偶数：`if (a % 2 == 0)`。取余在机器层面是一条除法指令，而除法指令的耗时通常是位运算指令的数倍到数十倍（量级依据见知识点 4）。更痛的场景是：要枚举 20 件物品"选或不选"的所有方案——用数组存选择状态，递归回溯写 30 行；而一个整数本身就存了 20 个 0/1 位，`for (int s = 0; s < (1 << 20); s++)` 一行把 $2^{20}$ 个方案全部铺开。

课件开场原话（17.1 位运算.pdf p4）："计算机的世界，其实就是一个二进制数字的世界"；"位运算和指针都是 C 语言的重要特色"。本篇讲 4 个知识点：进制与位（补码回顾）、六件套运算、lowbit 与经典技巧、位运算的复杂度账与竞赛用法。顺序理由：表示（1）先于运算（2），运算先于技巧（3），技巧先于竞赛用法（4）。

## 二、知识点逐讲（每个知识点一节，共 4 节）

### 1. 进制与位：二进制世界与补码回顾

前置依赖：[[数据类型与内存表示]]（int 的 32 位存储、补码、溢出）
后续衔接：[[#2. 六件套：与、或、异或、取反、左移、右移]]、[[#3. lowbit 与经典技巧：x&-x、判奇偶、异或交换]]

**① 它解决什么问题**

位运算的操作对象不是"一个数"，而是这个数在内存里的**每一个二进制位**。要谈它，先得回答"位从哪来"：现代计算机中所有数据以二进制形式存储，只有 0、1 两种状态（pdf p4）。int 类型占 32 个位，每个位是一个独立的开关。**复杂度先给总账**：任何位运算都是对一个整数的全部位**同时**操作，一条指令完成，$O(1)$。本知识点是全篇的地基：不先把"数=一排位"和"负数=补码"立起来，后面六个运算符全是无根之木。

**② 直觉理解**

模型级类比：**一排开关面板**。一个 int 是 32 个并排的开关，每个开关只有开（1）和关（0）两种状态；普通算术是"把整块面板当个数来算"，位运算是"伸手拨指定的那几个开关"。

用具体数字推演：612 的 16 位二进制是多少？拆权：$612 = 512 + 64 + 32 + 4 = 2^9 + 2^6 + 2^5 + 2^2$。从第 15 位到第 0 位填 1：第 9、6、5、2 位为 1，其余为 0——`0000001001100100`。这正是课件作业题（p26）的样例输出，实测程序输出一致（附录 B-5）。

**③ 原理与推导**

补码回顾（承接 [[数据类型与内存表示]]，此处只取位运算要用到的两条结论）：

1. **正数的补码就是自身**，11 的 8 位表示是 `0000 1011`。
2. **负数 = 按位取反再加一**：$-x = \sim x + 1$。为什么计算机选补码存负数？设计动机是**让减法消失**：$a - b = a + (-b)$，加法器一套电路同时干加法和减法两件事，硬件省一半。

由结论 2 立刻推出一条全篇反复用的恒等式：$x + \sim x$ 每个位都是 $1+0$ 或 $0+1$，无进位，和为全 1；而全 1 的补码值是 $-1$。所以：

$$\sim x = -1 - x$$

文字版结论：取反任何数，等价于取负再减一，`~5 == -6`、`~0 == -1`。这一段属通识补充（课件未展开推导），实测断言通过（附录 B-5 第 6 组）。

**④ 代码演示**

**块一·核心代码**（自编示例，依据课件 p26 作业题"输出一个整数的二进制形式"，样例 612 输出 0000001001100100）：

```cpp
#include <iostream>
using namespace std;                    // C 等价：每个 cout/cin 前加 std::
int main() {
    int n; cin >> n;                    // C 等价：scanf("%d", &n)
    for (int i = 15; i >= 0; i--) {     // 从最高位（15）往最低位（0）扫
        cout << ((n >> i) & 1);         // 右移 i 位把目标位顶到第 0 位，再 & 1 取出
    }
    cout << endl;                       // C 等价：printf("\n")
    return 0;
}
```

逐段讲：`(n >> i)` 把第 i 位搬到第 0 位；`& 1` 把第 0 位之外的 31 个位全部清零，只留目标位。输出的位数由循环上界决定（15 对应 16 位，与作业样例对齐）。

**块二·执行追踪表**（n=612，二进制 0000001001100100，只列取到 1 的位）：

| 步骤 | 当前元素 | 结构状态 | 动作 | 结果 |
|:---:|:---:|:---|:---|:---|
| 1 | i=15 | 612 = 0000001001100100 | (612>>15)&1 | 0，输出 0 |
| 2 | i=9 | 同上 | (612>>9)&1 | 1，输出 1（512 位） |
| 3 | i=6 | 同上 | (612>>6)&1 | 1，输出 1（64 位） |
| 4 | i=5 | 同上 | (612>>5)&1 | 1，输出 1（32 位） |
| 5 | i=2 | 同上 | (612>>2)&1 | 1，输出 1（4 位） |
| 6 | i=0 | 扫完 16 位 | (612>>0)&1 | 0，输出 0，结束 |

**块三·错误写法对照**（输出顺序反了）：

```diff
- for (int i = 0; i <= 15; i++) cout << ((n >> i) & 1);   // 坑：从第 0 位开始输出——低位先出，612 会打成 0010011001000000，与手写习惯完全颠倒（WA）
+ for (int i = 15; i >= 0; i--) cout << ((n >> i) & 1);   // 修复：人读二进制是最高位在左，必须从高位往低位输出
```

**⑤ 典型应用**

- 迁移题一（素材作业，p26）：输入 612，输出 0000001001100100。题解：④代码原样即为完整题解，16 位逐位右移取出。标注：课件作业，代码为自编示例。
- 迁移题二（自编）：输入一个 int，输出它的十六进制（每 4 位一组取 `((n >> (4*i)) & 15)` 映射到 `0123456789ABCDEF`）。原理与④同款，只是步长从 1 位变 4 位。
- 竞赛衔接：读题时看到"二进制串""翻转某些位"先想位存储；本题套路在 [[状压DP]] 里会升级成"一个整数存一个集合"。

**⑥ 坑点与边界**

> **【易错】** 输出二进制从第 0 位开始 → 顺序全反（④对照）。人写二进制高位在左，机器存数位权从小到大，两套习惯必须用"从高位输出"统一。

> **【注意】** 移位位数必须严格小于位宽：对 32 位 int 做 `n >> 32` 是未定义行为（不是得 0），循环上界为 15/31 时 i 最大 15/31，均安全；写 `i <= 32` 就越界了。

> [!example]-
> **边界数据集（先自己跑一遍，再展开对照）**
> 1. 空输入：无输入直接结束 → 程序不读 n 不输出，无崩溃（预期：空输出）。
> 2. 单元素：n=1 → 16 位输出 `0000000000000001`（预期：仅第 0 位为 1）。
> 3. 全相同：n=-1 → 补码全 1，输出 `1111111111111111`（预期：负数按补码位样输出，不出现负号）。
> 4. 严格递增：n=1,2,4,8 → 输出分别只有第 0/1/2/3 位为 1（预期：2 的幂与位一一对应）。
> 5. 严格递减：n=32768,16384,8192 → 第 15/14/13 位为 1（预期：高位 1 的位置随数减半左移一位）。
> 6. 极值：n=2147483647（INT_MAX）→ 32 位全 1；若循环上界写成 i<=31 对 32 位输出则 i=31 时 (n>>31)&1 合法，但 n=-2147483648 时 n>>31 得 -1（符号位补 1），&1 后仍是 1——负数右移补 1 是知识点 2 的伏笔（预期：不崩，但负数移位要懂补码）。

回扣开场：现在你能解决"把一个整数按位拆开看"的问题了——用的是"右移 i 位再 & 1"这一个动作。接下来把六个运算符一次配齐。

### 2. 六件套：与、或、异或、取反、左移、右移

前置依赖：[[#1. 进制与位：二进制世界与补码回顾]]、[[数据类型与内存表示]]（补码）
后续衔接：[[#3. lowbit 与经典技巧：x&-x、判奇偶、异或交换]]、[[状压DP]]（集合位表示的工具箱）

**① 它解决什么问题**

六个运算符就是六种"拨开关"的动作（pdf p3 目录，除概述外全部标"重点"）：`&`（按位与）、`|`（按位或）、`^`（按位异或）、`~`（按位取反）、`<<`（左移）、`>>`（右移）。它们解决的问题是**对指定的一些位做定向修改或读取，其余位原样保留**。关键性质（操作/复杂度/前提/返回值）：六个运算符均单指令完成、$O(1)$、前提是操作数按补码存储、返回值是逐位运算后的整数；其中 `<<` 与 `>>` 有算术意义——左移一位在不丢高位 1 的前提下相当于乘 2，右移一位对非负数相当于除以 2（pdf p18/p20，11<<1=22、11>>1=5，实测一致）。

**② 直觉理解**

模型级类比：**镂空的模板（掩码）**。想在木板上刻花样，先做一块只在某些位置镂空的模板盖上去——这块模板就是掩码（mask）。`&` 是"只在镂空处允许透光"（保留镂空位、清掉其余），`|` 是"只在镂空处喷漆"（置 1 其余位），`^` 是"只在镂空处翻色"（0 变 1、1 变 0）。

用课件的具体数字跑一遍（pdf p11/p14/p17）：X = `1010 1110`，Y = `0000 1111`（低 4 位镂空）：

| 运算 | 结果 | 含义 |
|:---:|:---:|:---|
| X & Y | 0000 1110 | 取出低 4 位 |
| X \| Y | 1010 1111 | 低 4 位置 1 |
| X ^ Y | 1010 0001 | 低 4 位翻转 |

**③ 原理与推导**

逐位规则各一句话：与——同时为 1 才是 1（pdf p9）；或——同时为 0 才是 0（pdf p12）；异或——相同为 0 不同为 1（pdf p15）；取反——1 变 0、0 变 1（pdf p6）。移位：左移高位丢弃、低位补 0；右移正数高位补 0、负数高位补 1（算术右移，pdf p20）。

推导三条课件用途为什么成立：

1. **判奇偶**（p11）：一个数的奇偶由第 0 位唯一决定，`a & 1` 把其余 31 位清零只留第 0 位——第 0 位是 1 即奇数。等价性已实测：$-5$ 到 $5$ 逐个比对 `(a & 1) != 0` 与 `a % 2 != 0` 全部一致（附录 B-5 第 1 组）。
2. **清最低位**（p8）：`a & ~1`，`~1 = 1111...1110`，与运算后最低位必为 0。课件同时提醒：`~` 的优先级比算术、关系、逻辑运算符都高，所以 `a & ~1` 不需要括号——**为什么这里强调优先级**？因为同为位运算的 `&` 优先级却低于 `==`，坑在④对照里等着。
3. **移位即乘除**（p18）：$x << k$ 把每个位的权都乘 $2^k$，整数的值就是各为 1 的位的权之和，所以值也乘 $2^k$——前提是被丢掉的高位里没有 1。

设计动机：为什么把"取指定位"设计成"先移位再与"两步而不是一步？因为硬件的与运算器是全位并行的，"第 i 位"对它没有特殊性——把它移到统一的第 0 位，一套电路通吃所有位，这是硬件简单性换来的软件写法。

**④ 代码演示**

**块一·核心代码**（自编示例，数值全部取自课件 p11/p14/p17/p19/p21 的演示数据；课堂代码 code.cpp 的对应片段为判奇偶与移位）：

```cpp
#include <iostream>
using namespace std;
int main() {
    int x = 0xAE;                       // 1010 1110，课件 p11 的 X
    cout << (x & 0x0F) << endl;         // 14 ：取低 4 位（p11）
    cout << (x | 0x0F) << endl;         // 175：低 4 位置 1（p14）
    cout << (x ^ 0x0F) << endl;         // 161：低 4 位翻转（p17）
    cout << (11 << 1) << endl;          // 22 ：左移乘 2（p19）
    cout << (11 >> 1) << endl;          // 5  ：右移除 2（p21）
    cout << (-11 >> 1) << endl;         // -6 ：负数右移补 1（实测）
    int num = 130;
    if (num & 1) cout << "奇数" << endl;  // code.cpp 原片段：非 0 即真
    else cout << "偶数" << endl;
    return 0;
}
```

实测输出：14 / 175 / 161 / 22 / 5 / -6 / 奇数（附录 B-5）。

**块二·执行追踪表**（X=1010 1110 与 Y=0000 1111 的三种掩码运算，逐位走）：

| 步骤 | 当前元素 | 结构状态 | 动作 | 结果 |
|:---:|:---:|:---|:---|:---|
| 1 | 第 7-4 位 | X=1010, Y=0000 | 逐位与/或/异或 | 与:0000 或:1010 异或:1010 |
| 2 | 第 3 位 | X=1, Y=1 | 与=1 或=1 异或=0 | 三结果的第 3 位 |
| 3 | 第 2 位 | X=1, Y=1 | 同上 | 与:1 或:1 异或:0 |
| 4 | 第 1 位 | X=1, Y=1 | 同上 | 与:1 或:1 异或:0 |
| 5 | 第 0 位 | X=0, Y=1 | 与=0 或=1 异或=1 | 汇总 00001110/10101111/10100001 |

**块三·错误写法对照**（优先级坑与"以为移位改了原值"）：

```diff
- if (x & 3 == 1) ...        // 坑1：== 优先级高于 &，实际算的是 x & (3==1) 即 x & 0，恒为 0（答案错）
+ if ((x & 3) == 1) ...      // 修复：& 与 == 混用时给 & 加括号；对比 ~1 不用括号（~优先级最高）
- int a = 6; a << 2;         // 坑2：移位是表达式，返回新值，a 仍是 6（逻辑失效）
+ a = a << 2;                // 修复：要改原值就赋回去，或用复合赋值 a <<= 2（课件 p22"位运算赋值运算符"）
```

**⑤ 典型应用**

- 迁移题一（自编）：输入 n 和 k（$1 \le n \le 10^9$，$0 \le k \le 30$），输出 n 的二进制第 k 位。题解：`(n >> k) & 1`。建议先独立做，再对照题解——就是知识点 1④ 循环体的单步版。
- 迁移题二（自编）：把 n 的低 4 位清零后输出。题解：`n & ~0xF`。建议先独立做，再对照题解；对照 p8"使最低位为零"的 `a & ~1`，掩码从 1 换成 0xF。
- 竞赛衔接：`&` `|` `^` 是 [[状压DP]] 的日常——第 i 件物品选了没有，就是 `(s >> i) & 1`；把 i 加入集合是 `s | (1 << i)`。六个运算符在那边一个都不少地要用。

**⑥ 坑点与边界**

> **【易错】** `x & 3 == 1` 忘加括号（④对照坑 1）。`==` 优先级高于 `&`，这是位运算在 C 系语言里最著名的优先级陷阱。

> **【易错】** 负数右移不等于除法：`-11 >> 1 == -6` 而 `-11 / 2 == -5`（实测，附录 B-5 第 5 组）。右移是向下取整，除法是向零取整，两者只在非负数上等价——非负场景才可放心用移位代替除法。

> **【注意】** 有符号数左移把 1 移进符号位、或右移负数，标准定义为实现相关（主流编译器是算术移位）；竞赛写法是：非负数随便移，涉负数先想清楚补码，能转 `unsigned` 就转。

> [!example]-
> **边界数据集（先自己跑一遍，再展开对照）**
> 1. 空输入：不适用：六件套是运算符不是读入流程，无输入边界（预期：不涉及）。
> 2. 单元素：x=0 → x&Y=0、x\|Y=Y、x^Y=Y、0<<1=0（预期：0 是位运算的"乘零"，或/异或都原样透传 Y）。
> 3. 全相同：x=0xFFFFFFFF（-1）→ x&1=1 判奇、-1>>1=-1（预期：全 1 的位样不因右移缩小）。
> 4. 严格递增：x=1,2,4,8 → x&1 全 0（全偶）、x&(x-1) 全 0（伏笔：这是"2 的幂"判据，知识点 3 续）（预期：规律一致）。
> 5. 严格递减：x=-1,-2,-4 → -1>>1=-1、-2>>1=-1、-4>>1=-2（预期：负数右移向下取整，数值逐次变大约一半）。
> 6. 极值：x=INT_MAX（2147483647）→ x&1=1；x=INT_MIN 右移 31 位得 -1（符号位铺满）；INT_MAX<<1 溢出为 -2（预期：溢出可预期但不崩溃，最高位 1 被移丢）。

回扣开场：六个"拨开关"的动作已经配齐——与取位、或置一、异或翻转、取反求补、移位乘除。现在你能解决"定向改位"的所有问题了，接下来拿它们组装竞赛技巧。

### 3. lowbit 与经典技巧：x&-x、判奇偶、异或交换

前置依赖：[[#2. 六件套：与、或、异或、取反、左移、右移]]、[[#1. 进制与位：二进制世界与补码回顾]]
后续衔接：[[#4. 位运算的复杂度账与竞赛用法]]、[[状压DP]]（lowbit 是其统计工具）

**① 它解决什么问题**

三个高频小技巧打包：**lowbit**（取一个数二进制最低位的 1 所在的位权，写法 `x & -x`——资料未覆盖，属补充）；**判奇偶**（`a & 1`，课件 p11）；**异或交换**（`a^=b; b^=a; a^=b;`，课件 p17/p23-24）。三者共同的卖点：把一件需要"循环逐位扫"的事压成一条表达式，$O(1)$ 完成。课堂代码 code.cpp 的主体正是异或交换：100 与 200 交换后输出 `num1 = 200 num2 = 100`，实测一致（附录 B-5）。

**② 直觉理解**

模型级类比：**负镜像求交**。lowbit 的直觉：把 x 和它的"负镜像" -x 叠在一起看，两者除了最低位的那个 1 完全互补，交在一起就只剩它。生活版：x 是一排亮灯里最靠左的一盏亮着，-x 是把所有灯翻个面再在最左亮的那盏下面垫一张纸——两排对齐，唯一都亮的位置就是最低位的 1。

用具体数字跑一遍：x = 12 = `1100`，-12 的补码 = `...0100`（取反得 `...0011`，加一得 `...0100`）。`12 & -12 = 0100 = 4`。实测 `12 & -12 == 4`、`612 & -612 == 4`（612 = `1001100100`，最低位 1 在 4 那一格）。

**③ 原理与推导**

lowbit 为什么对：设 x 的二进制形如 `...A 1 0...0`（A 是第 k 位以上的任意位，第 k 位是最低位的 1，后面全是 0）。按"负数 = 取反加一"分两段算 -x：第 k 位以上的 A 段取反；第 k 位本身取反得 0，但低 k 位全 0 加一进位正好把第 k 位顶回 1；第 k 位以下仍是 0。于是 x 与 -x 只在第 k 位同为 1，与起来就是 $2^k$。

**设计动机**：为什么树状数组、集合统计都靠 lowbit 而不是自己写循环找最低位 1？因为一次 `x & -x` 一条指令，而循环逐位找是 $O(\log x)$；且 lowbit 天然给出"以 2 的幂计的块大小"，正好对应树状数组的分层结构。

异或交换为什么对：三步代换，记初始 a=x、b=y。第一步 `a ^= b` 后 a=x^y；第二步 `b ^= a` 后 b = y^(x^y) = x（异或满足交换结合，且 y^y=0）；第三步 `a ^= b` 后 a = x^y^x = y。全程只用异或的两条性质：**与 0 异或不变、自己异或自己得 0**（课件 p17 用途 2）。

**④ 代码演示**

**块一·核心代码**（取自课堂代码 code.cpp 交换段；改动：仅补注释与初始化形式，逻辑逐行原样）：

```cpp
int num1 = 100, num2 = 200;          // 素材原值
num1 ^= num2;                        // num1 = 100 ^ 200 = 172
num2 ^= num1;                        // num2 = 200 ^ 172 = 100
num1 ^= num2;                        // num1 = 172 ^ 100 = 200
// 此刻 num1=200, num2=100，交换完成（实测输出 num1 = 200  num2 = 100）
int num = 12;
cout << (num & -num) << endl;        // 4：lowbit（自编示例）
if ((num & 1) == 0) cout << "偶数";  // 判偶（p11 写法，加括号防坑）
```

**块二·执行追踪表**（num1=100=`0110 0100`，num2=200=`1100 1000`，8 位视图）：

| 步骤 | 当前元素 | 结构状态 | 动作 | 结果 |
|:---:|:---:|:---|:---|:---|
| 1 | num1^=num2 | num1=01100100, num2=11001000 | 逐位异或 | num1=10101100(172), num2=200 |
| 2 | num2^=num1 | num1=172 | 200^172 逐位 | num2=01100100(100) |
| 3 | num1^=num2 | num2=100 | 172^100 逐位 | num1=11001000(200) |

**块三·错误写法对照**：

```diff
- void mySwap(int a, int b) { a^=b; b^=a; a^=b; }   // 坑1：传值形参——交换的是副本，调用方两个变量纹丝不动（逻辑失效）
+ mySwap(x, y) 里用 C++ 引用参数 int &a, int &b，或全局/指针传递；纯 C 写法 swap(&x,&y) 用 int* 解引用
- int *p = &x; *p ^= *p;   // 坑2：对同一地址自交换——x^x=0，x 被清成 0（答案错）
+ 异或交换的前提是两个独立的存储位置；同一变量先用临时变量交换
- if (num & 1 == 0) ...    // 坑3：== 优先级高于 &，等于 num & 0，恒假（答案错）
+ if ((num & 1) == 0) ...  // 知识点 2④ 坑 1 的复现：& 与 == 同现必加括号
```

**⑤ 典型应用**

- 迁移题一（自编）：统计 n（$1 \le n \le 10^9$）二进制里 1 的个数。题解：`while (n) { cnt++; n &= n - 1; }`——`n & (n-1)` 每次恰好消掉最低位的 1（12&11=8 消掉 4），循环次数就是 1 的个数。建议先独立做，再对照题解。
- 迁移题二（自编）：判断 n 是不是 2 的幂。题解：`n > 0 && (n & (n - 1)) == 0`——2 的幂的二进制只有一个 1，消掉即 0。建议先独立做，再对照题解。
- 竞赛衔接：lowbit 是树状数组单点修改与前缀查询的核心步（`i += i & -i` 与 `i -= i & -i`）；判奇偶在卡常题里代替 `%2`；异或还有"找出只出现一次的数"（全部数互相异或，成对的全消掉）这类经典题。

**⑥ 坑点与边界**

> **【易错】** 异或交换用到同一地址（`*p ^= *p`）→ 中间态 x^x=0 把原值抹掉，得 0（④对照坑 2）。两个独立变量才安全。

> **【易错】** lowbit 对 0 求值：0 & -0 = 0，而 $2^k$ 里不存在 0——树状数组里下标从 1 开始正是为了避开 lowbit(0) 死循环（`i -= i & -i` 在 0 上原地踏步，死循环）。

> **【注意】** lowbit 依赖"负数 = 取反加一"的补码机制，只对非负整数有意义（负数的 lowbit 仍能算出但不对应"最低位 1 的位权"这一语义）；统计 1 的个数同理要先转 unsigned。

> [!example]-
> **边界数据集（先自己跑一遍，再展开对照）**
> 1. 空输入：不适用：技巧都是表达式，无输入流程（预期：不涉及）。
> 2. 单元素：x=1 → lowbit(1)=1；x&1=1 判奇（预期：最低位 1 就是它自己）。
> 3. 全相同：交换 a 与 a（不同地址、同值）→ a^a=0 第一步就清零，最终两变量都是 0（预期：值相同≠地址不同，坑 2 的温和版）。
> 4. 严格递增：x=1,2,4,8 → lowbit 依次 1,2,4,8（预期：2 的幂的 lowbit 是自身）。
> 5. 严格递减：x=12,6,3 → lowbit 依次 4,2,1（预期：每次 n&=n-1 恰消一个 1：12→8→0 共 2 个 1）。
> 6. 极值：x=2147483647（31 个 1）→ lowbit=1；x=-2147483648（INT_MIN，`100...0`）→ lowbit 取绝对值位样得 -2147483648（int 内再无更大 2 的幂）；统计 1 的个数须用 unsigned 否则 INT_MIN 右移补 1 不终止（预期：负数场景用 unsigned 化解）。

回扣开场：判奇偶、交换、lowbit 三个技巧现在都装进了口袋——尤其是 lowbit，它是知识点 4 复杂度账里"位运算能省多少"的最佳证人。

### 4. 位运算的复杂度账与竞赛用法

前置依赖：[[#2. 六件套：与、或、异或、取反、左移、右移]]、[[#3. lowbit 与经典技巧：x&-x、判奇偶、异或交换]]
后续衔接：[[状压DP]]（一个整数存一个集合）、[[预处理命令]]（宏与位运算常量的组合，已学）

**① 它解决什么问题**

前面的技巧都是"单点省指令"，这一节回答更竞赛的问题：**位运算在整道题的复杂度账里省出多少**。三个层级的账：一是单操作级——`a & 1` 代替 `a % 2`，一条与指令代替一条除法指令，除法在主流 CPU 上的指令耗时通常是位运算的数十倍量级（这一段我不确定精确倍数，与具体架构有关，量级结论是稳的）；二是状态级——一个 int 存 31 个 0/1 开关，$2^{31}$ 量级的"集合状态"只占 4 字节；三是枚举级——`1 << n` 一步铺出 n 元素集合的全部 $2^n$ 个子集。本知识点把前三个知识点串成竞赛武器库，并交代它的边界：n 超过 30（int）或 62（long long）位运算枚举直接失效。

**② 直觉理解**

模型级类比：**点菜单的勾选栏**。20 道菜每道"要/不要"，不用 20 张纸，一张纸上 20 个格子打勾就够了——一个 20 位的整数就是这张纸。遍历"所有可能的勾法"，就是把 0 到 $2^{20}-1$ 每个整数看一遍：整数 s 的第 i 位是 1，就当第 i 道菜被勾选。

用具体数字跑一遍：n=3，s 从 0 到 7：s=0（都不选）、s=1（选 0 号）、s=2（选 1 号）、s=3（选 0 和 1）……s=7（全选）。$2^3 = 8$ 个整数恰好对应 8 个子集，一个不多一个不少。

**③ 原理与推导**

二进制枚举的正确性推导：n 元素集合的子集与 n 位 0/1 串一一对应（每位"选/不选"二选一），n 位 0/1 串共 $2^n$ 个，其值域恰是 $[0, 2^n - 1]$；而"取第 i 位"用 `(s >> i) & 1`（知识点 1④），"并入元素 i"用 `s | (1 << i)`（知识点 2）。三条已学结论拼起来，枚举框架就成立了。

**复杂度账**：枚举所有子集 $O(2^n)$，对每个子集逐位检查 $O(n)$，总 $O(2^n \cdot n)$；n=20 时约 $2 \times 10^7$ 次操作，1 秒内轻松跑完；n=26 约 $1.8 \times 10^9$，贴线；n=30 约 $3.2 \times 10^{10}$，超时。**为什么 int 的上限是 n=30**：`1 << 30` 以内的数不超 int 上限，`1 << 31` 在 32 位 int 上是负数——位宽就是枚举的硬边界。

**④ 代码演示**

**块一·核心代码**（自编示例：n 件物品，输出每个子集的成员编号）：

```cpp
#include <iostream>
using namespace std;
int main() {
    int n; cin >> n;                    // n <= 20，int 上限内
    for (int s = 0; s < (1 << n); s++) {   // 1<<n == 2^n：全部子集
        cout << "{ ";
        for (int i = 0; i < n; i++) {
            if ((s >> i) & 1) cout << i << " ";   // 第 i 位为 1：i 在集合里
        }
        cout << "}" << endl;
    }
    return 0;
}
```

实测 n=3 输出 8 行，与②的手推一致（附录 B-5）。

**块二·执行追踪表**（n=3，s 逐个展开）：

| 步骤 | 当前元素 | 结构状态 | 动作 | 结果 |
|:---:|:---:|:---|:---|:---|
| 1 | s=0 | 000 | 三位全查 | 输出 { } |
| 2 | s=1 | 001 | 第 0 位为 1 | 输出 { 0 } |
| 3 | s=2 | 010 | 第 1 位为 1 | 输出 { 1 } |
| 4 | s=5 | 101 | 第 0、2 位为 1 | 输出 { 0 2 } |
| 5 | s=7 | 111 | 三位全 1 | 输出 { 0 1 2 }，枚举结束 |

**块三·错误写法对照**：

```diff
- for (int s = 0; s < (1 << n); s++)   // 坑1：n=31 时 1<<31 是负数，s < 负数，循环体一次都不执行（逻辑失效）
+ n <= 30 用 int；n 到 62 用 long long：1LL << n；n 再大，位运算枚举这条路不通，换搜索
- if (s >> i & 1) ...       // 坑2：>> 优先级低于算术但这里无碍；若写成 1 << i - 1 则是 1<<(i-1)——减法优先级高于移位（答案错）
+ 涉算术与移位混用一律加括号：(1 << i) - 1
```

**⑤ 典型应用**

- 迁移题一（自编）：n（$n \le 15$）个物品各有重量，问所有"总重恰好为 W"的取法数。题解：二进制枚举每个子集、逐位累加判等，$O(2^n \cdot n)$。建议先独立做，再对照题解。
- 迁移题二（自编）：n 人（$n \le 12$）两两有"认识矩阵"，求最大的"互相都认识"的人群大小。题解：枚举每个子集 s，先检查 s 内每对人是否认识（$O(n^2)$），再取最大——这是 [[状压DP]] 与"极大团"枚举的毛坯版。建议先独立做，再对照题解。
- 竞赛衔接说明：位运算在竞赛里的四大驻地——[[状压DP]]（集合状态与转移）、树状数组（lowbit）、快速幂（指数逐位拆解，洛谷 P1226【模板】快速幂是其板子题，题号真实）、二进制枚举（本节）；另常见于"判断 2 的幂""找单独的数"等脑筋题。

**⑥ 坑点与边界**

> **【易错】** `1 << n` 在 n=31 及以上溢出 int（④对照坑 1）。写位运算枚举先问自己：n 的上限是多少位？30 以内 int，62 以内 `1LL << n`。

> **【易错】** 算术与移位混用不加括号：`1 << i - 1` 实为 `1 << (i - 1)`（④对照坑 2）。减法优先级高于移位，移位高于比较（`==`），但 `&` 低于 `==`——一张优先级雷区表考前过一遍。

> **【注意】** $O(2^n \cdot n)$ 的适用边界就是 n=20 到 26：出题人给 n≤20 就是明示枚举，给 n≤10^5 就绝不能枚举——先看数据范围再选武器。

> [!example]-
> **边界数据集（先自己跑一遍，再展开对照）**
> 1. 空输入：n=0 → 1<<0 = 1，s 只取 0，输出一个空集 { }（预期：$2^0=1$ 个子集，恰为空集）。
> 2. 单元素：n=1 → 输出 { } 与 { 0 } 两行（预期：2 个子集）。
> 3. 全相同：不适用：枚举与元素值无关，只与个数有关（预期：不涉及）。
> 4. 严格递增：n=1,2,3 → 输出行数 2,4,8（预期：行数 = 2^n 严格翻倍）。
> 5. 严格递减：n=3,2,1 → 同上逆序（预期：对称验证）。
> 6. 极值：n=30 → (1<<30)-1 = 1073741823 个子集，枚举不崩但跑不完（量级 $10^9$ 以上）；n=31 → 1<<31 为负，循环零次（预期：坑 1 的实测复现）。

回扣开场：现在你能解决开场那个"20 件物品选不选"的问题了——用的是本节"一个整数存一个集合"加 `1 << n` 枚举（③的结论）；而"为什么位运算快"的账，也在单操作、状态、枚举三个层级算清了。

## 四、总结与自测

### 核心内容（一页纸速览）

- **进制与位**：一个 int 是 32 个 0/1 开关；补码两条结论——负数 = 取反加一、$\sim x = -1 - x$；"右移 i 位再 & 1"是读任意一位的万能动作。
- **六件套**：`&` 取位/清零、`|` 置一、`^` 翻转、`~` 取反、`<<`/`>>` 乘除 2（前提：不丢高位 1 / 非负数）；掩码 = 镂空模板，模板位由 0xF 之类的常量给出。
- **经典技巧**：判奇偶 `a & 1`；异或交换三连（两独立变量才安全）；lowbit `x & -x` 取最低位 1（补章：资料未覆盖）；`n & (n-1)` 消最低位 1，用于统计 1 的个数与判 2 的幂。
- **复杂度账**：单操作 $O(1)$ 且指令快于除法；一个整数存 31/63 个开关；二进制枚举 $O(2^n \cdot n)$，n=20 约 $2\times10^7$ 可行、n=30 不可行——先看数据范围再选武器。
- **课件两处口径修正**：p4"加减乘除都叫位运算"按通识修正（见 A-3）；p18 左移乘 2 的前提是丢弃的高位不含 1。
