# Dijkstra 与 SPFA

## 一、为什么需要它

先用你大概率会碰壁的方式做一遍洛谷 P4779【模板】单源最短路径（标准版）：n 个点 m 条有向带权边，问起点 s 到每个点的最短距离，$n \le 10^5$、$m \le 2 \times 10^5$。暴力想法是"每次从头到尾扫一遍所有点，找当前看起来最近的"——朴素 Dijkstra 每轮 $O(n)$ 找最小、共 n 轮，$O(n^2) = 10^{10}$ 量级，必超时。**碰壁的根源：每轮"找未确定点中 dis 最小的那个"花了 $O(n)$。**（碰壁场景为自构：P4779 是本篇素材例题，朴素复杂度按 A 源 slide 1 的 $O(|V|^2)$ 计。）

破法按对象分三路：换数据结构——用小根堆把"找最小"降到 $O(\log n)$，得到 $O((n+m)\log n)$ 的堆优化 Dijkstra（知识点 2）；换算法骨架——从 Bellman-Ford 的"整轮松弛"改成"只松弛刚被更新的点"，得到 SPFA，顺带兼容负边权（知识点 3）；换问题规模——要所有点对之间的距离时，直接上 Floyd 的中转点 dp（知识点 4）。最后回答一个贯穿全篇的问题：为什么 Dijkstra 一遇到负边权就答案错（知识点 5）。

## 二、知识点逐讲（每个知识点一节，共 5 节）

### 1. Dijkstra 贪心与确定集：朴素 O(n^2) 实现

前置依赖：[[图的概念存储与遍历]]（邻接矩阵、边权、出边概念）、数组与循环（C 基础）
后续衔接：[[#2. 堆优化 Dijkstra：优先队列找最小]]、[[#5. 负权场景与选型：Dijkstra 为什么不能负权]]

**① 它解决什么问题**

B 源 Dijkstra算法代码.c 头注：n（<=100）个点、m 条边的带权**无向**图，求起点 s 到其他点的最短路径。Dijkstra 是**单源最短路**算法——起点只有一个，一次运行算出 s 到全部点的最短距离（A 源 slide 1）。它维护 dis[v]（s 到 v 的当前最短距离）与 flag/标记数组，核心性质表：

| 操作 | 复杂度 | 前提 | 产出 |
|------|--------|------|------|
| 选未确定点中 dis 最小 | $O(n)$ | 无负边权 | 该点距离定终身 |
| 用新确定点松弛出边 | $O(n)$（矩阵） | 邻接矩阵存图 | 更新邻居 dis |
| 全部 n 轮合计 | $O(n^2)$ | 无负边权（A 源 slide 1） | dis 数组即答案 |

**② 直觉理解**

模型级类比：**修路队圈地**。修路队从起点出发，地图上每个城市写着"当前已知的最短修路里程"。每一步，修路队把**当前里程最小的未定城市**宣布为"里程定死、以后不再改"（确定集扩一格），然后以它为中转站，看看借道它去别的城市能不能更短。小数据推演（P4779 官方样例，4 点 6 边：1→2 权 2、2→3 权 2、2→4 权 1、1→3 权 5、3→4 权 3、1→4 权 4）：起点 1 的出边直接给出 dis=[0,2,5,4]；未确定中最小是 2（里程 2），借道 2 后 3 号降到 4、4 号降到 3；再定 4（3），再定 3（4）——全表 [0,2,4,3]，实测输出与官方一致（附录 B-5）。

**③ 原理与推导**

贪心正确性的归纳证明（关键在**无负边权**）：归纳假设"已确定点的 dis 就是真最短路"。看未确定点中 dis 最小的 u：任何一条 s 到 u 的、真正更短的路径，都必须先经过某个**未确定**点 x（否则与归纳假设矛盾——已确定点的 dis 已无法再改进）；而按定义 $\text{dis}[x] \ge \text{dis}[u]$，且从 x 继续走到 u 的剩余边权和非负，所以这条"更短路径"总长至少 $\text{dis}[u]$——不可能更短。故 u 的 dis 定终身。

**设计动机：为什么必须维护确定集？** 因为松弛只能保证"当前已知最优"，不能保证"永久最优"；一旦某个点的 dis 被宣布定局，后续松弛就不再碰它——这一"不再碰"正是上面归纳证明能成立的前提，也是 $O(n^2)$ 复杂度里"每轮确定一个、共 n 轮"的来源（B 源注释原话：每次确定"起点到一个点的最短距离"）。B 源还用 pre[i] 记录前驱、输出整条路径：松弛成立时 `pre[i]=k`，路径从终点沿 pre 回爬到起点（实测 9 点样例路径 `0到8: 8 7 6 3 4 2 1 0`，附录 B-5）。

```text
朴素 Dijkstra 一轮（B 源结构）：
选最小未确定 u  ──>  flag[u]=1（定终身）  ──>  对每个 i：若 flag[i]=0 且 dist[u]+g[u][i] < dist[i]
                                              则 dist[i] = dist[u]+g[u][i]（并记 pre[i]=u）
共执行 n-1 轮（起点自身在初始化时已确定）
```

**④ 代码演示**

取自源文件 Dijkstra算法代码.c（B 源，改动：删去全局变量 v 的"存在不可达点"提示分支与输出路径的打印段——路径输出逻辑已在③文字交代；点编号 0 起，邻接矩阵存无向图；其余逻辑逐行原样）：

```cpp
#include <stdio.h>
#include <string.h>
#define INF 10001              // 前提：边权 < 10000，INF 取 10001 贴线够用
int n, m;
int g[105][105];               // 邻接矩阵：g[u][v] 存边权，INF 表示无边
int dist[105], flag[105], pre[105];
void Dijkstra(int s) {         // 复杂度：O(n^2)
    dist[s] = 0;
    flag[s] = 1;               // 起点先确定
    for (int i = 0; i < n; i++)
        if (g[s][i] < INF) {   // i 是 s 的邻接点：直接继承边权
            dist[i] = g[s][i];
            pre[i] = s;
        }
    pre[s] = -1;               // 路径回爬的终点标志
    for (int j = 1; j <= n - 1; j++) {   // 共 n-1 轮，每轮确定一个点
        int k = -1, minn = INF;
        for (int i = 0; i < n; i++)      // O(n) 扫描找未确定点中 dis 最小
            if (flag[i] == 0 && dist[i] < minn) { k = i; minn = dist[i]; }
        if (k == -1) break;    // 剩余点全部不可达，提前收工
        flag[k] = 1;           // k 的距离定终身
        for (int i = 0; i < n; i++)      // 用 k 松弛所有未确定邻居
            if (flag[i] == 0 && dist[k] + g[k][i] < dist[i]) {
                dist[i] = dist[k] + g[k][i];
                pre[i] = k;    // 记路径
            }
    }
}
```

**执行追踪表**（P4779 官方样例改用本节朴素逻辑跑，有向 4 点，s=1；dist 下标 1..4）：

| 步骤 | 当前元素 | 结构状态 | 动作 | 结果 |
|:---:|:---:|:---|:---|:---|
| 1 | 初始化 | flag={1}，dist=[0,2,5,4] | 起点 1 的出边直接松弛 | 2/3/4 得初值 2/5/4 |
| 2 | 未确定 {2,3,4} | dist=[0,2,5,4] | 选最小 2（dist=2），确定并松弛 | dist3=4、dist4=3 |
| 3 | 未确定 {3,4} | dist=[0,2,4,3] | 选最小 4（dist=3），确定并松弛 | 4 无出边，无变化 |
| 4 | 未确定 {3} | dist=[0,2,4,3] | 选 3，确定并松弛 | 3→4 已确定，跳过 |

**⑤ 典型应用**

- 真题：洛谷 P4779【模板】单源最短路径（标准版）（A 源 P4779.cpp 文件内注释保留了同构的朴素版）——但 $n \le 10^5$ 下 $O(n^2)$ 是 $10^{10}$ 量级，朴素版在该题 TLE，须升级知识点 2；它恰好是"朴素为什么不够用"的活教材。
- 真题：洛谷 P3371【模板】单源最短路径（弱化版）——$n \le 10^4$ 时 $O(n^2) = 10^8$ 量级可过，但 $m \le 5 \times 10^5$ 下邻接矩阵内存不可行（$10^8$ 个 int 约 400MB），需换邻接表存储；出处：洛谷题目数据范围（附录 B-1）。
- 迁移题（自编）：n 个村子 m 条无向路，问起点到各村最短里程并输出其中一个村的完整路径。数据范围 $n \le 500$。题解：B 源矩阵版原样适用——先跑 Dijkstra，再从目标村沿 pre 回爬打印；建议先独立做，再对照题解（题解即④代码 + ③的 pre 回爬一段）。

**⑥ 坑点与边界**

> **【易错】** 松弛时漏判 `flag[i]==0`。后果：已确定点的 dis 被改写，"定终身"承诺破产，答案错（④对照坑 1）。

> **【易错】** 无向图只建一条有向边。后果：反向不可达，部分点 dist 停在 INF（④对照坑 2）。

> **【注意】** B 源的 INF=10001 是"贴线设计"：依赖题面保证边权 < 10000。若照抄到边权 $10^9$ 的题，INF 处处被击穿，松弛逻辑全乱——INF 必须大于"任何可能出现的真实距离"。

> [!example]-
> **边界数据集（先自己跑一遍，再展开对照）**
> 1. 空输入：n=1, m=0 → 主循环 n-1=0 轮，dist=[0]，无输出内容（预期：仅起点，距离 0，不崩）。
> 2. 单元素：n=1, s=0 → dist[0]=0，flag[0]=1，一轮循环都不到（预期：输出 0）。
> 3. 全相同：m 条重边同权（邻接矩阵后写覆盖前写，恰好同值）→ 结果与单边一致（预期：幂等；若重边不同权，后写覆盖前写可能丢掉更短的边——A-3 登记 4 的隐患，一般题面保证无重边或取 min）。
> 4. 严格递增：点按 0,1,2… 编号且边权递增的链 → 每轮选出的恰好是下一个编号，最优顺序（预期：n-1 轮跑满，结果正确）。
> 5. 严格递减：边权递减的链 → 同样正确，只是松弛方向反过来（预期：结果正确；贪心与编号大小无关）。
> 6. 极值：边权 9999（贴近 B 源上限）链式累加，n=100 → 最长距离约 $10^6$，int 无溢出；若边权放宽到 $10^9$、n=100，链和达 $10^{11}$ 超 int——dist 须 long long（预期：防溢出）。

回扣开场：朴素 Dijkstra 把"每次全表扫最小"做成 $O(n^2)$，P4779 的 $10^{10}$ 量级就是死在这里。现在你能解决"小图怎么求单源最短路"，下一节专治"找最小太慢"。

### 2. 堆优化 Dijkstra：优先队列找最小

前置依赖：[[#1. Dijkstra 贪心与确定集：朴素 O(n^2) 实现]]、[[栈与队列]]（堆与队列的形态对比）、[[图的概念存储与遍历]]（链式前向星存图）
后续衔接：[[#3. SPFA：队列松弛与负环检测]]、[[#5. 负权场景与选型：Dijkstra 为什么不能负权]]

**① 它解决什么问题**

A 源 slide 2-3 连问三句："如何找到 dis[i] 值最小的 i？遍历 O(n)。如何快速找到？用小根堆进行优化，即用优先队列 O(log n)。如何快速遍历 i 点的邻接点？链式前向星（邻接表）存图。"两刀下去，朴素 Dijkstra 的 $O(n^2)$ 降到 $O((|V|+|E|)\log|V|)$（slide 3 原文）。P4779 的 $n \le 10^5$、$m \le 2 \times 10^5$ 在此复杂度下约 $3 \times 10^5 \times 17 \approx 5 \times 10^6$ 次堆操作，轻松通过。性质表：

| 操作 | 复杂度 | 前提 | 返回 |
|------|--------|------|------|
| 堆顶取最小 | $O(\log n)$ | pair(距离,点) 进堆 | 当前最近点 |
| 松弛成功后入堆 | $O(\log n)$ | 无负边权 | 副本稍后出堆 |
| 全流程 | $O((n+m)\log n)$ | 无负边权（A 源 slide 1/5） | dis 数组即答案 |

**② 直觉理解**

模型级类比：**医院叫号系统**。每个病人挂号时写下"预估等待成本"（pair 的 first 是 dis），叫号屏永远叫成本最低的人；他确诊（确定集扩容）后，若他的邻居因他而降低了成本，邻居就**重新取一个号**（松弛入堆）——旧号不作废，但叫到时发现人已经确诊过（v[k]==1），直接跳过。**重复取号不是 bug，是 priority_queue 不支持"改号"时的标准代偿**。小数据推演见④追踪表：P4779 样例里 (4,4)、(5,3) 两个废弃副本被依次叫到、依次跳过。

**③ 原理与推导**

堆优化的本质只换了一件事：朴素版"O(n) 扫描找最小"换成"O(log n) 堆顶弹最小"。**设计动机：为什么堆里存 pair(距离, 点编号) 且距离在前？** 因为堆按 pair 的字典序排，first 是距离才能让"dis 最小的点"浮在堆顶；点编号放 second 只是搭车传递。**为什么允许重复入堆？** priority_queue 不支持修改堆内元素（没有 decrease-key 接口），松弛变小后只能塞一个新副本；A 源 slide 3 原话："一个点可能会被更新多次而入堆多次，但是只有最后一次入堆才是正确的 dis，同时也一定是在所有入堆操作结束后才会出堆，所以直接开个数组判断有没有出堆过就好了"——副本出堆时 `v[k]==1` 就 `continue`，无效副本的松弛被跳过（P4779.cpp 的 `if(v[k]==1)continue;` 正是这句）。总复杂度账：每个点确定一次、每条边至多引发一次成功松弛、每次堆操作 $O(\log n)$，堆内元素上界 $O(m)$，合计 $O((n+m)\log n)$。

```text
堆优化 Dijkstra 主循环（P4779 结构）：
while 堆非空:
    取堆顶 (d, k)，弹堆
    若 v[k]=1 → continue（废弃副本）
    v[k]=1（k 定终身）
    沿链式前向星扫 k 的每条出边 (u, w):
        若 dis[u] > d + w → dis[u] = d + w，push (dis[u], u)
```

**④ 代码演示**

取自源文件 P4779-Dijkstra堆优化.cpp（A 源，改动：删去文件内注释保留的朴素版 dij 与多余 include，逻辑逐行原样；`#define inf 1e9+7` 的 double 字面量问题见 A-3 登记 3）：

```cpp
#include <cstdio>
#include <cstring>
#include <queue>
#include <utility>
#define ll long long
using namespace std;
int n, m, cnt, h[100005], v[100005];   // h：链式前向星头；v：出堆标记
struct Edge { int to, w, next; } e[200005];   // P4779: n<=1e5, m<=2e5
ll dis[100005];                        // dis 用 ll 防 sum 累加溢出
typedef pair<ll, int> PII;             // (距离, 点)：距离在前，堆按它排序
priority_queue<PII, vector<PII>, greater<PII> > q;   // greater：小根堆
void add(int u, int vv, int w) {       // 链式前向星建边，O(1)
    e[cnt].to = vv; e[cnt].w = w; e[cnt].next = h[u]; h[u] = cnt++;
}
void dij(int x) {
    for (int i = 1; i <= n; i++) dis[i] = 1e9 + 7;   // 无穷：大于任何真实距离
    dis[x] = 0;
    q.push(PII(dis[x], x));
    while (q.size()) {
        PII now = q.top(); q.pop();
        int k = now.second;
        if (v[k] == 1) continue;       // 废弃副本：已确定，跳过
        v[k] = 1;                      // k 的距离定终身
        for (int i = h[k]; i != -1; i = e[i].next) {
            int u = e[i].to;
            if (dis[u] > now.first + e[i].w) {   // 松弛成功
                dis[u] = now.first + e[i].w;
                q.push(PII(dis[u], u));      // 重新取号（允许重复入堆）
            }
        }
    }
}
int main() {
    memset(h, -1, sizeof(h));
```

### 3. SPFA：队列松弛与负环检测

前置依赖：[[#1. Dijkstra 贪心与确定集：朴素 O(n^2) 实现]]、[[BFS]]（队列的进出形态）、Bellman-Ford（本库《Bellman-Ford与负环》同批待产出，先文字锚定：逐轮松弛所有边的单源最短路算法，$O(nm)$）
后续衔接：[[#5. 负权场景与选型：Dijkstra 为什么不能负权]]

**① 它解决什么问题**

A 源 slide 1：Bellman-Ford 是 $O(|V||E|)$ 的单源最短路算法，"适用于出现负边权的情况，但无法处理存在负权回路的情况"。SPFA（Shortest Path Faster Algorithm）是它的队列优化：A 源 slide 4 原话——"每一轮遍历 dis 值减小的点，是上一轮 dis 值减小的点的邻接点。所以每一轮没必要遍历所有的边了，只遍历上一轮 dis 值减小的点的出边即可"。最坏仍 $O(nm)$，最好 $O(m)$，**不稳定**（slide 4）。素材 P3371.cpp 的 spfa 还顺带用 cur 数组计"起点到该点的边数"，超过 n-1 即判负环。性质表：

| 操作 | 复杂度 | 前提 | 返回 |
|------|--------|------|------|
| 出队一个点、松弛出边 | 均摊小 | dis 变化才入队 | 邻居 dis 更小 |
| 判负环 | $O(1)$/次更新 | cur[k] > n-1 即有 | false |
| 全流程 | 最坏 $O(nm)$，最好 $O(m)$ | 无负环（有负环时无最短路） | dis 数组或"有负环" |

**② 直觉理解**

模型级类比：**情报扩散**。市场上只有"刚降价"的商家才有新情报可传：一个商家被传出更低价（dis 更新）就排进队列，轮到他时把低价顺着他的进货渠道（出边）传给邻居；邻居若因此又降价，也排进队列。没有降价发生（队列空），市场出清。**和 Dijkstra 的根本区别：这里的"确定"不存在——一个商家可以多次降价、多次入队**，正因为允许多次松弛，负边权才扛得住（知识点 5 展开）。小数据推演见④追踪表（P3371 官方样例，与知识点 1、2 同一张图，三方答案一致：[0,2,4,3]）。

**③ 原理与推导**

从 Bellman-Ford 推到 SPFA（A 源 slide 3-4 的推理链）：BF 每轮对**所有**边做一次松弛，若某轮没有任何松弛成功则停；最短路存在时最多 n-1 轮（每次成功松弛使最短路的边数至少 +1），总复杂度 $O(nm)$。观察：第 i 轮里 dis 变小的点，恰是第 i-1 轮 dis 变小的点的邻接点——所以只需把"上轮变小的点"的出边松弛一遍，用队列装这些点即可，这就是 SPFA。**设计动机：为什么用"在队标记" v[]？** 同一点连续多次更新只需入队一次——它在队里躺着时又有新 dis，出队时自然用最新值松弛；不设标记会让同一时刻队列里堆满同一批点的重复副本，队列长度失控（对比：堆优化的重复入堆是跨时间的副本，SPFA 的在队标记是同时间的去重，两者解决的是不同方向的重复）。**为什么 cur[k] > n-1 能判负环？** 存在的最短路最多含 n-1 条边（n 个点、不重复经过）；cur[k] 记录"产生当前 dis[k] 的路径边数"，一旦超过 n-1，说明路径上有点被重复经过，且总权还在变小——这只可能是绕了负权回路（素材 P3371.cpp 的 `if(cur[k]>n-1)return 0;`）。

**④ 代码演示**

取自源文件 P3371-SPFA算法.cpp（A 源，改动：删去注释掉的 cin 行与含注释变量，逻辑逐行原样；P3371 保证 不可达输出 $2^{31}-1$，恰好是 INT_MAX 的十进制值，与 `dis[i]=INT_MAX` 的初始化天然对齐）：

```cpp
#include <cstdio>
#include <cstring>
#include <queue>
#include <climits>
#define ll long long
using namespace std;
int n, m, cnt, h[100005], v[100005];   // v[i]=1 表示 i 点在队列中
int cur[100005];                       // 起点到 i 的路径边数（判负环用）
struct Edge { int to, w, next; } e[500005];   // P3371: m<=5e5
ll dis[100005];
void add(int u, int vv, int w) {
    e[cnt].to = vv; e[cnt].w = w; e[cnt].next = h[u]; h[u] = cnt++;
}
bool spfa(int x) {
    for (int i = 1; i <= n; i++) { dis[i] = INT_MAX; cur[i] = 0; v[i] = 0; }
    queue<int> q;
    dis[x] = 0; v[x] = 1; q.push(x);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        v[u] = 0;                      // u 已出队，之后可再次入队
        for (int i = h[u]; i != -1; i = e[i].next) {
            int k = e[i].to;
            if (dis[k] > dis[u] + e[i].w) {      // 松弛成功
                dis[k] = dis[u] + e[i].w;
                cur[k] = cur[u] + 1;             // 路径边数 +1
                if (cur[k] > n - 1) return false; // 边数超界：有负环
                if (v[k] == 0) { q.push(k); v[k] = 1; }   // 不在队才入队
            }
        }
    }
    return true;
}
int main() {
    memset(h, -1, sizeof(h));
    int x, y, w, s;
    scanf("%d %d %d", &n, &m, &s);
    for (int i = 1; i <= m; i++) { scanf("%d %d %d", &x, &y, &w); add(x, y, w); }
    if (spfa(s) == 0) { printf("negcycle\n"); return 0; }   // 素材原样输出 INT_MAX，此处按语义改写为负环提示
    for (int i = 1; i <= n; i++) printf("%lld ", dis[i]);
    return 0;
}
```

**执行追踪表**（P3371 官方样例，s=1；出边按链式前向星倒序扫描：1 的出边依次 1→4、1→3、1→2）：

| 步骤 | 当前元素 | 结构状态 | 动作 | 结果 |
|:---:|:---:|:---|:---|:---|
| 1 | 出队 1 | 队=[1]，dis=[0,inf,inf,inf] | 松弛出边 | dis=[0,2,5,4]，队=[4,3,2] |
| 2 | 出队 4 | 队=[4,3,2] | 无出边 | 无变化 |
| 3 | 出队 3 | 队=[3,2]，dis=[0,2,5,4] | 松弛 3→4 | dis4=3 更新，4 已出队故重新入队，队=[2,4] |
| 4 | 出队 2 | 队=[2,4] | 松弛 2→4、2→3 | dis4=3 不小于 3、dis3=4 不小于 4，均不入队 |
| 5 | 出队 4 | 队=[4] | 无出边 | 队空，dis=[0,2,4,3] |

**⑤ 典型应用**

- 真题：洛谷 P3371【模板】单源最短路径（弱化版）——本知识点主战场，实测官方样例输出 `0 2 4 3`；不可达点输出 2147483647（实测 T3，附录 B-5）。注意题面背景：测试数据随机，构造数据可能卡掉 SPFA，此时移步 P4779 用堆优化 Dijkstra。
- 真题：负边权单源最短路类题（如洛谷 P3385【模板】负环，SPFA 判负环的标准板题，题号真实）——cur>n-1 判负环的 cur 机制原样适用；详细推导见本库《Bellman-Ford与负环》（同批待产出，先文字锚定）。
- 迁移题（自编）：n 个城市 m 条航班，部分航线有"补贴"（负权），问起点到各城最便宜票价；若存在越飞越便宜的环则报告。数据范围 $n \le 2000, m \le 5000$。题解：spfa 原样，返回 false 时报告负环；建议先独立做，再对照题解。

**⑥ 坑点与边界**

> **【易错】** 在队标记漏写或语义写反（v=1 当成"已处理"）。后果：队列重复副本堆积 TLE，或点永远不再入队导致答案错（④对照坑 1）——SPFA 的 v 是"在队"，出队时要清零，与堆优化 Dijkstra 的 v"已出堆"语义不同（A-3 登记 5）。

> **【易错】** dis 初值用 int 的 INT_MAX 却仍做 `dis[u]+e[i].w`。出队的 u 的 dis 必为有限值（它入过队），真正危险的是手写版把"未入队的点"也拿去松弛——初值与松弛对象要配套设计。

> **【注意】** SPFA 不稳定：A 源 slide 5 原话"各大比赛的出题人在不出现负边权时会卡 SPFA"——无负权时选堆优化 Dijkstra，负权才请 SPFA 出山（选型表见知识点 5）。

> [!example]-
> **边界数据集（先自己跑一遍，再展开对照）**
> 1. 空输入：n=1, m=0, s=1 → 队列只有 1，出队后无出边即空（预期：输出 0）。
> 2. 单元素：n=1, s=1 → 同上；此时 cur 阈值 n-1=0，任何自环更新都会触发负环判定（预期：自环权 0 亦被 cur=1>0 判负环——保守但符合"最短路不存在绕行"语义）。
> 3. 全相同：m 条 1→2 的等权边 → 第一次松弛后 dis2 定值，后续不小于（预期：幂等，队列总长可控）。
> 4. 严格递增：链上边权递增 → 每个点恰好入队一次（预期：行为接近 BFS，最好复杂度 O(m) 的形态）。
> 5. 严格递减：长边在前短边在后（1→2 权 100、1→3 权 1、3→2 权 1）→ 2 被更新两次、入队两次（预期：dis2=2，验证"多次入队"机制）。
> 6. 极值：1→2 权 $2 \times 10^9$（超 int）→ ll 的 dis 正确；若 dis 用 int，样例直接溢出（预期：防溢出）。

回扣开场：BF 的"整轮全表松弛"被裁成"只松弛刚降价的点"，负边权也扛住了。现在你能解决"带负权的单源最短路"——下一节换个目标：一次算出**所有点对**的距离。

### 4. Floyd 全源最短路：中转点 dp

前置依赖：[[#1. Dijkstra 贪心与确定集：朴素 O(n^2) 实现]]（dis 与松弛语义）、[[图的概念存储与遍历]]（邻接矩阵）
后续衔接：[[#5. 负权场景与选型：Dijkstra 为什么不能负权]]、传递闭包（延伸，非必需）

**① 它解决什么问题**

A 源 slide 1：Floyd 是 $O(|V|^3)$ 的**多源**最短路算法——一次运行得到**所有点对**之间的最短距离；"适用于出现负边权的情况，但无法处理存在负权回路的情况"。B 源 Floyd算法.c 用 dp 语义实现：`dp[i][j]` 表示"允许用前 k 个点做中转点时 i 到 j 的最短距离"。单源 × n 次 Dijkstra 也能得全源（$O(n^3)$），Floyd 的价值是**实现只有三重循环**，且天然兼容负边权。性质表：

| 操作 | 复杂度 | 前提 | 产出 |
|------|--------|------|------|
| 加入中转点 k | $O(n^2)$ | dp 矩阵现态 | 全表按"可借道 k"更新 |
| 全部 n 个中转点 | $O(n^3)$ | 无负环 | dp 即全源距离矩阵 |
| 判负环 | $O(n^2)$ | 跑完后检查 | dp[i][i] < 0 即有 |

**② 直觉理解**

模型级类比：**航线逐城开通**。开局时各城市间只有直飞票价（直连边）；航空公司每宣布"第 k 城开放为中转枢纽"，就重算一遍全表：i 到 j 可以试试"先飞 k、再从 k 飞往 j"两段拼起来是否更便宜。n 座城市全部开放后，表里就是任意两点间的最便宜票价。小数据推演（B 源 Floyd算法.c 自带样例，5 点 7 条**有向**边：1→3 权 1、1→5 权 10、2→5 权 5、2→4 权 1、3→2 权 1、3→5 权 7、4→5 权 1）：1 到 5 的直飞是 10，开放中转 3 后降到 1→3→2→…拼出的 7，开放中转 4 后进一步降到 1→3→2→4→5 的 4——追踪表见④。

**③ 原理与推导**

从三维定义推出二维滚动（B 源文件注释里恰好保留了三维版全文作对照）：设 $dp[k][i][j]$ 为"只允许前 k 个点当中转站时 i 到 j 的最短距离"。加入第 k 个中转点时，i 到 j 要么不借道 k，要么拆成 i 到 k 加 k 到 j 两段：

$$dp[k][i][j] = \min\big(dp[k-1][i][j],\ dp[k-1][i][k] + dp[k-1][k][j]\big)$$

**设计动机：为什么 k 必须放最外层、且三维能滚成二维？** 若把 k 放内层，转移读到的 $dp[i][k]$、$dp[k][j]$ 是"已经允许借道更多中转点"的值，转移定义本身被破坏。而滚动省掉一维的理由是：对角元 $dp[k][k][k]=0$ 恒成立，于是第 k 轮内 $dp[k][i][k] = \min(dp[k-1][i][k],\ dp[k-1][i][k] + 0) = dp[k-1][i][k]$（同理 $dp[k][k][j]$ 也不变）——**第 k 轮读到的两个端元永远等于第 k-1 层的值**，所以原地更新安全，B 源的二维 `dp[i][j]=minn(dp[i][j], dp[i][k]+dp[k][j])` 与三维版等价（实测：两版对同一 5 点样例输出全源矩阵一致，附录 B-5）。负环检测：跑完后若有 $dp[i][i]<0$，说明存在从 i 出发绕回 i 的负权回路（断言 T7b 实测）。

```text
Floyd 主循环（B 源结构）：for k = 1..n（中转点在最外层）
                           for i = 1..n
                             for j = 1..n
                               dp[i][j] = min(dp[i][j], dp[i][k] + dp[k][j])
```

**④ 代码演示**

取自源文件 Floyd算法.c（B 源，改动：删去注释保留的三维版全文——其完整逻辑已在③推导交代；修正一处源文件注释笔误"时间复杂度：O(n^2)"，实测三重循环应为 $O(n^3)$，见 A-3 登记 2）：

```cpp
#include <stdio.h>
#define inf 10005           // 前提：边权不超过 10000（B 源题设）
int minn(int p, int q) { return p < q ? p : q; }
int n, m;                   // 有向图，点编号 1..n
int dp[105][105];           // dp[i][j]：当前中转点集合下 i 到 j 的最短距离
int main() {
    scanf("%d %d", &n, &m);
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= n; j++) {
            dp[i][j] = inf;
            if (i == j) dp[i][j] = 0;   // 对角线为 0：滚动安全性的支柱
        }
    for (int i = 1; i <= m; i++) {
        int x, y, w;
        scanf("%d %d %d", &x, &y, &w);
        dp[x][y] = w;                   // 有向边；无向图需对称赋值
    }
    for (int k = 1; k <= n; k++)        // 中转点：最外层，逐个开放
        for (int i = 1; i <= n; i++)
            for (int j = 1; j <= n; j++)
                dp[i][j] = minn(dp[i][j], dp[i][k] + dp[k][j]);   // 复杂度：O(n^3)
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= n; j++)
            printf("%d--->%d 的最短距离是:%d\n", i, j, dp[i][j]);
    return 0;
}
```

- 迁移题（自编）：n 个路口 m 条街道（无向），问删掉任意一个路口后，其余路口对之间最短距离的最大值会不会变大。数据范围 $n \le 200$。题解：Floyd 出全源矩阵，对每个被删点 v 统计"两端都不是 v 的最大 dp 值"即可对比（忽略含 v 的行列）；建议先独立做，再对照题解。

**⑥ 坑点与边界**

> **【易错】** 中转点 k 写进内层循环。后果：转移读到"已含 k"的值，定义破坏，样例可能侥幸过、一般图必 WA（④对照坑 1）。口诀：Floyd 的 k 在最外层，"见谁让谁当驿站，一站开完全体更新"。

> **【易错】** inf 相加溢出。dp[i][k] 与 dp[k][j] 都可能是 inf，两个大 inf 相加在 int 下溢出成负数、min 误更新（④对照坑 3）。

> **【注意】** 有向/无向的建图差异：B 源 Floyd 样例是有向图（dp[x][y]=w 单向），B 源 Dijkstra 是无向图（g[x][y]=g[y][x]=w 双向）——同一批素材里两种口径并存，套模板前先看题面（A-3 登记 1）。

> [!example]-
> **边界数据集（先自己跑一遍，再展开对照）**
> 1. 空输入：n=1, m=0 → dp=[0]，输出 1 行"1--->1 的最短距离是:0"（预期：仅对角为 0）。
> 2. 单元素：n=1, s 不存在（Floyd 无起点概念）→ 全源即 1x1 矩阵（预期：0）。
> 3. 全相同：m 条重边同权 → dp[x][y] 后写覆盖前写同值（预期：幂等；不同权重边则需 dp[x][y]=min(dp[x][y],w) 防覆盖——B 源写法依赖题面无不同权重边）。
> 4. 严格递增：边权沿链递增 → 借道中转不会更便宜，dp 保持直连值（预期：无更新，验证"非负不绕路"）。
> 5. 严格递减：直飞贵、绕行便宜的阶梯图 → dp 值随 k 逐轮下降（预期：终态等于最便宜拼接，追踪表第 3、4 步即是）。
> 6. 极值：n=100 全连通、边权 10000 → 最远 $10^6$，int 无溢出；边权若 $10^9$、链长 n=100 → 距离 $10^{11}$ 超 int，dp 须改 long long（预期：防溢出）。

### 5. 负权场景与选型：Dijkstra 为什么不能负权

前置依赖：[[#1. Dijkstra 贪心与确定集：朴素 O(n^2) 实现]]、[[#2. 堆优化 Dijkstra：优先队列找最小]]、[[#3. SPFA：队列松弛与负环检测]]、[[#4. Floyd 全源最短路：中转点 dp]]
后续衔接：本库《Bellman-Ford与负环》（同批待产出，先文字锚定）、[[拓扑排序]]（DAG 上按拓扑序 DP 求最短路是负权安全的另一条路，延伸）

**① 它解决什么问题**

A 源 slide 1 与 slide 5 给出五算法总账：Floyd $O(|V|^3)$ 多源、可负边权、不可负环；Dijkstra $O(|V|^2)$ 与堆优化 $O((|V|+|E|)\log|V|)$ 单源、**不能负边权**；Bellman-Ford $O(|V||E|)$ 与 SPFA 单源、可负边权、不可负环。本知识点回答两个"为什么"：为什么 Dijkstra 见不得负边权？负边权时该选谁？这是考试里"看到负权用什么"的决策依据，也是理解知识点 1 贪心证明适用边界的收口。

**② 直觉理解**

模型级类比（承接知识点 1 的修路队）：修路队宣布"2 号城里程 1 公里、定终身"时，是相信"任何绕路都只会更长"。可一旦出现负权边，**绕路可能发补贴**——先绕到 3 号城（里程看着更远），再领一段 -2 的补贴直扑 2 号城，总里程反而更小。确定集的"定终身"承诺在负权下是空头支票。小数据推演（自编反例，实测附录 B-5 断言 T6）：4 点有向图 1→2 权 1、1→3 权 2、3→2 权 **-2**、2→4 权 1。真最短路：1 到 2 走 1→3→2 得 0，1 到 4 得 1。Dijkstra 却在 2 号点 dis=1 时就确定它，3 号点的补贴松弛来得太晚——答案错。

**③ 原理与推导**

把知识点 1 的贪心证明逐条放到负权下检验：证明关键一步是"$\text{dis}[x] \ge \text{dis}[u]$ 且剩余路径边权和**非负**，故替代路径不会更短"。负边权击碎的正是"非负"这个前提——剩余部分可以是负的，把 $\text{dis}[x] \ge \text{dis}[u]$ 的优势全部吃掉甚至反超。所以 Dijkstra 的答案错不在"流程"，而在**确定集的归纳前提失效**：先确定的点未必是真正最近的。SPFA 为什么扛得住？它没有确定集——dis 一变小就重新入队、重新松弛，等价于 Bellman-Ford 的多轮松弛被裁剪后仍保留全部必要松弛，正确性建立在"最多 n-1 轮"上而非"定终身"上。为什么两者都不能处理负环？负环上每绕一圈总权再降一点，"最短路径"根本不存在（最短路存在时最多 n-1 条边，A 源 slide 4 的推理反用），所以 BF/SPFA 只能**检测**负环（cur>n-1 或 Floyd 的 dp[i][i]<0），不能给出"最短"。

**④ 代码演示**

自编对比驱动（改动说明：把知识点 2 的 dij 与知识点 3 的 spfa 装进同一个 main，跑同一张负权图对照答案；断言程序 verify_b4_dij.cpp 的 T6 同款）：

```cpp
#include <cstring>
#include <queue>
#include <utility>
#define ll long long
using namespace std;
int cnt, h[15], v[15], cur[15], inq[15];
ll dis[15];
struct Edge { int to, w, next; } e[15];
void add(int u, int vv, int w) { e[cnt].to=vv; e[cnt].w=w; e[cnt].next=h[u]; h[u]=cnt++; }
void dij(int x, int n) {                       // 知识点 2 的堆优化版
    for (int i = 1; i <= n; i++) { dis[i] = 1e9 + 7; v[i] = 0; }
    priority_queue<pair<ll,int>, vector<pair<ll,int>>, greater<pair<ll,int>>> q;
    dis[x] = 0; q.push({dis[x], x});
    while (q.size()) {
        auto now = q.top(); q.pop();
        int k = now.second;
        if (v[k] == 1) continue;               // 此处会丢弃"补贴来的新值"的传播机会
        v[k] = 1;
        for (int i = h[k]; i != -1; i = e[i].next)
            if (dis[e[i].to] > now.first + e[i].w) {
                dis[e[i].to] = now.first + e[i].w;
                q.push({dis[e[i].to], e[i].to});
            }
    }
}
int main() {                                   // 图：1->2:1, 1->3:2, 3->2:-2, 2->4:1
    cnt = 0; memset(h, -1, sizeof(h));
    add(1,2,1); add(1,3,2); add(3,2,-2); add(2,4,1);
    dij(1, 4);
    // 实测输出：dis=[0,0,2,2]——4 号点得 2，真值是 1（错误）；2 号点碰巧被后到的 (0,2) 改对
    return 0;
}
```

|:---:|:---:|:---|:---|:---|
| 1 | 出堆 (0,1) | 堆={(0,1)} | 确定 1 | dis2=1、dis3=2，push (1,2),(2,3) |
| 2 | 出堆 (1,2) | 堆={(1,2),(2,3)} | 确定 2（dis=1 非真值） | dis4=2，push (2,4) |
| 3 | 出堆 (2,3) | 堆={(2,3),(2,4)} | 确定 3 | 3→2 补贴：dis2=0，push (0,2) |
| 4 | 出堆 (0,2) | 堆={(0,2),(2,4)} | v2==1 | 新值被丢弃，无法传播到 4 |

**错误写法对照**：

```diff

- dij(s);   // 坑1：图里有负边权，确定集前提失效（答案错，且错得悄无声息）
```

**⑤ 典型应用**

- 真题：洛谷 P4779（无负权 → 堆优化 Dijkstra）与 P3371（随机数据 SPFA 可过、构造数据可能被卡）——同一模板题的"标准/弱化"两版本身就是一张选型问卷；出处见两题题面背景。
- 真题：洛谷 P3385【模板】负环（题号真实）——SPFA 判负环（cur>n-1）或 Floyd 判 dp[i][i]<0 的直接应用。
- 迁移题（自编）：地铁换乘图，票价非负但持卡进站有 -5 元折扣边，问任意两点最小花费是否有限（即判负环后输出距离）。数据范围 $n \le 300, m \le 10^4$。题解：SPFA 判负环（有限则输出 dis），或 Floyd 后查对角线；建议先独立做，再对照题解。

**⑥ 坑点与边界**

> **【易错】** 负权图上跑 Dijkstra。后果不是崩溃而是个别点答案偏大（确定太早），且错得无声——必须靠"先查边权符号"的流程拦截（④对照坑 1）。

> **【易错】** 认为负权图上 Dijkstra 结果"碰巧对几个点"就没事。反例里 2 号点碰巧对、4 号点错——**碰巧对不等于逻辑对**，负权图一律换 SPFA。

> **【注意】** 负环与负边权是两回事：负边权图只要无负环，最短路依然存在且有限；有负环则最短路不存在，SPFA 返回 false、Floyd 出现 dp[i][i]<0，此时任何"最短距离"输出都无意义。

> [!example]-
> **边界数据集（先自己跑一遍，再展开对照）**
> 1. 空输入：n=1, m=0, s=1 → 无负权边、无更新（预期：输出 0，两算法一致）。
> 2. 单元素：n=1, 无边 → 同上；此时任何自环更新在 SPFA 里 cur=1 > n-1=0 即判负环（预期：保守报负环）。
> 3. 全相同：负权边全部同值且不成环 → 各点一次更新（预期：SPFA 一次出清，结果与手推一致）。
> 4. 严格递增：正权递增链 → Dijkstra 与 SPFA 结果一致（预期：对拍 200 张随机图之一的一般形态，T5 实测一致）。
> 5. 严格递减：先正权长边后负权短路 → Dijkstra 在确定顺序上出错、SPFA 正确（预期：即④反例的放大版）。
> 6. 极值：负权边 $-10^9$、链长 100 → 距离 $-10^{11}$，int 溢出（预期：ll 的 dis 正确；负方向同样要防溢出）。

回扣开场：知识点 1 的"碰壁"在 P4779 上是复杂度问题，这一节的"碰壁"在负权图上是正确性问题——用的是③里对贪心证明前提的逐条检验。现在五个知识点连成一张选型网，你能对任何一张最短路图说出"该派谁上场、为什么"。

## 四、总结与自测

### 核心内容（一页纸速览）

- **Dijkstra 朴素**：贪心确定集——每轮把未确定点中 dis 最小者定终身，再松弛其出边；无负权下正确（归纳证明），复杂度 $O(n^2)$（B 源矩阵版 + A 源注释版两版同构）。
- **堆优化 Dijkstra**：堆把"找最小"降到 $O(\log n)$；pair(距离,点) 允许重复入堆、出堆时 v[] 淘汰废弃副本；总复杂度 $O((n+m)\log n)$，P4779 官方样例 `0 2 4 3`。
- **SPFA**：Bellman-Ford 的队列优化——只松弛"上轮 dis 变小的点"的出边；v[] 是"在队"标记（与堆版"已出堆"语义不同）；cur>n-1 判负环；最坏 $O(nm)$、最好 $O(m)$、不稳定。
- **Floyd**：中转点逐个开放的 dp，k 在最外层；对角线为 0 保证三维可滚成二维原地更新；$O(n^3)$ 出全源矩阵，兼容负边权、可判负环（dp[i][i]<0）。
- **负权与选型**：Dijkstra 错因是确定集归纳前提里"剩余路径非负"失效；负权选 SPFA（或 Floyd 全源）；负环时最短路不存在，只能检测不能求解。
- **实测对账**：四份源码编译全过；同图三方对拍一致；断言程序 10 PASS / 0 FAIL（附录 B-5）。

## 五、语法糖对照表

| 语法 | 等价 C 写法 | 一句话用途 |
|------|------------|-----------|
| `typedef pair<ll,int> PII;` | `struct PII { long long first; int second; };` | 堆元素的载体（P4779） |
| `priority_queue<PII, vector<PII>, greater<PII>> q;` | 手写小根堆或每轮 O(n) 扫最小（朴素版即等价） | 堆顶即 dis 最小 |
| `q.push() / q.top() / q.pop() / q.size()` | 数组模拟堆的 up/down（或朴素版扫描） | 优先队列四件套 |
| `queue<int> q; q.front() / q.pop()` | `int q[N]; q[head++];`（BFS 同款数组队列） | SPFA 的队列 |
| `memset(h, -1, sizeof(h))` | `for (int i = 0; i < N; i++) h[i] = -1;` | 链式前向星头初始化 |
| `struct Edge { ... } e[N];` | `struct Edge { ... }; struct Edge e[N];` | 边表声明（两源码同款） |
| `#define ll long long` + `ll dis[N]` | `long long dis[N];` | 大距离防溢出 |
| `#define inf 1e9+7`（P4779 原样） | `const long long INF = 1000000007;` | 无穷标记（宏是 double 字面量，建议整数写法，A-3 登记 3） |
