## 一、为什么需要它

看课件开篇那道题（6.快速幂.pptx slide 1）：$5^{10} = ?$。按"以往的学习经验"连乘 10 次当然算得出来，但要算 $a^b$ 且 $b$ 到 $10^9$ 甚至 $10^{18}$ 呢？连乘一次一步，$10^{18}$ 步在每秒 $10^8$ 量级的评测机上是 $10^{10}$ 秒——**宇宙年龄级别的等待**。碰壁的根源：连乘把"已经算出来的部分"全部扔掉重来，而 $5^2 \times 5^2$ 和 $5^4 \times 5^4$ 这类重复过程其实可以复用。

破法一句话：**底数不断自乘翻倍，指数按二进制位决定"这次要不要它"**。代价从 $O(b)$ 降到 $O(\log b)$——$b = 10^{18}$ 时只要约 60 次乘法。而竞赛里幂几乎总带取模，取模又引出溢出问题（乘前必须取模），这两件事在知识点 3 里一起结算。

本篇讲 4 个知识点：幂运算的暴力与目标量级、二进制拆分原理、取模幂与防溢出、实战应用。顺序理由：动机（1）先于机制（2），机制（2）先于工程细节（3），三者齐了才接实战（4）。

## 二、知识点逐讲（每个知识点一节，共 4 节）

### 1. 幂运算的暴力与 O(log n) 目标

前置依赖：[[数据类型与内存表示]]（long long 上界 9.2e18）、[[复杂度分析与递归]]（量级估算）、循环（C 基础）
后续衔接：[[#2. 快速幂的二进制拆分原理]]、[[二分]]（同为"每步砍半"的 log 思想）

**① 它解决什么问题**

问题：给定 $a$、$b$，求 $a^b$（可能再对 $p$ 取模）。暴力是循环连乘 $b$ 次，复杂度 $O(b)$——它是"指数本身"的线性，不是输入规模的线性：$b$ 只要一个 19 位数字，步数就是 $10^{18}$。本节先把这个量级算实，确立"必须压到 $O(\log b)$"的目标；$O(\log b)$ 的意思是 $b$ 翻倍步数只加 1，$10^{18}$ 也只需约 60 步。

**② 直觉理解**

模型级类比：**折纸翻倍**。纸对折 1 次是 2 层、2 次是 4 层、3 次是 8 层——每折一次层数翻倍，折 60 次层数就远超任何需要的数字。连乘是"一层一层数"，翻倍法是"每次把已有厚度对折"。数到 $10^{18}$ 要 $10^{18}$ 步，对折到 $10^{18}$ 只要 60 步，这就是线性与对数的差距。

用具体数字推演：算 $5^{10}$，课件 slide 1 的路子——10 个 5 连乘是重复过程，先算 $5 \times 5$ 得 $5^2$，再做 $(5^2)^5$？不对，$5^{10} = (5^2)^5$ 只省到 6 次乘法；继续发现 $(5^2)^2 = 5^4$、$(5^4)^2 = 5^8$，而 $10 = 8 + 2$，所以 $5^{10} = 5^8 \times 5^2$——只需算 $5^2$（1 乘）、$5^4$（1 乘）、$5^8$（1 乘）、最后相乘（1 乘），**4 次乘法搞定原来 9 次**。

**③ 原理与推导**

目标量级从数据范围倒推：竞赛题若给 $b \le 10^{18}$，$O(b)$ 是 $10^{18}$ 步，评测机每秒约 $10^8$ 次基本运算，需要 $10^{10}$ 秒，必超时；而 $O(\log_2 10^{18}) \approx 60$ 步，瞬间完成。**为什么偏偏是 log**：第 2 节会证明指数每次右移一位（除以 2），循环次数就是 $b$ 的二进制位数 $\lfloor \log_2 b \rfloor + 1$。这也是 [[二分]] 的同款思想：每步把问题规模砍半，步数就是规模的对数。

**④ 代码演示**

块一「核心代码」（暴力版，作为对照基准；自编）：

```cpp
long long brute(long long a, long long b) {   // 复杂度：O(b)，b 大即死
    long long r = 1;
    for (long long i = 0; i < b; i++) r *= a; // 错：b=1e18 时循环体执行 1e18 次（TLE）
    return r;
}
// 对：正确的复杂度目标见知识点 2，O(log b)
```

### 2. 快速幂的二进制拆分原理

前置依赖：[[#1. 幂运算的暴力与 O(log n) 目标]]、[[位运算]]（按位与、右移）、[[运算符与表达式]]（% 与整除）
后续衔接：[[#3. 取模幂与防溢出]]、[[线段树]]（懒标记里的"标记下传次数"分析同款 log 思想）

**① 它解决什么问题**

把"算 $a^b$ 要哪些幂块"从手工观察变成机械规则。核心结论：**任何正整数都能写成若干 2 的幂之和**（6.快速幂.pptx slide 1："任何正整数都可以写成 2^n 相加的形式"），于是 $a^b = a^{2^{k_1}} \times a^{2^{k_2}} \times \cdots$，而 $a^{2^0}, a^{2^1}, a^{2^2}, \ldots$ 每一项都由前一项平方得到。复杂度：平方链 $\log b$ 次 + 挑块合并至多 $\log b$ 次，合计 $O(\log b)$。

**② 直觉理解**

模型级类比：**兑换零钱只收"2 的幂"面额**。指数 $b$ 是要凑的金额，底数自乘链 $a^1, a^2, a^4, a^8, \ldots$ 是面额 1、2、4、8 的钞票，每种面额**最多用一张**（二进制每个位只有 0/1），凑出任意金额。

用具体数字跑一遍（课件 slide 2 的例子）：$10_{(10)} = 1010_{(2)} = 2^3 + 2^1$，所以 $5^{10} = 5^{8} \times 5^{2}$。再如课件 slide 1：$5 = 2^2 + 2^0$，$7 = 2^2 + 2^1 + 2^0$。**为什么二进制拆分是完备的**：每个十进制数有唯一二进制表示（进位制基本定理），所以"挑哪些块"无歧义、无遗漏。

**③ 原理与推导**

课件 slide 2 给出两个任务：任务一"有一个变量 n 始终保存当前指数是 2 的几次方……只需要每次 n *= n 即可"（底数自乘翻倍）；任务二"如果 x%2==1 证明该二进制位的值为 1，因此应该用累乘变量 res 乘上当前的 n……x 需要除以 2，只要 x 不为零这个循环始终执行下去"。

推导正确性（循环不变式）：维护不变式 $res \times n^{x} = a^{b}$（res 是已结算部分，n 是当前幂块，x 是剩余指数）。初始 $res=1, n=a, x=b$，成立。每轮：若 x 末位为 1，$res \gets res \times n$；然后 $n \gets n^2$、$x \gets \lfloor x/2 \rfloor$——检查：$(res \times n_{odd}) \times (n^2)^{\lfloor x/2 \rfloor} = a^b$ 仍成立（当 x 为偶时直接折叠）。x 每轮至少减半，循环 $\lfloor \log_2 b \rfloor + 1$ 轮后 x=0，此时 $res = a^b$。归纳成立。

```text
b=10=1010(B) 的拆分过程（文字版推导链）：
第1轮 x=1010: 末位0 → 不挑块；n: 5→25；x→101
第2轮 x=101:  末位1 → res×=25 (5^2)；n: 25→625；x→10
第3轮 x=10:   末位0 → 不挑块；n: 625→390625；x→1
第4轮 x=1:    末位1 → res×=390625 (5^8)；n→(5^16)；x→0 结束
结果 res = 5^2 × 5^8 = 5^10 = 9765625（4 次乘法）
```

**④ 代码演示**

块一「核心代码」（自编整数版骨架，逻辑与素材 快速幂.cpp 逐行同构，仅去取模以便先看纯机制）：

```cpp
long long qpow_int(long long a, long long b) {   // 复杂度：O(log b)
    long long res = 1;   // 累乘器：乘法单位元（类比加法累加器初值 0）
    long long n = a;     // n 始终是 a^(2^k)：当前幂块
    while (b != 0) {     // b 的二进制位从低位到高位逐位扫描
        if (b % 2 == 1)  // 末位为 1：这一位的幂块要挑（课件任务二）
            res *= n;
        b /= 2;          // 指数右移一位（课件任务二）
        n *= n;          // 幂块翻倍：a^(2^k) → a^(2^(k+1))（课件任务一）
    }
    return res;
}
```

块二「执行追踪表」（$a=5, b=10$，结构状态记 res / n / x）：

| 步骤 | 当前元素 | 结构状态 | 动作 | 结果 |
|:---:|:---:|:---|:---|:---|
| 1 | x=10(1010B) | res=1, n=5 | 末位 0，不挑；n=25, x=5 | res=1 |
| 2 | x=5(101B) | res=1, n=25 | 末位 1，res*=25；n=625, x=2 | res=25 |
| 3 | x=2(10B) | res=25, n=625 | 末位 0，不挑；n=390625, x=1 | res=25 |
| 4 | x=1(1B) | res=25, n=390625 | 末位 1，res*=390625；n 越界值弃用, x=0 | res=9765625 |

块三「错误写法对照」：

```diff
- while (b != 0) { if (b % 2 == 1) res *= n; n *= n; b /= 2; }   // 这行是对的
- while (b != 0) { if (b % 2 == 1) res *= n; b /= 2; }   // 坑1：漏 n*=n——幂块永远停在 a^1，算出 a^(popcount)（答案错）
+ 每轮必须先 n*=n 再判下一轮：幂块随指数右移同步翻倍
- if (b % 2 == 0) res *= n;   // 坑2（虚构示意）：条件写反，挑的全是不要的块（答案错）
+ if (b % 2 == 1) res *= n;   // 末位 1 才挑：1 的位值 = 该块面额被使用
- b = b / 2; n = n + n;   // 坑3：n 自加是 2n 不是 n^2，幂块从 a^(2^k) 退化成 a·2^k（答案错）
+ n *= n;   // 幂块翻倍靠平方：a^(2^k) × a^(2^k) = a^(2^(k+1))
```

**⑥ 坑点与边界**

> **【易错】** 循环里漏 `n *= n` 或位置放错（放在 `if` 的分支内）。后果：幂块不再翻倍，结果错（答案错），见④对照坑 1。**原因**：指数右移一位意味着剩余指数减半，幂块必须同步从 $a^{2^k}$ 升级到 $a^{2^{k+1}}$，两步是一对。

> **【注意】** 素材源码用 `x % 2 == 1` 判末位；若 x 可能是负数（本题不会，但通用库要考虑），`x % 2` 在 C++ 里可为 -1，改用 `x & 1` 更稳（呼应 [[位运算]]）。本题 x 恒非负，两种写法等价。

回扣开场：暴力 $O(b)$ 的死局被"指数二进制拆分 + 幂块自乘"解掉，$O(\log b)$ 落地。现在你能解决"算得快"了——下一节解决"算得对"：竞赛里幂必带取模，取模必伴溢出。

### 3. 取模幂与防溢出：乘前取模

前置依赖：[[#2. 快速幂的二进制拆分原理]]、[[运算符与表达式]]（% 的分配性质）、[[数据类型与内存表示]]（long long 上界 9.2e18——防溢出卡模式 5 呼应）
后续衔接：[[#4. 实战与应用]]、[[数据类型与内存表示]]（溢出判定）

**① 它解决什么问题**

竞赛版的幂是 $a^b \bmod p$（P1226 题意即此）。两件事必须一起办：一是**取模时机**——每乘一次就取模，不能算完再取（中间值早溢出了）；二是**溢出判定**——取模后 $res, n < p$，乘积上界 $(p-1)^2$，若 $p \le 3 \times 10^9$ 则 $(p-1)^2 \le 9 \times 10^{18}$ 贴着 long long 上界 $9.22 \times 10^{18}$（实测素材版在 $p$ 接近 3e9 时安全，更大需 __int128）。复杂度不变 $O(\log b)$，取模是常数代价。

**② 直觉理解**

模型级类比：**结算时每笔都走收银台**。mod p 就像"金额超过 p 元就先付掉 p、只留零头"——总额在数学上等价（模运算保等价类），但手里现金永远不会膨胀到爆炸。等最后再一次性结算，现金早就溢出账户了。

用具体数字跑一遍（P1226 官方样例）：$2^{10} \bmod 9$。按拆分：$10 = 8 + 2$，$2^2 = 4$，$2^4 = 16 \bmod 9 = 7$，$2^8 = 7^2 = 49 \bmod 9 = 4$，$2^{10} = 2^8 \times 2^2 = 4 \times 4 = 16 \bmod 9 = 7$。**为什么中途取模不改变答案**：模运算对乘法封闭——$(x \bmod p)(y \bmod p) \bmod p = xy \bmod p$，每步取模只改"表示"，不改"等价类"。

**③ 原理与推导**

素材源码（快速幂.cpp）逐行对应：`if(x%2==1)ans=(ans*n)%p;` 挑块即取模；`n=(n*n)%p;` 幂块翻倍即取模；`x/=2;` 指数右移。两处取模缺一不可：`ans*n` 与 `n*n` 的两个操作数都已被上一步压到 $< p$，乘积 $< p^2$——**这就是"乘前取模"的全部含义：保证任何一次乘法发生时两个因子都已小于 p**。

设计动机：**为什么素材末尾还有一行 `ans=ans%p`？** 因为当 b=0 或 p=1 时循环可能一次未执行或结果恰为 p 的倍数，`ans` 初始为 1 可能本身 $\ge p$（p=1 时 1 mod 1 = 0）；这行兜底把"1 不小于 p"的边界归零。**为什么复杂度仍是 O(log b)**：循环结构没变，取模是 O(1) 常数操作。

**④ 代码演示**

块一「核心代码」：取自源文件 快速幂.cpp（改动：仅缩进与注释，逻辑逐行原样）：

```cpp
#include<iostream>
using namespace std;
long long a,b,p,x,n;
long long ans=1;
int main()
{
  cin>>a>>b>>p;
  n=a,x=b;
  while(x!=0)
  {
    if(x%2==1)ans=(ans*n)%p;   // 挑块即取模：ans,n < p，乘积 < p^2
    x/=2;                      // 指数右移：二进制扫下一位
    n=(n*n)%p;                 // 幂块翻倍即取模：同上界约束
  }
  ans=ans%p;                   // 兜底：b=0 或 p=1 时 ans 初值 1 可能 >= p（复杂度：O(log b)）
  printf("%lld^%lld mod %lld=%lld",a,b,p,ans);
  return 0;
}
```

### 4. 实战与应用：从板子到变体

前置依赖：[[#3. 取模幂与防溢出]]、[[#2. 快速幂的二进制拆分原理]]
后续衔接：[[线段树]]（延伸：矩阵幂与数据结构结合的计数场景，待产出，先文字锚定）

**① 它解决什么问题**

前三节给出机制与工程细节，本节回答"竞赛里它在哪"。三类高频场景：一是直接的模幂题（P1226 型）；二是**费马小定理求逆元**——模 p（素数）意义下除法转乘法，$a^{p-2}$ 一次幂解决，这是"计数题答案对 1e9+7 取模"类题的标配工具；三是**快速幂优化带乘方递推**——凡递推中出现 $x^k$ 且 k 达 $10^9$ 量级，直接幂就 TLE，快速幂把它压到 log。复杂度账：逆元一次 $O(\log p)$，线性递推每步 $O(\log k)$。

**② 直觉理解**

模型级类比：**幂是"多份相同的乘法"，快速幂是把"多份"打包**。就像 [[位运算]] 里"加减用移位打包"的思想——凡是"同一操作重复线性多次"的地方，都该问一句：能不能按二进制打包？逆元场景里"除以 a"这个没有直接实现的操作，被打包成"乘 a 的 p-2 次幂"。

用具体数字跑一遍（逆元）：$3^{-1} \bmod 7$。费马小定理：$3^6 \equiv 1 \pmod 7$，故 $3^{5} \equiv 3^{-1}$。算 $3^5 \bmod 7$：$3^2=9 \equiv 2$，$3^4 = 2^2 = 4$，$3^5 = 4 \times 3 = 12 \equiv 5$。验证：$3 \times 5 = 15 \equiv 1 \pmod 7$，正确。

**③ 原理与推导**

费马小定理（引用结论，来源：通识教材，课件未覆盖——这段标注为补充）：p 为素数且 $\gcd(a,p)=1$ 时 $a^{p-1} \equiv 1 \pmod p$。推导逆元式：两边同除 $a$（乘法群内可逆），$a^{p-2} \equiv a^{-1} \pmod p$。**为什么逆元能转幂**：模素数 p 下非零元构成乘法群，每个元素都有逆，且逆恰好落在 $a, a^2, \ldots, a^{p-1}$ 的循环里——幂是遍历这个循环的最短路径。

**④ 代码演示**

块一「核心代码」（自编：逆元函数，内部直接复用知识点 3 的取模快速幂）：

```cpp
long long qpow(long long a, long long b, long long p) {   // 知识点 3 原样复用
    long long res = 1; n = a % p;
    while (b) {
        if (b & 1) res = res * n % p;
        n = n * n % p; b >>= 1;
    }
    return res;
}
long long inv(long long a, long long p) {   // 复杂度：O(log p)，要求 p 素数且 a 非 p 倍数
    return qpow(a, p - 2, p);   // 费马小定理：a^(p-2) ≡ a^(-1) (mod p)
}
```

（注：上一块为节选骨架，`n` 需声明为 `long long n`；完整可编译版与对拍见附录 B-5 的断言程序。）

块二「执行追踪表」（$inv(3, 7)$ 即 $3^5 \bmod 7$，b=5=101B）：

| 步骤 | 当前元素 | 结构状态 | 动作 | 结果 |
|:---:|:---:|:---|:---|:---|
| 1 | b=5(101B) | res=1, n=3 | 末位 1：res=3；n=9%7=2, b=2 | res=3 |
| 2 | b=2(10B) | res=3, n=2 | 末位 0；n=4, b=1 | res=3 |
| 3 | b=1(1B) | res=3, n=4 | 末位 1：res=12%7=5；b=0 | res=5，验证 3×5≡1 (mod 7) |

块三「错误写法对照」：

```diff
+ return qpow(a, p - 2, p);   // p-2：两边同除 a 的结果
- return qpow(a, p - 2, p);   // 坑2：p 不是素数时直接套用——费马小定理前提破坏（答案错）

- qpow(a, b, p) 中漏掉 a % p 的入口归约   // 坑3：a ≥ p 时首轮 res、n 未归约虽逐步修正，但 a 可能为 p 的倍数时 n=0 正确得 0；真正的问题是 p=1（见知识点 3 兜底行的作用）
+ 入口做 a %= p，出口补 ans % p（素材原样的两道保险）
```

**⑤ 典型应用**

- 真题：P1226（板子，知识点 3）。
- 真题：P3811【模板】乘法逆元——线性求 1..n 逆元是另一算法，但单点逆元即本节 inv。标注：课件未覆盖，属补充，题号真实。
- 迁移题：设 f(1)=1，f(k)=f(k-1)×3 mod 1e9+7，求 f(1e18)——答案即 $3^{10^{18}-1} \bmod (10^9+7)$，一次快速幂。标注：自编。

**⑥ 坑点与边界**

> **【易错】** 逆元指数写 p-1 而非 p-2。后果：得到 1 不是逆元（答案错），见④坑 1。**原因**：p-1 次幂是"归一"，逆元要的是"归一前一步"。

> **【易错】** p 非素数时套费马小定理。后果：结论不成立（答案错）。反例：p=8, a=3，$3^6 = 729 \equiv 1 \pmod 8$，但 $3^{-1} \bmod 8 = 3$（$3 \times 3 = 9 \equiv 1$），$3^6 \ne 3$。

> **【注意】** a 是 p 的倍数时逆元不存在（模 p 下 a ≡ 0），qpow 返回 0——调用方需按题意处理，不是程序 bug。

> [!example]-
> **边界数据集（先自己跑一遍，再展开对照）**
> 1. 空输入：不适用（固定参数）。
> 2. 单元素：inv(1, p) → 1（1 的逆是自身，任何素数 p 成立）。
> 3. 全相同：inv(a, p) 调 100 次 → 结果一致（预期：确定性）。
> 4. 严格递增：a=1,2,3,4 (p=7) → 1,4,5,2（预期：各自满足 a×inv≡1）。
> 5. 严格递减：a=6,5,4,3 (p=7) → 6,3,2,5（预期：同上验证）。
> 6. 极值：a=p-1 (p=1e9+7) → inv=p-1（$(p-1)^2 = p^2-2p+1 \equiv 1$，自逆元素；预期：返回 1000000006）。
