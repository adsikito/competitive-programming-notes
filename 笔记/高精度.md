# 高精度

## 零、知识地图

```text
高精度
├── 1. 为什么需要高精度 —— long long 上界 9.2e18 之外的世界（防溢出卡模式 5 呼应）
├── 2. 高精度加法与减法 —— 数组倒序存位、进位/借位、前导零与负号
├── 3. 高精度乘法 —— 竖式乘积累加 c[i+j] += a[i]*b[j]
└── 4. 高精度除法（试商）—— 补零对齐 + 减法模拟除法逐位试商

学习顺序：1 → 2 → 3 → 4。理由：先立"存不下"的动机与存位方案（1），再用最简单的加减把"进借位 + 前导零"两件核心工程做熟（2），然后乘法只是加法的累加升级（3），最后除法用"减法 + 移位"收编全部前置技能（4）——存法到进借位到乘到除，难度阶梯单向。
```

## 一、为什么需要它

看课件开篇的例子（7.高精度.pptx slide 1）：求 Fibonacci 数列第 1000 个数、算 π 到小数点后 2000 位。第 1000 个 Fibonacci 数有 209 位——long long 上界只有约 $9.22 \times 10^{18}$，即 19 位数字（来源：[[数据类型与内存表示]]），**从第 93 项起就爆了**。碰壁的根源：不是算不动，是**存不下**——任何内置类型都装不下 209 位。

破法一句话：**把大数的每一位拆开存进数组，用程序模拟小学竖式**。课件原话："该问题属于模拟题。用一个数组保存一个数字的每一位，然后模拟加减的竖式运算。"本篇讲 4 个知识点：为什么需要高精度、加法与减法、乘法、除法。顺序理由：加法立"存位 + 进位"的地基（含减法的借位与负号），乘法是加法的累加版，除法是减法的重复版——每一环只用上一环的结论。

## 二、知识点逐讲（每个知识点一节，共 4 节）

### 1. 为什么需要高精度：long long 之外的世界

前置依赖：[[数据类型与内存表示]]（long long 上界、int 上界）、[[一维数组与字符串]]（字符串读入与数组下标）
后续衔接：[[#2. 高精度加法与减法：倒序存位与进借位]]、[[快速幂]]（同为"内置类型不够用"场景的另一条路：取模）

**① 它解决什么问题**

大数定义（slide 1 原话）：**计算的数值非常大或者对运算的精度要求非常高，用已知的数据类型无法精确表示的数值**。高精度 = 用数组逐位存数 + 程序模拟竖式，绕开内置类型的位宽限制。复杂度总账：加减乘的复杂度是 $O(n)$ 或 $O(n^2)$（n 为位数），除法 $O(n^2 \cdot \text{商位规模})$——比内置类型运算慢一个量级，所以**只在存不下时才用**。

**② 直觉理解**

模型级类比：**算盘珠子不够，改用一排格子**。long long 是一把 19 位的算盘，位数超过 19 就拨不下去了；高精度是想要多少位就摆多少个格子，每个格子只放 0-9 一个数位。运算时人怎么列竖式，程序就怎么算——竖式本来就是"逐位处理"的算法，人类用了一千年。

用具体数字推演（slide 2）：$1006 - 1000$，竖式逐位减得 $0006$，输出前要去掉前导零写成 $6$——这是课件特意点的第一个坑。

**③ 原理与推导**

为什么 long long 撑不住：64 位有符号上界 $2^{63}-1 = 9223372036854775807$，19 位。Fibonacci 第 93 项 12200160415121876738 已超。**为什么不换更大的类型**：unsigned long long 也只到 20 位，128 位整数（__int128）到 39 位，而题目动辄要求万位（素材源码注释："两个不超过 1 万位的数相加"）——位宽翻倍只多几个数量级，永远追不上题目，必须换"位数可编程决定"的数组方案。与 [[快速幂]] 对照：同样是"存不下"，能取模的题走模幂，必须精确值的题走高精度，两条路互斥互补。

**④ 代码演示**

块一「核心代码」（自编最小演示：数位如何进出数组，取自素材 4 份源码共用的 init 逻辑）：

```cpp
string s;
cin >> s;                        // 输入：字符串（大数无法用数字类型读入）
int l = s.size();                // 位数 = 字符串长度（slide 1 问题 2 的答案）
for (int i = 0; i < l; i++)
    x[i] = s[l - 1 - i] - '0';   // 倒序存位：x[0] 是个位（-'0' 把字符转数字）
// 复杂度：O(n)，n 为位数
```

**为什么倒序存是设计动机核心**：竖式从个位往高位算，进位/借位只会向"更高位"传递；数组尾部追加（`x[l]`）天然是"更高位"，头部插入却要整体挪动——**倒序让"进位方向"与"数组增长方向"一致**，所有后续运算的循环都顺着写。

### 2. 高精度加法与减法：倒序存位与进借位

前置依赖：[[#1. 为什么需要高精度：long long 之外的世界]]、[[一维数组与字符串]]（string 比较）、[[运算符与表达式]]（整除与取模做进位）
后续衔接：[[#3. 高精度乘法：竖式乘积累加]]、[[#4. 高精度除法：补零对齐与减法试商]]

**① 它解决什么问题**

两个大数（素材上限 1 万位）的加法与减法。加法核心：逐位相加满 10 进 1；减法核心：先判大小定符号，逐位相减不够借 1，再去前导零。复杂度均为 $O(n)$（n 为位数）。slide 1 给出进位两种写法（方法 1 用变量 x 记进位、方法 2 直接 `c[i+1]++`），素材源码采用方法 2 风格。

**② 直觉理解**

模型级类比：**会计逐栏记账**。两本账并成一本，从"个位栏"开始逐栏相加，某一栏满 10 就在本栏留零头、往左一栏记 1 笔"进位"；减法相反，本栏不够减就从左一栏"借 1 当 10"。竖式规则完全同构，只是"栏"换成了"数组下标"。

用具体数字跑一遍（slide 2 的 $1006 - 1000$ 与自选 $999 + 1$）：加法 $999+1$：个位 $9+1=10$ 留 0 进 1，十位 $9+0+1=10$ 又进 1，百位同理，千位落 1 → $1000$。减法 $1006-1000$：逐位 $6-0=6$、$0-0=0$、$0-0=0$、$1-1=0$，得 $0006$，去前导零 → $6$。

**③ 原理与推导**

加法（源码 高精度加法.cpp）：结果位数上界 $\max(la, lb) + 1$（最高位可能再进一位），lc 从它开始。核心循环：`c[i] += a[i] + b[i]`，若 `c[i] >= 10` 则 `c[i] -= 10; c[i+1]++`。**为什么 `c[i+1]++` 就够**：a[i]+b[i]+进位 ≤ 9+9+1=19 < 20，单次进位至多 1，不会连环爆；而 c[i+1] 在下一轮循环还会再做自己的加法——素材把"先加后进"揉在同一个数组里省了一个结果数组。

减法（源码 高精度减法.cpp）：两个前置判断（slide 2 明列）——一是 a、b 大小未知可能出负数，"先对 a 和 b 进行大小关系的判断，保证 a > b"，源码用**字符串长度 + 字典序**比较（长度不等比长度，相等比字典序——同长数字串的字典序即数值序）；二是前导零，"输出前先进行前置位多余 0 的过滤"（slide 2 原话，$0006 \to 6$）。借位写成 `if (c[i] < 0) { c[i] += 10; c[i+1]--; }`——**为什么借位可以这样"事后补"**：被借的位在下一轮循环做减法时一并扣掉，借位传递自然展开，与加法的进位对称。

**④ 代码演示**

块一「核心代码」：取自源文件 高精度减法.cpp（改动：删去注释掉的旧借位写法与多余 include，其余逻辑逐行原样；加法源码结构同构，仅进位方向相反）：

```cpp
#include<iostream>
#include<string>
using namespace std;
int a[10010],b[10010],c[10010];
string s1,s2;
int init(int x[],string s)   // 倒序存位（知识点 1④）
{
  int l=s.size();
  for(int i=0;i<l;i++) x[i]=s[l-1-i]-'0';
  return l;
}
int main()
{
  cin>>s1>>s2;
  if((s1.size()<s2.size())||(s1.size()==s2.size()&&s1<s2))
  {
    cout<<'-';               // slide 2：a<b 时结果为负，先打负号
    swap(s1,s2);             // 再交换，保证"大减小"
  }
  int la=init(a,s1), lb=init(b,s2);
  int lc=max(la,lb);
  for(int i=0;i<lc;i++)
  {
    c[i]+=a[i]-b[i];
    if(c[i]<0)               // 借位：本位不够，向上一位借 1 当 10
    {
      c[i]+=10;
      c[i+1]--;
    }
  }
  lc--;
  while(c[lc]==0&&lc>0) lc--;   // 去前导零：lc>0 保证结果为 0 时至少留一位
  for(int i=lc;i>=0;i--) cout<<c[i];
  cout<<endl;
  return 0;                    // 复杂度：比较 O(n) + 逐位 O(n) = O(n)
}
```

块二「执行追踪表」（$1006 - 1000$，竖式过程；结构状态记 c 数组）：

| 步骤 | 当前元素 | 结构状态 | 动作 | 结果 |
|:---:|:---:|:---|:---|:---|
| 0 | 存位 | a=[6,0,0,1], b=[0,0,0,1] | 倒序读入 | 就绪 |
| 1 | i=0（个位） | c=[0,0,0,0] | 6-0=6 | c=[6,0,0,0] |
| 2 | i=1（十位） | c=[6,0,0,0] | 0-0=0 | 不变 |
| 3 | i=2（百位） | c=[6,0,0,0] | 0-0=0 | 不变 |
| 4 | i=3（千位） | c=[6,0,0,0] | 1-1=0 | 不变，无借位 |
| 5 | 去前导零 | c=[6,0,0,0], lc=3 | c[3]=0→lc=2→c[2]=0→lc=1→c[1]=0→lc=0 停 | 输出 6 |

块三「错误写法对照」：

```diff
- while(c[lc]==0) lc--;   // 坑1：去前导零漏 lc>0——结果为 0 时 lc 一路减到 -1，输出越界（RE）
+ while(c[lc]==0&&lc>0) lc--;   // 素材原样：0 是合法结果，至少留一位
- if((s1.size()<s2.size())||(s1.size()==s2.size()&&s1<s2)) { /* 交换 */ }   // 坑2：只比长度不比字典序——"19"与"20"同长，比长度平手后直接算 19-20，借位算错（答案错）
+ 同长时必须 s1<s2 按字典序再判（同长数字串字典序=数值序）
- c[i]+=a[i]-b[i]; if(c[i]>0){c[i]-=10;c[i+1]++;}   // 坑3（虚构示意）：减法抄了加法的进位——借位方向是 -10 向上借，写成 +10 向上进，结果全错（答案错）
+ if(c[i]<0){c[i]+=10;c[i+1]--;}   // 借位：本位 +10，上一位 -1，与进位符号全反
```

**⑤ 典型应用**

- 真题：P1601 A+B Problem（高精）（slide 2 链接）——加法板子，实测对拍 200 组全对（附录 B-5）。

**⑥ 坑点与边界**

> **【易错】** 结果为 0 时去前导零越界。后果：lc 减到 -1，输出访问 c[-1]（RE）。正解：`lc>0` 守卫，见④坑 1。

> **【注意】** 素材减法源码注释里保留了一种"先借后减"的写法（`if(a[i]<b[i]){a[i]+=10;a[i+1]--;}` 再 `c[i]=a[i]-b[i]`），与正文"先减后补"等价——两种借位时机都对，但一篇代码只用一种，混写容易把借位扣两次。

> [!example]-
> **边界数据集（先自己跑一遍，再展开对照）**
> 1. 空输入：不适用（题面保证非空；空串 l=0 属未定义输入）。
> 2. 单元素："0" 与 "0" → 加法输出 0；减法输出 0（预期：去前导零后留一位的 0）。

> 6. 极值：10000 位 "9…9" + "1" → 10000 位 "1" 后接 10000 个 0？不对——是 1 万位 9 全进位变 1 后接 1 万个 0，共 10001 位，c 数组 10010 够（预期：全链进位不越界；实测对拍含 10000 位级锚点，见附录 B-5）。

回扣开场：加减两件套把"竖式模拟"的地基打完——存位、进借位、符号、前导零四大件。现在你能解决 P1601 和 P2142 了，用的是本节的倒序存位与进借位循环。乘法只是在这个地基上多一层"累加"。

### 3. 高精度乘法：竖式乘积累加

前置依赖：[[#2. 高精度加法与减法：倒序存位与进借位]]、[[一维数组与字符串]]（双下标循环）
后续衔接：[[#4. 高精度除法：补零对齐与减法试商]]、[[快速幂]]（幂块相乘在大数场景的对接，延伸）

**① 它解决什么问题**

两个不超过 1 万位的正整数相乘（源码注释原话）。竖式乘法的关键观察：**a 的第 i 位与 b 的第 j 位相乘，贡献落在结果的第 i+j 位**——这一条把"两层竖式（逐位乘 + 错位相加）"压成一条累加公式 `c[i+j] += a[i]*b[j]`，最后统一进位。复杂度 $O(la \times lb)$，1 万位乘 1 万位约 $10^8$ 次乘加，可过。

**② 直觉理解**

模型级类比：**快递按"楼层 + 房间"投柜**。a[i]×b[j] 这个"包裹"的收货格由两位数决定：i+j——就像十进制竖式里"错位"的本质：乘 10 的 i 次方再乘 10 的 j 次方，指数相加得 $10^{i+j}$。所有包裹先堆进柜子（累加），最后一遍逐格整理进位（满 10 移仓）。

用具体数字跑一遍（$123 \times 45 = 5535$）：累加阶段 c[0]=3×5=15，c[1]=3×4+2×5=22，c[2]=2×4+1×5=13，c[3]=1×4=4；进位阶段 c[0]=15→留 5 进 1，c[1]=23→留 3 进 2，c[2]=15→留 5 进 1，c[3]=5；得 5535。

**③ 原理与推导**

推导 `c[i+j]` 下标公式：$a = \sum a_i 10^i$，$b = \sum b_j 10^j$，则 $a \times b = \sum_{i,j} a_i b_j 10^{i+j}$——$10^{i+j}$ 的系数就是所有满足 i+j=k 的 $a_i b_j$ 之和，故结果第 k 位累加 `a[i]*b[j]`（i+j=k）。**为什么进位放最后统一做**：累加阶段 c[k] 是若干乘积的和，单项 $a_i b_j \le 81$，累加和不会瞬间爆 int（1 万位 × 81 ≈ 8.1×10^5，c[k] 峰值远小于 int 上界 2.1×10^9），先累加后进位省掉逐次进位的开销；结果位数上界 la+lb（最高位无进位空间时恰满），故源码 `lc = la + lb`、c 数组开 20005。

**④ 代码演示**

块一「核心代码」：取自源文件 高精度乘法.cpp（改动：无，逻辑逐行原样）：

```cpp
#include<iostream>
#include<string>
using namespace std;
int a[10005],b[10005],c[20005];   // c 开双倍：位数和（知识点 1⑥ 数组大小坑）
int init(int x[])   // 倒序存位，与知识点 1④ 逐行相同（同文件原样，此处节选）
int main()
{
  int la=init(a), lb=init(b);
  int lc=la+lb;                    // 结果位数上界
  for(int i=0;i<la;i++)
    for(int j=0;j<lb;j++)
      c[i+j]+=a[i]*b[j];           // 核心：第 i 位 × 第 j 位 → 第 i+j 位（复杂度 O(la*lb)）
  for(int i=0;i<lc;i++)            // 统一进位：满 10 移仓
  {
    if(c[i]>=10)
    {
      c[i+1]+=c[i]/10;
      c[i]=c[i]%10;
    }
  }
  while(c[lc]==0&&lc>0) lc--;      // 去前导零（同知识点 2）
  for(int i=lc;i>=0;i--) cout<<c[i];
  cout<<endl;
  return 0;
}
```

### 4. 高精度除法：补零对齐与减法试商

前置依赖：[[#2. 高精度加法与减法：倒序存位与进借位]]（减法与去前导零全复用）、[[一维数组与字符串]]
后续衔接：[[二分]]（延伸：商的二分优化思想）、[[快速幂]]（同批：大数与模运算的分野）

**① 它解决什么问题**

两个不超过 1 万位的正整数相除，输出整数商（源码注释："两个不超过一万位的正整数相除"）。核心思想：**除法就是"能减几次"**——被除数与"除数补 k 个 0"对齐后，反复做减法，减的次数就是商的那一位。复杂度：商每一位至多减 10 次（0-9），每次减法 O(n)，总 $O(10 \times n \times \text{商位数})$，n=1 万位时约 $10^9$？——不：商位数 ≤ n，最坏 $10 \times n^2 = 10^9$ 偏紧，实际多数题数据远松于此，素材源码即按此实现，此段复杂度我不确定课件是否有精确账，按实现直接推算登记。

**② 直觉理解**

模型级类比：**用天平称重试凑**。除数加上一串 0（放大 10^k 倍）当砝码，往被除数那边压：能压一次商的对应位就 +1，压不动就换小一号的砝码（少补一个 0）。从最大的砝码试到最小的，天平剩下的读数就是余数，各砝码的使用次数连起来就是商。

用具体数字跑一遍（$100 \div 7 = 14$）：7 补 2 个 0 得 700，100 压不动 700（商百位 0）；7 补 1 个 0 得 70，100 减 70 剩 30，商十位 1；30 再减 70 不动；7 补 0 个 0，30 减 7 四次剩 2，商个位 4 → 商 14 余 2。

**③ 原理与推导**

素材源码除法有三件套：check（比较两个"数组数"大小：先比位数 x[0]，再从高位到低位逐位比）、sub（带借位的减法，同时更新位数——减完前导零后 `x[0]=i`）、试商主循环。注意这份源码**约定 x[0] 存长度**（源码注释："数组 0 下标存放数据长度"），与前三份"init 返回长度"不同，这是 A-3 登记的约定差异。

推导商位公式 `c[0] = a[0] - b[0] + 1`：商的位数至多是被除数位数减除数位数加 1（$10^{la-1} \le a < 10^{la}$，$b < 10^{lb}$，商 $< 10^{la}/10^{lb-1} = 10^{la-lb+1}$）。主循环 `for(i=c[0]; i>=1; i--)`：把 b 补 i-1 个 0 对齐到第 i 位（`t[j+i-1]=b[j]`），`while(check(a,t)) { sub(a,t); c[i]++; }`——每位至多减 9 次（0-9 试商），**为什么试商次数有界**：若能减 10 次，说明补位后仍能再对齐一位，与"从最高可能位开始"的枚举顺序矛盾，故每层 while 至多 9 次退出。

**④ 代码演示**

块一「核心代码」：取自源文件 高精度除法.cpp（改动：无，逐行原样；check 与 sub 为篇幅节选自同文件，未改逻辑）：

```cpp
#include<iostream>
#include<string>
using namespace std;
int a[10005],b[10005],c[10005];   // 约定：x[0] 存长度，x[1..len] 存位
void init(int x[])                // 与前三份不同：长度写进 x[0]
{
  string s; cin>>s;
  x[0]=s.size();
  for(int i=1;i<=x[0];i++) x[i]=s[x[0]-i]-'0';
}
bool check(int x[],int y[])       // x>=y 返 1，x<y 返 0（先比长度再逐位）
{
  if(x[0]>y[0])return 1;
  if(x[0]<y[0])return 0;
  for(int i=x[0];i>=1;i--)
  {
    if(x[i]>y[i])return 1;
    if(x[i]<y[i])return 0;
  }
  return 1;
}
void sub(int x[],int y[])         // x-=y（带借位），随后更新 x[0]
{
  for(int i=1;i<=x[0];i++)
  {
    if(x[i]<y[i]) { x[i]+=10; x[i+1]-=1; }
    x[i]-=y[i];
  }
  int i=x[0];
  while(x[i]==0&&i>1) i--;
  x[0]=i;                          // 去前导零并刷新长度（复用知识点 2 思想）
}
int main()
{
  init(a); init(b);
  while(a[a[0]]==0&&a[0]>1) a[0]--;   // 防输入带前导零：005/9
  while(b[b[0]]==0&&b[0]>1) b[0]--;
  if(check(a,b)==0) { cout<<0<<endl; return 0; }   // 小数除大数：商 0
  c[0]=a[0]-b[0]+1;                   // 商的位数上界
  for(int i=c[0];i>=1;i--)            // 从商的最高位往下试
  {
    int t[10005]={0};                 // t = b 补 i-1 个 0（对齐砝码）
    for(int j=1;j<=b[0];j++) t[j+i-1]=b[j];
    t[0]=b[0]+i-1;
    while(check(a,t)==1)              // 复杂度：每层至多 9 次减法
    {
      sub(a,t);
      c[i]++;                         // 每减一次，商的这一位 +1
    }
  }
  while(c[c[0]]==0&&c[0]>1) c[0]--;   // 商去前导零
  for(int i=c[0];i>=1;i--) cout<<c[i];
  cout<<endl;
  return 0;
}
```

- **乘法**：$a_i b_j$ 落在第 $i+j$ 位，先累加后统一进位，复杂度 $O(la \cdot lb)$（知识点 3，高精度乘法.cpp）。
- **除法**：补零对齐 + 减法试商，每位至多试 9 次；约定 x[0] 存长度；除数 0 不设防（知识点 4，高精度除法.cpp）。
- **实测**：4 份源码编译全过；与 Python int 对拍 814 组全 PASS（附录 B-5）。
