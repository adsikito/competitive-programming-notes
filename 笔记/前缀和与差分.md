# 前缀和与差分

## 零、知识地图

```text
前缀和与差分
├── 1. 一维前缀和（多次查区间和：预处理 O(n)，查询 O(1)）
├── 2. 二维前缀和（容斥推广到平面，子矩阵和 O(1)）
├── 3. 二维前缀和应用：P1387 最大正方形（"和等于面积"当全 1 判定器）
├── 4. 一维差分（两端打标记 O(1) 改区间，前缀和统一结算）
└── 5. 二维差分（四角标记改矩形，二维前缀和还原）
学习顺序：1 → 2 → 3 → 4 → 5——先"查"后"改"，因为差分的还原公式就是前缀和的递推式。
```

## 一、为什么需要它

先看两个最平常的需求。需求一：数组有 $10^5$ 个数，每次问"区间 $[l, r]$ 的和是多少"，要问 $10^5$ 次。老老实实每次从 $l$ 加到 $r$，单次 $O(n)$，总共 $10^{10}$ 次操作，超时。需求二：每次"给区间 $[l, r]$ 的每个数都加上 $v$"，做完 $10^5$ 次修改后问每个位置最终的值。每次修改都逐个加，同样是 $10^{10}$ 次。

这两个需求方向相反——一个是"只查不改"，一个是"只改不查"——分别由本篇的两大工具解决：前缀和把"求一段和"压到 $O(1)$，差分把"改一段"压到 $O(1)$。它们的本质是同一件事：预先做一遍 $O(n)$ 的加工，把重复劳动提前算好。

本篇讲 5 个知识点：一维前缀和、二维前缀和、二维前缀和应用（P1387）、一维差分、二维差分。前两个是"查"的工具，后两个是"改"的工具，中间一个例子演示两者配合能救活一个超时暴力。

## 二、知识点逐讲（每个知识点一节，共 5 节）

### 1. 一维前缀和

前置依赖：C 语言的循环与数组（前缀和的载体）、[[枚举与模拟#2. 复杂度估算与数据范围]]（判断"预处理 O(n) + 查询 O(1)"是否划算）
后续衔接：[[#2. 二维前缀和]]（平面推广）、[[#4. 一维差分]]（逆运算）

**① 它解决什么问题**

前缀和就是"数列的前 n 项和"：原数组 $a$，新数组 $sum$，$sum[i] = a[1] + a[2] + \dots + a[i]$。它解决的问题：多次询问任意区间 $[l, r]$ 的和，每次 $O(1)$ 回答。性质：预处理 $O(n)$，查询 $O(1)$，空间 $O(n)$；代价是数组中途不能改（改了 $sum$ 就过期，见坑点）。

**② 直觉理解**

把 $sum$ 想成汽车里程表：上车记一次读数，下车记一次读数，两读数一减就是这段路走的里程。不管这段路多长，你只需要两次读表——不需要把每一米都重走一遍。区间和 $= sum[r] - sum[l-1]$，就是"下车读数减上车读数"。

用具体数字跑一遍：$a = [3, 1, 4, 1, 5]$，则 $sum = [3, 4, 8, 9, 14]$。问 $[2, 4]$ 的和：$sum[4] - sum[1] = 9 - 3 = 6$，与手加 $1 + 4 + 1 = 6$ 一致。

**③ 原理与推导**

先推递推式。按定义 $sum[i] = \sum_{k=1}^{i} a[k]$，把第 i 项拆出来：$sum[i] = \sum_{k=1}^{i-1} a[k] + a[i] = sum[i-1] + a[i]$。这就是"边读入边求前缀和"的依据——只依赖上一项。

再推查询式。$sum[r] - sum[l-1] = \left(\sum_{k=1}^{r} a[k]\right) - \left(\sum_{k=1}^{l-1} a[k]\right)$。两个和式里 $k \le l-1$ 的部分完全相同，相减抵消，剩下 $\sum_{k=l}^{r} a[k]$，恰是区间和。为什么要减 $sum[l-1]$ 而不是 $sum[l]$：减 $sum[l]$ 会把 $a[l]$ 自己也减掉，而 $a[l]$ 属于询问区间。

设计动机：下标从 1 而不是 0 开始，正是为了给"空区间"留位置——$sum[0] = 0$ 让 $l = 1$ 时公式依然成立（$sum[1] - sum[0] = a[1]$），不需要特判。

**④ 代码演示**

```cpp
#include <cstdio>
int a[100005];
long long s[100005];   // 复杂度：预处理 O(n)，查询每次 O(1)
int main() {
    int n, q; scanf("%d %d", &n, &q);
    for (int i = 1; i <= n; i++) {
        scanf("%d", &a[i]);
        s[i] = s[i - 1] + a[i];    // 边读边推：s[i] = s[i-1] + a[i]
    }
    while (q--) {
        int l, r; scanf("%d %d", &l, &r);
        printf("%lld\n", s[r] - s[l - 1]);  // 区间和 = 下车读数 - 上车读数
    }
    return 0;
}
```

第 6 行用 `s[i] = s[i-1] + a[i]` 就地递推，少写一个循环。第 9 行是全篇第一个核心公式，务必背下。

**执行追踪表**（数据取②节：a = [3, 1, 4, 1, 5]）

| 步骤 | 当前元素 | 结构状态 | 动作 | 结果 |
|------|---------|---------|------|------|
| 1 | a[1]=3 | s[0]=0 | s[1]=s[0]+3 | s[1]=3 |
| 2 | a[2]=1 | s[1]=3 | s[2]=s[1]+1 | s[2]=4 |
| 3 | a[3]=4 | s[2]=4 | s[3]=s[2]+4 | s[3]=8 |
| 4 | a[4]=1 | s[3]=8 | s[4]=s[3]+1 | s[4]=9 |
| 5 | a[5]=5 | s[4]=9 | s[5]=s[4]+5 | s[5]=14 |
| 6 | 查询 [2,4] | s[1]=3，s[4]=9 | 输出 s[4]-s[1] | 6 |

**错误写法对照**

```diff
- printf("%lld\n", s[r] - s[l]);      // 坑1：左端点没退一位，a[l] 自己被减掉 → WA
+ printf("%lld\n", s[r] - s[l - 1]);  // 修复：口诀"左端点退一位再减"
- int s[100005];                      // 坑2：n=1e5、单值 1e9 时总和 1e14，int 存不下 → 溢出为错误答案
+ long long s[100005];                // 修复：估算总和上界，超约 2e9 就用 long long
```

**⑤ 典型应用**

- B3612（课件指定练习，洛谷）：区间和查询入门题，做法即上面代码：边读边求 $s[i]$，查询输出 $s[r] - s[l-1]$。
- 洛谷 P8218 求区间和（同型题）：给数列与多次询问，输出每次 $[l,r]$ 的和，同公式直接套。
- 自编迁移题（自编）：n 个学生排队（n ≤ $10^5$），每人一个体重，q 次询问"第 l 到第 r 个人的总体重"。建议先独立做，再对照题解。

  题解：与前两题同构——体重数组做前缀和，每次 $O(1)$ 查询。唯一注意点：n = $10^5$、每人最重 $10^9$ 时总和最大 $10^{14}$，超出 int 范围，必须用 long long 存 s（这就是代码第 2 行用 long long 的原因）。

**⑥ 坑点与边界**

> [!caution]
> **【易错】** 查询写成 `s[r] - s[l]` → 结果少了 a[l] 自己 → WA。正确写法：`s[r] - s[l-1]`，记忆口诀"左端点退一位再减"。

> [!caution]
> **【易错】** 前缀和数组用 int 存大和 → 溢出为负数 → 输出错误答案。正确写法：估算总和上界（n × 单值上限），超过约 $2 \times 10^9$ 就用 long long。

> [!example]-
> **边界数据集（先自己跑一遍，再展开对照）**
> 1. 空输入：n=0, q=0 → 读入与递推循环均不执行 → 无输出
> 2. 单元素：n=1, a=[7]，查询 [1,1] → s[1]-s[0]=7-0=7 → 输出 7
> 3. 全相同：a=[5,5,5]，查询 [1,3] → 15；查询 [2,3] → s[3]-s[1]=15-5=10 → 依次输出 15、10
> 4. 严格递增：a=[1,2,3,4]，查询 [2,4] → s[4]-s[1]=10-1=9 → 输出 9
> 5. 严格递减：a=[4,3,2,1]，查询 [2,3] → s[3]-s[1]=9-4=5 → 输出 5
> 6. 极值：n=10^5 全为 10^9，查询 [1,10^5] → 总和 10^14，int 版溢出为错误值，long long 版输出 100000000000000

结论失效条件：数组元素中途被修改时，$sum$ 全部过期，需要 $O(n)$ 重建或改用树状数组（后续篇章）。收尾回扣：现在你能解决开场需求一了——一遍预处理、两次读表相减，$10^5$ 次询问稳稳落地。

### 2. 二维前缀和

前置依赖：[[#1. 一维前缀和]]（一维公式是推广基底）
后续衔接：[[#3. 二维前缀和应用：P1387 最大正方形]]、[[#5. 二维差分]]（复用递推公式）

**① 它解决什么问题**

把一维推广到平面：$sum[i][j]$ 是以 $(1,1)$ 为左上角、$(i,j)$ 为右下角的整个矩形的元素和。它解决"多次询问任意子矩阵的和，每次 $O(1)$"。性质：预处理 $O(nm)$，查询 $O(1)$；递推与查询各用一个四项式（容斥），这是本篇唯一需要背的两条公式。

**② 直觉理解**

想象城市里一张"累计人口地图"：每个格子记录"从西北角到这格围出的矩形区住了多少人"。想知道任意矩形区的人口，用大矩形减去左边一条、上面一条，多减的左上角再加回来——这就是容斥原理：不重不漏地计数，重叠部分减一次就要补一次。

用具体数字跑一遍：$a = \begin{bmatrix} 1 & 2 \\ 3 & 4 \end{bmatrix}$，则 $sum[1][1]=1$，$sum[1][2]=3$，$sum[2][1]=4$，$sum[2][2]=10$（全矩阵和）。问右下角单格 $a[2][2]$（即子矩阵 $(2,2)$ 到 $(2,2)$）：$sum[2][2] - sum[1][2] - sum[2][1] + sum[1][1] = 10 - 3 - 4 + 1 = 4$，正确。

**③ 原理与推导**

递推式怎么来：$sum[i][j]$ 要覆盖矩形 $(1,1)$ 到 $(i,j)$。把它切成三块已知的加自己：左边长条 $sum[i][j-1]$、上面长条 $sum[i-1][j]$、自己 $a[i][j]$。但左条与上条在左上角重叠了 $sum[i-1][j-1]$ 这一小块，加两次就要减一次：

$$sum[i][j] = sum[i][j-1] + sum[i-1][j] - sum[i-1][j-1] + a[i][j]$$

文字版结论：左边加上面，重叠减一角，最后加自己。

查询式同理。求子矩阵 $(x_1, y_1)$ 到 $(x_2, y_2)$：大矩形 $sum[x_2][y_2]$ 减去上面多算的 $sum[x_1-1][y_2]$、左边多算的 $sum[x_2][y_1-1]$，左上角被减了两次补一次 $sum[x_1-1][y_1-1]$：

$$\text{子矩阵和} = sum[x_2][y_2] - sum[x_1-1][y_2] - sum[x_2][y_1-1] + sum[x_1-1][y_1-1]$$

文字版结论：大矩形，减上条减左条，加回左上角。

设计动机：为什么二维要容斥而一维不用？一维的"左边一条"就是另一个前缀和，相减恰好无重叠；二维里左条与上条天然相交于左上角，必须显式补一次。维度每升一维，容斥项按 $2^{d}$ 增长——这也是多维前缀和不常手写的原因（课件提到多维基于容斥，正文不展开）。

**④ 代码演示**

```cpp
#include <cstdio>
int a[105][105];
long long s[105][105];   // 复杂度：预处理 O(nm)，查询 O(1)
int main() {
    int n, m; scanf("%d %d", &n, &m);
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++) {
            scanf("%d", &a[i][j]);
            // 容斥递推：左 + 上 - 左上重叠 + 自己
            s[i][j] = s[i][j-1] + s[i-1][j] - s[i-1][j-1] + a[i][j];
        }
    int x1, y1, x2, y2; scanf("%d %d %d %d", &x1, &y1, &x2, &y2);
    // 容斥查询：大矩形 - 上条 - 左条 + 左上角
    printf("%lld\n", s[x2][y2] - s[x1-1][y2] - s[x2][y1-1] + s[x1-1][y1-1]);
    return 0;
}
```

**错误写法对照**

```diff
- printf("%lld\n", s[x2][y2] - s[x1][y2] - s[x2][y1] + s[x1][y1]);   // 坑：x1、y1 忘减一，上条左条只减一半 → WA
+ printf("%lld\n", s[x2][y2] - s[x1-1][y2] - s[x2][y1-1] + s[x1-1][y1-1]);   // 修复：四个边界统一减一
```

**⑤ 典型应用**

- 洛谷 P1719 最大加权矩形（同族题）：在 n×n 矩阵中找和最大的子矩阵，枚举上下边界把二维压成一维再套前缀和，$O(n^3)$。
- 自编迁移题（自编）：n×m 的 01 矩阵（n, m ≤ 100），q 次询问某矩形内 1 的个数。建议先独立做，再对照题解。

  题解：1 与 0 的矩阵直接做二维前缀和，每次询问套查询式，$O(nm + q)$。这题就是知识点 3 的技术底座——把"元素和等于面积"当判定条件。

**⑥ 坑点与边界**

> [!caution]
> **【易错】** 查询时 $x_1 - 1$ 写成 $x_1$ → 上条只减掉一半 → 子矩阵和偏大 → WA。正确写法：四个边界统一"减一"，与一维的 `s[l-1]` 同理。

> [!note]
> **【注意】** 递推与查询两条公式长得像，背混的高发点：递推减的是 $sum[i-1][j-1]$（左上角一格区域），查询加的是 $sum[x_1-1][y_1-1]$（同为左上角）。区分口诀：递推式里是"自己 a[i][j]"，查询式里没有 a。

> [!example]-
> **边界数据集（先自己跑一遍，再展开对照）**
> 1. 空输入：n=0, m=0 → 递推循环不执行，s 全 0 → 任何查询输出 0
> 2. 单元素：1×1 矩阵 a=[9]，查询 (1,1)-(1,1) → s[1][1]=9 → 输出 9
> 3. 全相同：2×3 全 5 → 查询 (1,1)-(2,3) 输出 30；查询 (2,2)-(2,3) → s[2][3]-s[1][3]-s[2][1]+s[1][1]=30-15-10+5=10 → 输出 10
> 4. 严格递增：2×2 矩阵 [[1,2],[3,4]]，查询 (2,2)-(2,2) → 10-3-4+1=4 → 输出 4（即②节推演）
> 5. 严格递减：2×2 矩阵 [[4,3],[2,1]]，查询 (1,2)-(2,2) → 10-0-6+0=4 → 输出 4
> 6. 极值：100×100 全 10^9，查询整矩阵 → 总和 10^13，int 版溢出为错误值，long long 版输出 10000000000000

结论失效条件：矩阵元素中途修改时同样失效（同知识点 1 的边界）。收尾回扣：现在你能"一次加工、永久查询"任意矩形了——容斥让平面问题仍是一减一加。

### 3. 二维前缀和应用：P1387 最大正方形

前置依赖：[[#1. 一维前缀和]]、[[#2. 二维前缀和]]（判定器的公式来源）、[[枚举与模拟#2. 复杂度估算与数据范围]]（先估算出暴力必死才需要本节）
后续衔接：线性 DP 解法（LC 221 的 O(nm) 做法，库内暂无 DP 篇笔记，先以文字锚定）

**① 它解决什么问题**

n×m 的 01 矩阵，找最大的全 1 正方形，输出边长。朴素做法 $O(nml^3)$ 超时（知识点：估算见枚举篇），二维前缀和把每次"判断一个正方形是否全 1"压到 $O(1)$，总复杂度 $O(nm \cdot \min(n,m))$，在 n, m ≤ 100 时约 $10^7$ 次操作，稳过。性质：本知识点是"前缀和当判定器"的标准范式——元素非 0 即 1 时，"区间和 = 面积"等价于"区间全 1"。

**② 直觉理解**

判断一块 n×n 的地毯是不是纯色，不用一格一格翻看——称出它的重量，与"同尺寸纯色地毯的标准重量"一比就知道。01 矩阵里"重量"就是元素和，"标准重量"就是 $l \times l$（边长平方）。

**③ 原理与推导**

判定条件怎么来的：矩阵元素非 0 即 1，记子矩阵和为 $S$、面积为 $A$。若子矩阵全 1，则 $S = A$；若其中有 0（哪怕一个），每多一个 0 和就少 1，$S < A$。所以 $S = A$ 是"全 1"的充要条件——不是必要条件凑巧成立，而是严格等价。

为什么"枚举右下角"而不是"枚举左上角"：两者都能写对，本篇源码选择枚举右下角 $(i,j)$ 与边长 $l$，左上角由 $(i-l+1, j-l+1)$ 反推。理由是前缀和查询式天然以右下角为主参数（$s[x_2][y_2]$），少做一次坐标换算。设计动机：写查询式时顺着公式的书写顺序组织循环，出错率最低。

**④ 代码演示**

P1387 核心逻辑（取自源文件 P1387.cpp，读入与递推同知识点 2，此处只放判定骨架）：

```cpp
int l = 1, x, y;
while (l <= min(n, m)) {          // 枚举边长（也可以枚举到更大的就停）
    for (int i = l; i <= n; i++)
        for (int j = l; j <= m; j++) {   // 枚举每个正方形的右下角
            x = i - l + 1; y = j - l + 1;    // 反推左上角
            // 判定：子矩阵和 == 面积  <=>  全 1
            if (s[i][j] - s[i][y-1] - s[x-1][j] + s[x-1][y-1] == l * l)
                ans = max(ans, l);
        }
    l++;
}
printf("%d\n", ans);
```

**错误写法对照**

```diff
- for (int l = min(n, m); l >= 1; l--)   // 坑：从大到小找到即停，未论证"l 可行则 l-1 可行"，且 ans 未初始化 → 输出随机值 → WA
-     if (check(l)) { printf("%d\n", l); break; }
+ int ans = 0;
+ for (int l = 1; l <= min(n, m); l++)   // 修复：小到大枚举 + ans 取 max，逻辑最直白
+     if (check(l)) ans = max(ans, l);
+ printf("%d\n", ans);
```

**⑤ 典型应用**

- P1387 建立方块（洛谷）：本知识点主例，上面已完整推导。
- LC 221 最大正方形（力扣，同族题）：同题面但推荐 DP 解法（$O(nm)$ 且更通用），可作为学完线性 DP 后的重做练习。
- 自编迁移题（自编）：01 矩阵中求最大的全 0 正方形边长。建议先独立做，再对照题解。

  题解：两种改法。改法一：判定条件改为"子矩阵和 = 0"（全 0 时和为 0），其余照抄。改法二（更通用）：把 0/1 取反再跑原判定。复杂度不变 $O(nm \cdot \min(n,m))$。

**⑥ 坑点与边界**

> [!caution]
> **【易错】** 枚举边长从大到小、找到就输出：源码从小到大枚举并取 max，两者都对；但"从大到小找到即停"必须配合"该边长存在"的证明（l 可行时 l-1 一定可行），凭感觉写容易漏初始化 ans。正确写法：像源码一样小到大 + ans 取 max，逻辑最直白。

> [!note]
> **【注意】** 复杂度里 $\min(n,m)$ 来自正方形边长上限：边长不可能超过矩阵较短边，循环上界写 min 而不是 n 或 m，白做的枚举少一半。

> [!example]-
> **边界数据集（先自己跑一遍，再展开对照）**
> 1. 空输入：n=0 或 m=0 → 判定循环不执行，ans=0 → 输出 0
> 2. 单元素：1×1 矩阵 [1] → l=1 时和=1=1×1 → 输出 1；矩阵 [0] → 输出 0
> 3. 全相同：3×3 全 1 → 边长 3 的全 1 正方形存在 → 输出 3
> 4. 严格递增：不适用：输入是 01 矩阵而非数值序列，单调性无语义
> 5. 严格递减：不适用：同上
> 6. 极值：100×100 全 1 → l 枚举到 100，l*l=10000 无溢出 → 输出 100；若 n, m ≤ 1000 的全 1，nm·min(n,m)=10^9 超 1 秒标尺 → TLE，须换 DP（对应本节数据范围段）

数据范围与复杂度上限：$nm \cdot \min(n,m) \le 10^7$（n, m ≤ 100）通过；若 n, m ≤ 1000 则是 $10^9$，本做法超时，需改用 DP（LC 221 的 $O(nm)$ 做法）。收尾回扣：现在你能解决开场那个超时暴力了——把"逐格翻看"换成"称重比对"，$10^{10}$ 变 $10^7$。

### 4. 一维差分

前置依赖：[[#1. 一维前缀和]]（差分的还原就是一遍前缀和）
后续衔接：[[#5. 二维差分]]（平面推广）；树状数组/线段树（边改边查，库内暂无对应笔记）

**① 它解决什么问题**

与"只查不改"相反：要对区间 $[l, r]$ 整体加 v，做 $10^5$ 次修改，最后才问每个位置的值。逐个加是 $O(n)$ 每次，总量 $10^{10}$。差分把"改一段"压到 $O(1)$：只在两个端点做记号，最后一次前缀和统一结算。性质：修改 $O(1)$，最终还原 $O(n)$，只适合"修改全部结束后才查询"的场景（课件原话：修改操作一定要在查询操作之前）。

**② 直觉理解**

高速公路收费站按"进站记一笔、出站记一笔"结算：一辆车从 A 口进 B 口出，A、B 两个站各打一条记录，中间所有站不用管。最后想知道每两个站之间通过多少车，把记录沿线扫一遍做前缀和——进站 +1、出站 -1，路过即累计。差分就是在区间的两端"打记录"。

用具体数字跑一遍：$a = [2, 5, 1, 4]$，把区间 $[2, 3]$ 每个数加 3。打标记：$b[2] += 3$（进站），$b[4] -= 3$（出站，r+1 处）。对 b 做前缀和得修改量 $d = [0, 3, 3, 0]$，加回原数组得 $[2, 8, 4, 4]$——第 2、3 位各加了 3，正确。

**③ 原理与推导**

为什么对 b 求前缀和恰好得到每个位置的修改量？设修改区间 $[l, r]$ 加 v 的标记为 $b[l] += v$、$b[r+1] -= v$，其余为 0。前缀和 $d[i] = \sum_{k=1}^{i} b[k]$：当 $i < l$ 时求和不含 $b[l]$，$d[i] = 0$；当 $l \le i \le r$ 时含 $b[l]$ 不含 $b[r+1]$，$d[i] = v$；当 $i \ge r+1$ 时两项都含，$+v$ 与 $-v$ 抵消，$d[i] = 0$。三段恰好覆盖数轴，且与"修改只作用于 $[l, r]$"完全一致。

设计动机：为什么出站标记打在 r+1 而不是 r？若打在 r，前缀和在 i = r 处已经 $+v - v = 0$，第 r 个位置自己收不到 v。打在 r+1 让"第 i 位含有效标记"的区间恰为 $[l, r]$。这个"+1 错位"与知识点 1 查询式的 `s[l-1]` 是同一种边界思想：给"区间右端点之后"留一格。

两种初始化（课件区分了"差分数组"与"差分标记数组"）：
- 由原数组求 b：$b[i] = a[i] - a[i-1]$，此时对 b 求前缀和直接还原 a（再叠加修改）。
- 标记数组全 0 起：只记修改量，最后 $a[i] += d[i]$。多轮修改只用后者更省心。

**④ 代码演示**

```cpp
#include <cstdio>
int a[100005], b[100005];   // b：差分标记数组，全 0 起
int main() {
    int n, m; scanf("%d %d", &n, &m);
    for (int i = 1; i <= n; i++) scanf("%d", &a[i]);
    while (m--) {
        int l, r, v; scanf("%d %d %d", &l, &r, &v);
        b[l] += v;           // 进站：从 l 开始受影响
        b[r + 1] -= v;       // 出站：r 之后不再受影响（错位一格）
    }
    for (int i = 1; i <= n; i++) {
        b[i] += b[i - 1];    // 前缀和结算：b[i] 变成位置 i 的总修改量
        a[i] += b[i];
        printf("%d ", a[i]);
    }
    return 0;
}
```

**执行追踪表**（数据取②节：a = [2, 5, 1, 4]，区间 [2, 3] 加 3）

| 步骤 | 当前元素 | 结构状态 | 动作 | 结果 |
|------|---------|---------|------|------|
| 1 | 修改指令 [2,3]+3 | b 全 0 | b[2]+=3，b[4]-=3 | b[2]=3、b[4]=-3，其余为 0 |
| 2 | i=1 | b[1]=0，b[0]=0 | b[1]+=b[0]，a[1]+=b[1] | a[1]=2 |
| 3 | i=2 | b[2]=3 | b[2]+=b[1]=3，a[2]+=3 | a[2]=8 |
| 4 | i=3 | b[3]=0 | b[3]+=b[2]=3，a[3]+=3 | a[3]=4 |
| 5 | i=4 | b[4]=-3 | b[4]+=b[3]=0，a[4]+=0 | a[4]=4（结算后 b[4]=0） |

**错误写法对照**

```diff
- b[r] -= v;             // 坑1：出站标记打在 r，第 r 位收不到 v → WA
+ b[r + 1] -= v;         // 修复：右端点后一格才是结算的出站口
- printf("%d\n", a[k]);  // 坑2（最小示意）：修改做到一半就查询单点，前缀和未结算 → WA
+ // 修复：差分只支持"先改完再查"——m 次修改全部结束后，一遍前缀和结算再查询
```

**⑤ 典型应用**

- 洛谷 P2367 语文成绩（同型题）：多次给区间学生分数加减，输出最终每人分数，标准一维差分模板。
- 自编迁移题（自编）：n 盏灯全亮，m 次操作每次把 $[l, r]$ 的灯状态翻转，问最后灭着的灯有哪些。建议先独立做，再对照题解。

  题解：翻转不是加减常数，但差分思想不变——"对区间加 1"改成"对区间加 1（模 2）"：`b[l]++`、`b[r+1]--` 后前缀和，位置 i 的累计翻转次数为 b[i]，b[i] 为奇数则灯灭。复杂度 $O(n + m)$。

**⑥ 坑点与边界**

> [!caution]
> **【易错】** 出站标记写 `b[r] -= v` → 第 r 个位置收不到 v → 该位置少加了 v → WA。正确写法：`b[r+1] -= v`，"右端点后一格"才是结算的出站口。

> [!caution]
> **【易错】** 修改中途就要查询单点值 → 差分的前缀和还没做完，读到的 b 不是修改量 → WA。正确写法：差分只支持"先改完再查"；边改边查需树状数组或线段树（后续篇章）。

> [!example]-
> **边界数据集（先自己跑一遍，再展开对照）**
> 1. 空输入：n=0, m=0 → 打标记与结算循环均不执行 → 无输出
> 2. 单元素：n=1, a=[7]，修改 [1,1]+5 → b[1]+=5、b[2]-=5 → 结算后 a[1]=12 → 输出 12
> 3. 全相同：a=[3,3,3]，修改 [1,3]+2 → 输出 5 5 5
> 4. 严格递增：a=[1,2,3]，修改 [2,2]+10 → 输出 1 12 3
> 5. 严格递减：a=[3,2,1]，修改 [1,2]-1 → 输出 2 1 1
> 6. 极值：n=10^5 全 10^9，m=10^5 次修改均为 [1,10^5]+10^9 → 每位最终 10^9+10^14=100001000000000，超出 int（示例代码 a、b 均为 int 会溢出，正是"估算总和上界"纪律要拦的情形，需 long long）

结论失效条件：区间加的值互不相同没问题，但"区间赋值"（不是加减）不能直接用差分，需改写为差分形式 $b[l] = v, b[i] = 0 (l<i\le r)$ 的批量处理。收尾回扣：现在你能解决开场需求二了——两端打记录、一遍前缀和结算，$10^5$ 次区间修改只剩 $O(n + m)$。

### 5. 二维差分

前置依赖：[[#2. 二维前缀和]]（还原公式）、[[#4. 一维差分]]（两端打标记思想的推广）
后续衔接：P2004 领地选择（"查"方向的对偶练习）；树状数组/线段树（库内暂无对应笔记）

**① 它解决什么问题**

把"改一段"推广到"改一块"：每次给子矩阵 $(x_1, y_1)$ 到 $(x_2, y_2)$ 内所有格子加 v，做完 m 次后输出整个矩阵。逐格加是 $O(nm)$ 每次。二维差分在四个角打标记，最后一遍二维前缀和还原。性质：修改 $O(1)$，还原 $O(nm)$；P3397（地毯）的 n ≤ 1000、m ≤ 10^5 规模下，逐格加是 $10^5 \times 10^6 = 10^{11}$ 必超时，四角标记是 $10^5 + 10^6$ 稳过。

**② 直觉理解**

一维是收费站"进站/出站"两个点；二维变成"四个角"。想象在平面区域盖章：想让一个矩形区域全部 +1，就在矩形的左上角 +1、右上角 -1、左下角 -1、右下角 +1。最后从左到右、从上到下"扫"一遍平面（二维前缀和），四个角的记号沿着扫描扩散又互相抵消，恰好只在目标矩形内留下 +1。

用具体数字跑一遍：4×4 平面，给 $(1,1)$ 到 $(3,3)$ 加 1。打标记：$b[1][1]{+}{+}$，$b[1][4]{-}{-}$，$b[4][1]{-}{-}$，$b[4][4]{+}{+}$。还原 $a[2][2] = a[1][2] + a[2][1] - a[1][1] + b[2][2] = 1 + 1 - 1 + 0 = 1$（在矩形内，正确）；$a[4][4] = a[3][4] + a[4][3] - a[3][3] + b[4][4] = 0 + 0 - 1 + 1 = 0$（在矩形外，正确）。

**③ 原理与推导**

四角公式的来历：还原式就是知识点 2 的递推式 $a[i][j] = a[i-1][j] + a[i][j-1] - a[i-1][j-1] + b[i][j]$，其中 b 是标记数组。我们把"哪些格子该 +1"倒推回 b 应该长什么样：目标矩形 $(x_1,y_1)$ 到 $(x_2,y_2)$ 内 $a$ 全为 1、外全为 0。对照递推方向，在 $b[x_1][y_1]$ 放 +1，它会随递推"扩散"到整个右下方向；在 $b[x_1][y_2+1]$ 放 -1，把 $y > y_2$ 的右条抵消；在 $b[x_2+1][y_1]$ 放 -1，把 $x > x_2$ 的下条抵消；右下角 $(x_2+1, y_2+1)$ 被减了两次，放 +1 补回。四个角恰是二维容斥的镜像操作。

$$\text{修改}(x_1,y_1,x_2,y_2,v):\quad b[x_1][y_1]{+}{=}v,\; b[x_1][y_2{+}1]{-}{=}v,\; b[x_2{+}1][y_1]{-}{=}v,\; b[x_2{+}1][y_2{+}1]{+}{=}v$$

文字版结论：左上加、右上减、左下减、右下加；上标 1 的是左/上，加 1 的是"区域外第一格"。

设计动机：为什么还原公式与二维前缀和递推一模一样？因为"差分"与"前缀和"互为逆运算——差分是对前缀和数组做逐项差分，前缀和是对差分做累加。同一套容斥系数（+1、-1、-1、+1）在两个方向上各自成立，这正是课件页 11 公式与知识点 2 公式形似的原因。

**④ 代码演示**

P3397 核心逻辑（取自源文件 P3397.cpp，原样保留）：

```cpp
#include <iostream>
using namespace std;
int n, m;
int a[1005][1005];
int b[1005][1005];       // 二维差分标记数组（全 0 起）
int main() {
    cin >> n >> m;
    int lx, ly, rx, ry;
    for (int i = 1; i <= m; i++) {
        cin >> lx >> ly >> rx >> ry;   // 左上、右下
        b[lx][ly]++;                   // 左上 +
        b[lx][ry + 1]--;               // 右上外 -
        b[rx + 1][ly]--;               // 左下外 -
        b[rx + 1][ry + 1]++;           // 右下外 +
    }
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= n; j++) {
            // 二维前缀和还原：上 + 左 - 左上 + 标记
            a[i][j] = a[i-1][j] + a[i][j-1] - a[i-1][j-1] + b[i][j];
            cout << a[i][j] << " ";    // 复杂度：修改 O(m)，还原 O(n^2)
        }
    return 0;
}
```

**错误写法对照**

```diff
- b[rx + 1][ry + 1]--;   // 坑1：右下角补偿写成减，容斥不闭合 → 大片格子值错误 → WA
+ b[rx + 1][ry + 1]++;   // 修复：口诀"左上加、右上减、左下减、右下加"
- int b[1001][1001];     // 坑2：rx+1 = n+1 = 1001 时越界访问 → RE
+ int b[1005][1005];     // 修复：数组开到 n+2 以上（本篇 1005 对 n ≤ 1000 恰好够）
```

**⑤ 典型应用**

- P3397 地毯（洛谷）：本知识点主例，m 张矩形地毯逐块覆盖，最后输出每格被盖层数。
- 洛谷 P2004 领地选择（同族题）：二维前缀和求最大子矩阵（"查"的方向），可与本篇知识点 2 配对练习。
- 自编迁移题（自编）：n×n 棋盘，m 次操作每次把矩形区域翻转（0 变 1、1 变 0），最后输出棋盘。建议先独立做，再对照题解。

  题解：与一维翻转题同理，把"+v"换成"+1（模 2）"：四角标记 $+1, -1, -1, +1$ 在模 2 意义下即 $+1, +1, +1, +1$（因为 $-1 \equiv 1 \pmod 2$）。还原后每格对 2 取模，奇数为 1。复杂度 $O(m + n^2)$。

**⑥ 坑点与边界**

> [!caution]
> **【易错】** 四角符号写错（如右下角写 -1）→ 容斥不闭合 → 大片格子值错误 → WA。正确写法：背口诀"左上加、右上减、左下减、右下加"，并理解"减的是区域外第一行/列，加的是右下补偿"。

> [!caution]
> **【易错】** 数组开 1005 但 $r + 1 = n + 1$ 或 $rx + 1 = n + 1$ 越界访问 → RE。正确写法：数组第二维开到 n+2 以上（本篇开 1005 对 n ≤ 1000 恰好够，若 n 更大需同步放大）。

> [!example]-
> **边界数据集（先自己跑一遍，再展开对照）**
> 1. 空输入：n=0, m=0 → 打标记与还原循环均不执行 → 无输出
> 2. 单元素：n=1, m=1，地毯 (1,1)-(1,1) → 还原 a[1][1]=1 → 输出 1
> 3. 全相同：n=3, m=2 张均 (1,1)-(3,3) → 每格被盖 2 层 → 三行均为 2 2 2
> 4. 严格递增：不适用：输入是矩形坐标集合，无单调序列语义
> 5. 严格递减：不适用：同上
> 6. 极值：n=1000, m=10^5 张均 (1,1)-(1000,1000) → 每格 10^5、标记累计 10^5，均在 int 内无溢出 → 每格输出 100000

数据范围与复杂度上限：m 次 $O(1)$ 修改 + 一次 $O(n^2)$ 还原，$10^5 + 10^6$ 量级安全。结论失效条件：需要"修改中途查询"或"矩形赋值"时同样不适用，理由同知识点 4。收尾回扣：现在你能解决开场那个 $10^{11}$ 次的覆盖统计了——四角盖章、一遍扫描，地毯问题从暴力变成了模板题。

## 三、全篇坑点总表

| # | 坑 | 正解 |
|---|----|------|
| 1 | 区间和查询写成 s[r]-s[l] | 左端点退一位：s[r]-s[l-1] |
| 2 | 前缀和用 int 存大和溢出 | 估算总和上界，超 2e9 用 long long |
| 3 | 二维查询边界忘统一减一 | 四个边界统一减一 |
| 4 | 递推式与查询式背混 | 递推含 a[i][j]，查询不含 |
| 5 | 一维差分出站标记打在 r | 打在 r+1，右端点后一格 |
| 6 | 改到一半就查询 | 差分只支持改完再查 |
| 7 | 二维差分四角符号写错 | 左上加右上减左下减右下加 |
| 8 | 差分标记访问 b[r+1] 越界 | 数组开到 n+2 以上 |

## 四、总结与自测

- 前缀和与差分互为逆运算：一个把"查区间"压到 O(1)，一个把"改区间"压到 O(1)，都靠一遍 O(n) 预加工。
- 一维区间和 $s[r] - s[l-1]$；二维子矩阵和是四项容斥；递推式与查询式各背一条。
- "元素非 0 即 1"时，区间和等于面积等价于全 1——前缀和因此能当判定器（P1387）。
- 一维差分两端打标记（进站 l、出站 r+1），二维差分四角打标记，前缀和统一结算。
- 差分只支持"先改完再查"；边改边查交给树状数组/线段树（后续篇章）。
