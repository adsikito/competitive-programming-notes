## 一、为什么需要它

先做一道素材课堂题（12.1 二维数组.pdf 应用 1）：n 行 m 列的矩阵，输出每行每列的和，$n, m < 100$。只用一维数组，你得给每行的数据各开一个数组，变量名写到手软，n、m 还必须写死。**碰壁的根源：一维数组只能存"一条线"，而问题在"一个面"上。**

二维数组的破法一句话：**给每个元素发两个下标（行、列），数据按网格落位**。接着双循环（知识点 2）接管全部遍历，递推（知识点 3）让它从容器变成计算工具，字符版（知识点 4）让它装下迷宫与棋盘。本篇讲 4 个知识点，顺序理由：结构（1）先于操作（2），数值表（3）先于字符表（4）。

## 二、知识点逐讲（每个知识点一节，共 4 节）

### 1. 二维数组与行优先存储：内存视角下的行列平面

前置依赖：[[一维数组与字符串]]（一维数组的下标与内存布局）
后续衔接：[[#2. 双循环遍历与矩阵操作：行列求和、边缘和、转置]]、[[前缀和与差分]]（二维前缀和建立在这个存储模型上）

**① 它解决什么问题**

源 p4 定义：二维数组是"数组的每一个元素都是一个一维数组"——一维数组解决"一条线"上的批量变量问题，二维数组解决"一个面（行列）"上的问题。语法（源 p5）：`type arrName[row][col];`。关键性质：所有元素在内存里**连续存放**，`a[i][j]` 的位置可由公式直接算出，访问 $O(1)$；行列数声明时固定，不能运行期增长。

**② 直觉理解**

模型级类比：**一栋宿舍楼**。每层楼房间数相同（列数固定），房号 = 楼层号 + 层内序号。行优先存储就是管理员贴房牌的顺序：从 1 楼左端开始、一层一层从左到右编进一条直廊——内存是直的，网格是抽象出来的。

用具体数字跑一遍：`int a[2][3];` 在内存里排成 `a[0][0] a[0][1] a[0][2] a[1][0] a[1][1] a[1][2]` 共 6 个 int 占 24 字节。给 `a[1][2] = 7` 时，CPU 实际算的是"第 1 层第 2 间"= 全楼第 5 间。

**③ 原理与推导**

行优先存储的地址公式：`a[i][j]` 字节地址 = 首地址 $+ (i \times col + j) \times sizeof(元素)$。推导：跳过前 i 行需要 $i \times col$ 个元素，再走 j 个元素到本行第 j 列。

**设计动机：为什么初始化时行数可省、列数不能省？**（源 p16"第二维同样不可省略"）编译器给 `a[i][j]` 定位必须知道一行多长（col），否则第 i 行从哪开始都算不出来；而"一共几行"可由初始化数据总量除以 col 推出。这就是 `int a[][2] = {100,200,300,400};` 合法而 `int a[2][] = ...` 非法的原因。

```text
int a[2][3] 的内存视角（每格 4 字节，基地址 B）：
下标    a[0][0] a[0][1] a[0][2] a[1][0] a[1][1] a[1][2]
偏移    B+0     B+4     B+8     B+12    B+16    B+20

文字推导链：网格坐标 (i, j) 先折算成"直廊序号" i*3+j，再乘元素大小换算成字节
偏移——第 1 行第 2 列 = 1*3+2 = 5 号元素 = B+20，与上表一致。
```

**④ 代码演示**

初始化五种写法（取自素材 12.1 code.cpp 注释段，自编整理成可编译版）：

```cpp
#include <iostream>
using namespace std;
int main() {
    int a1[2][2] = {100,200,300,400};        // 写法1：值个数与位置一一对应
    int a2[2][2] = {111,222};                // 写法2：不够则其余补0，a2[1][1]=0
    int a3[2][2] = {{100,200},{300,400}};    // 写法3：按行括起（素材推荐写法）
    int a4[2][2] = {{100},{200,300}};        // 写法4：行内也可缺省补0
    int a5[][2] = {{100,200},{300,400}};     // 写法5：行数省略，列数必须有
    int a[10][5];                            // 循环赋值（源 p10 原样）
    for (int i = 0; i < 10; i++)             // 外层控行
        for (int j = 0; j < 5; j++)          // 内层控列
            a[i][j] = i * 10 + j;            // 复杂度：O(行*列) 全量填表
    cout << a[1][2] << " " << a3[1][0] << "\n";  // 输出 12 300
    return 0;
}
```

**执行追踪表**（`int a[2][3]` 上执行 `a[1][2] = 7;` 再读 `a[1][0]`）：

| 步骤 | 当前元素 | 结构状态 | 动作 | 结果 |
|:---:|:---:|:---|:---|:---|
| 1 | a[1][2] | 全部为 0 | 算偏移 (1*3+2)*4=B+20 | 定位第 5 号格 |
| 2 | a[1][2] | a[1][2]=7 | 写入 7 | B+20 处变 7 |
| 3 | a[1][0] | a=[0,0,0,0,0,7] | 算偏移 (1*3+0)*4=B+12 | 定位第 3 号格 |
| 4 | a[1][0] | 不变 | 读取该格 | 返回 0 |

**错误写法对照**：

```diff
- int a[2][] = {{1,2},{3,4}};   // 坑1：列数省略——编译器算不出一行长度，编译错误
+ int a[][2] = {{1,2},{3,4}};   // 行数可由数据总量推出，列数必须写明
- a[1][3] = 5;                  // 坑2（2列数组越界写）：踩进 a[2][0] 的位置，不报错但数据乱（答案错）
+ a[1][1] = 5;                  // 列下标范围 0..cols-1，越界是"静默错"不是"必崩"
- int b[100][100]; memset(b, 1, sizeof(b));   // 坑3：memset 按字节填，int 被填成 0x01010101=16843009（答案错）
+ memset(b, 0, sizeof(b));      // 只填 0 或 -1 安全；其他初值老实用双循环填
```

**⑤ 典型应用**

- 课堂题：行列求和（源 p19-20 应用 1）——`row[i] += arr[i][j]; col[j] += arr[i][j];` 一趟双循环同时出两组和，完整代码见知识点 2。
- 迁移题（自编）：读入 3x3 矩阵，输出主对角线元素之和。思路：只累加满足 `i == j` 的格子，$O(n^2)$ 遍历中的选择性处理。
- 竞赛衔接：二维前缀和（[[前缀和与差分]]）的第 0 步就是"把矩阵存进二维数组"；矩阵乘法、棋盘轮廓类题（[[状压DP]]）也都建立在这个模型上。

**⑥ 坑点与边界**

> **【易错】** 行、列下标写反。声明 `a[行][列]`，行列大小不同的矩阵一旦写反，轻则输出转置样貌（答案错），重则列下标越界踩进别行（数据乱）。

> **【易错】** 数组大小按题目上限贴线开。素材 $n, m \le 100$ 开 `[100][100]` 恰好够用，竞赛习惯多留余量（如 `[105][105]`），防边界上多读一行就是 RE。

> **【注意】** 局部二维数组不自动清零，声明后直接用会读到栈上残留值；全局数组（素材代码全开在 main 外）才自动清零。

> [!example]-
> **边界数据集（先自己跑一遍，再展开对照）**
> 1. 空输入：n=0, m=0 → 双循环体零次执行，无输出（预期：空、不崩溃）。
> 2. 单元素：n=1, m=1 → 只有 a[0][0]，四个边缘条件同时成立但只累加一次（预期：边缘和 = 该数本身）。
> 3. 全相同：3x3 全填 5 → 行和列和都是 15（预期：行列对称时结果对称）。
> 4. 严格递增：1..9 逐行填入 → a[1][2]=6，验证行优先落位（预期：与地址公式一致）。
> 5. 严格递减：9..1 填入 → 同上反向验证。
> 6. 极值：元素 1000、n=m=100 → 行和最大 $10^5$，int 稳够；元素若 $10^9$ 量级求全矩阵和，$10^{11}$ 超 int，累加变量必须 long long（防溢出）。

回扣开场："每行每列求和"用两个下标 + 一趟双循环就写完了——现在你能解决开场那个变量名写到手软的问题，用的是知识点 1 的网格落位与知识点 2 的双循环框架。

### 2. 双循环遍历与矩阵操作：行列求和、边缘和、转置

前置依赖：[[#1. 二维数组与行优先存储：内存视角下的行列平面]]、[[一维数组与字符串]]（for 循环与累加器）
后续衔接：[[#3. 杨辉三角：二维递推的起点]]、[[排序]]（结构体排序前先练熟按行列扫描）

**① 它解决什么问题**

二维数组绝大多数操作是同一种形状：**外层控行、内层控列的双循环**。源 p20/p22/p27 三道应用题——行列求和、边缘元素和、矩阵转置——都是这个框架换一种"循环体内做什么"。复杂度：全量遍历 $O(nm)$，素材上限 $100 \times 100$ 是 $10^4$ 次访问，即使 $1000 \times 1000$ 也只有 $10^6$，安全。

**② 直觉理解**

模型级类比：**点名册按排扫**。老师从第一排左端开始，一行点完换下一排——这就是双循环的执行顺序；"求每行总分"是点每个人时把分数记到该排头上，"转置"是改成按列点、重新填一张表。

用具体数字跑一遍（2x3 转置）：原矩阵 `1 2 3 / 4 5 6`，执行 `arr2[j][i] = arr[i][j]`：arr[0][0]=1 落到 arr2[0][0]，arr[0][1]=2 落到 arr2[1][0]……原矩阵的"行"变成新矩阵的"列"，得到 3 行 2 列的 `1 4 / 2 5 / 3 6`。

**③ 原理与推导**

转置（源 p27 作业，代码见素材 hw_code.cpp）：定义是 $A^T[j][i] = A[i][j]$，扫描原矩阵每个元素时把它投递到**对调坐标**。**设计动机：为什么转置要新开数组而不是原地交换？** 原地交换要求 a[i][j] 与 a[j][i] 一一配对，只有方阵（n=m）才严格成立；长方形矩阵连配对格都不存在，新开数组是通用写法，代价只是多一份 $O(nm)$ 内存。

边缘和（源 p21-22）：边缘元素 = 第一行（i==0）或最后一行（i==n-1）或第一列（j==0）或最后一列（j==m-1），四条件取或，遍历时选择性累加。

行列和（源 p19-20）：扫到 `arr[i][j]` 时它同时属于第 i 行和第 j 列，所以 `row[i] += x; col[j] += x;` 一起做——一趟循环出两组答案。

**④ 代码演示**

矩阵转置（取自素材 hw_code.cpp，逐行原样，实测 `2 3 / 1 2 3 / 4 5 6` 输出 `1 4 / 2 5 / 3 6`；3x3 样例与源 p27 一致）：

```cpp
#include <iostream>
using namespace std;
int arr[100][100];      // 全局数组自动清零（对比：局部数组不会）
int arr2[100][100];
int main() {
    int n, m;
    cin >> n >> m;                          // n 行 m 列
    for (int i = 0; i < n; i++)             // 接收：外控行
        for (int j = 0; j < m; j++)
            cin >> arr[i][j];
    for (int i = 0; i < n; i++)             // 转置：坐标对调投递
        for (int j = 0; j < m; j++)
            arr2[j][i] = arr[i][j];         // 复杂度：O(nm)
    for (int i = 0; i < m; i++) {           // 输出：m 行 n 列（行列互换）
        for (int j = 0; j < n; j++)
            cout << arr2[i][j] << " ";
        cout << endl;
    }
    return 0;
}
```

**执行追踪表**（原矩阵 2 行 3 列 `1 2 3 / 4 5 6`，列代表性投递步）：

| 步骤 | 当前元素 | 结构状态 | 动作 | 结果 |
|:---:|:---:|:---|:---|:---|
| 1 | arr[0][0]=1 | arr2 全 0 | arr2[0][0]=arr[0][0] | arr2[0][0]=1 |
| 2 | arr[0][1]=2 | 不变 | arr2[1][0]=arr[0][1] | arr2[1][0]=2 |
| 3 | arr[0][2]=3 | 不变 | arr2[2][0]=arr[0][2] | arr2[2][0]=3 |
| 4 | arr[1][0]=4 | 不变 | arr2[0][1]=arr[1][0] | arr2[0][1]=4 |
| 5 | arr[1][2]=6 | 不变 | arr2[2][1]=arr[1][2] | arr2[2][1]=6 |
| 6 | 输出阶段 | arr2 完整 | 按 3 行 2 列打印 | 1 4 / 2 5 / 3 6 |

**错误写法对照**：

```diff
- for (int i = 0; i < n; i++) { for (int j = 0; j < n; j++) cout << arr2[i][j] << " "; cout << endl; }
+ for (int i = 0; i < m; i++) { for (int j = 0; j < n; j++) cout << arr2[i][j] << " "; cout << endl; }
  // 坑1：输出仍按 n 行 m 列——转置后行列互换，必须输出 m 行 n 列，否则错位甚至越界（答案错/RE）
- arr[j][i] = arr[i][j];        // 坑2（原地转置）：长方形行列数不同，配对格不存在（答案错）
+ arr2[j][i] = arr[i][j];       // 新开数组投递，方阵与长方形通吃
- if (i == 0 && j == 0 || ...) total += arr[i][j];   // 坑3（边缘和示意）：把"或"写成"与"——只有四角被累加（答案错）
+ if (i==0 || j==0 || i==n-1 || j==m-1) total += arr[i][j];   // 边缘 = 四条边任一命中
```

**⑤ 典型应用**

- 课堂题：边缘元素和（源 p21-22 应用 2），实测样例 `3 3 / 3 4 1 / 3 7 1 / 2 0 1` 输出 15（3+4+1+3+2+0+1+1，中心 7 不计，与样例一致）。课堂题：行列求和（源 p19-20 应用 1）同框架。
- 迁移题（自编）：判断 n x n 矩阵是否对称。思路：检查所有 `i < j` 的格子是否满足 `a[i][j] == a[j][i]`，$O(n^2)$；只扫一半即可，扫全矩阵会把每对查两遍（结论仍对，常数翻倍）。
- 竞赛衔接："扫描-选择性处理"框架直接服务[[排序]]的结构体排序与[[枚举与模拟]]类大模拟题——都是双循环换个循环体。

**⑥ 坑点与边界**

> **【易错】** 转置输出边界不换。输入 n 行 m 列，输出必须 m 行 n 列；素材 hw_code.cpp 输出循环写 `i < m`、内层 `j < n`，抄模板时这两处最容易顺手写反（④对照坑 1）。

> **【易错】** 行列读反。源 p21 题面写"行数 m 和列数 n"，源 p22 参考代码却按 `cin >> n >> m` 当"n 行 m 列"用——题面字母与代码字母不一致，采信代码（样例可复算，附录 A-3 登记 1）。教训：读题先对样例，字母名不等于语义。

> **【注意】** 边缘判断在 1x1 矩阵上四条件同时成立但只累加一次——条件是"或"，每个元素整趟只被访问一次；重复计数的风险只在你手动分四段循环累加时出现。

> [!example]-
> **边界数据集（先自己跑一遍，再展开对照）**
> 1. 空输入：n=0, m=0 → 转置输出零行，无输出（预期：空、不崩）。
> 2. 单元素：n=1, m=1 → 转置是自身；边缘和 = 该元素本身（预期：恒等）。
> 3. 全相同：2x3 全 5 → 转置 3x2 全 5；边缘和 = 全部 6 格都在边缘 = 30（预期：小矩阵无内部元素）。
> 4. 严格递增：2x3 填 1..6 → 转置第一列 1 2 3（预期：行的首元素变列）。
> 5. 严格递减：2x3 填 6..1 → 同上反向。
> 6. 极值：100x100 全 1000 → 边缘和 = $(100+100+98+98) \times 1000 = 396000$，int 稳够；元素 $10^9$ 量级则累加和可到 $10^{11}$，必须 long long（防溢出）。

回扣开场：行列求和、边缘和、转置现在都是"双循环 + 一句核心操作"——现在你能解决开场那个问题，靠的正是知识点 1 的落位与知识点 2 的扫描框架。

### 3. 杨辉三角：二维递推的起点

前置依赖：[[#1. 二维数组与行优先存储：内存视角下的行列平面]]、[[函数]]（C 基础递归，理解"算过的留下来"）
后续衔接：[[前缀和与差分]]（二维前缀和递推式同构）、[[线性DP]]（网格型 DP 的第一块跳板）

**① 它解决什么问题**

前两节把二维数组当**存表格的容器**；本节把它升级为**算表格的机器**：新格子的值由已算好的旧格子推出来，这就是二维递推。以杨辉三角为例（自编示例，资料未覆盖，属补充）：求 $n \le 30$ 行杨辉三角。每项用组合数公式硬算要算阶乘、做除法、防溢出；二维递推只用加法。关键性质：第 i 行有 i+1 个数，总计算量 $O(n^2)$，n=30 时约 465 次加法。

**② 直觉理解**

模型级类比：**爬山接力**。每个人（格子）从"左肩上的人"和"正上方的人"手里接过重量相加背走；最左、最右的人没有两个来源，固定背 1。每条"肩线"算一遍就固定不动，后面所有人都能放心引用。

用具体数字跑一遍（n=5）：第 0 行 `1`；第 2 行 `1 2 1`（2 = 1+1）；第 4 行 `1 4 6 4 1`（6 = 3+3）。实测程序输出与此完全一致（附录 B-5）。

**③ 原理与推导**

递推式与边界：$y[i][j] = y[i-1][j-1] + y[i-1][j]$，其中 $j = 1 \ldots i-1$；边界 $y[i][0] = y[i][i] = 1$。

**设计动机：为什么边界和递推要分开写？** 递推式读 $y[i-1][j-1]$ 与 $y[i-1][j]$：当 $j=0$ 时 $y[i-1][-1]$ 越界；当 $j=i$ 时 $y[i-1][i]$ 是上一行不存在的位置（读到未初始化值）。所以先让边界挡住非法下标，递推只在 $1 \le j \le i-1$ 的安全区间运行——边界不是补丁，是递推式成立的前提。

```text
n=5 的递推依赖图（每格只依赖上一行两格）：
行0   1
行2   1  2  1        2 = 1+1
行3   1  3  3  1     3 = 1+2, 3 = 2+1
行4   1  4  6  4  1  4 = 1+3, 6 = 3+3, 4 = 3+1

文字推导链：算第 i 行时第 i-1 行必须全部就绪——外层按行号递增即天然满足；
"上一行"永远比"当前行"早一步算完，二维数组按行存储正好保证这个顺序。
```

**④ 代码演示**

杨辉三角（自编示例，已编译实测）：

```cpp
#include <iostream>
using namespace std;
int y[35][35];                       // 全局数组清零；35 行：C(34,17) 已超 int，见⑥
int main() {
    int n; cin >> n;                 // n <= 30
    for (int i = 0; i < n; i++)
        for (int j = 0; j <= i; j++)
            if (j == 0 || j == i)    // 边界：两端为 1（短路求值挡住非法下标）
                y[i][j] = 1;         // 为什么必须先判边界：递推式在 j=0/i 处下标非法
            else
                y[i][j] = y[i-1][j-1] + y[i-1][j];   // 递推：上一行两格相加
    for (int i = 0; i < n; i++) {    // 复杂度：O(n^2) 时间，O(n^2) 空间
        for (int j = 0; j <= i; j++) cout << y[i][j] << " ";
        cout << "\n";
    }
    return 0;
}
```

**执行追踪表**（n=5，列代表性步）：

| 步骤 | 当前元素 | 结构状态 | 动作 | 结果 |
|:---:|:---:|:---|:---|:---|
| 1 | y[0][0] | 全 0 | j==0 命中边界 | y[0][0]=1 |
| 2 | y[1][0], y[1][1] | 行0 就绪 | 边界各置 1 | 行1 = 1 1 |
| 3 | y[2][1] | 行1 就绪 | y[1][0]+y[1][1] | y[2][1]=2 |
| 4 | y[3][1], y[3][2] | 行2 就绪 | 1+2, 2+1 | 行3 = 1 3 3 1 |
| 5 | y[4][2] | 行3 就绪 | y[3][1]+y[3][2]=3+3 | y[4][2]=6 |
| 6 | 输出 | n=5 全就绪 | 逐行打印 | 1 / 1 1 / 1 2 1 / 1 3 3 1 / 1 4 6 4 1 |

**错误写法对照**：

```diff
- y[i][j] = y[i-1][j-1] + y[i-1][j];          // 坑1：递推不设边界——j=0 读 y[i-1][-1]（未定义行为），
+ if (j == 0 || j == i) y[i][j] = 1;          //   j=i 读上一行不存在的 y[i-1][i]（脏数据，WA/RE）
+ else y[i][j] = y[i-1][j-1] + y[i-1][j];     // 边界先挡，递推只在安全区间跑
- for (int j = 0; j < i; j++) cout << y[i][j];   // 坑2：内层 j < i——每行少打最后一个 1（答案错）
+ for (int j = 0; j <= i; j++) cout << y[i][j] << " ";   // 第 i 行有 i+1 个数，j <= i
- int y[35][35]; 放 main 里且不初始化          // 坑3：局部数组栈上残留值，读到垃圾（答案错）
+ int y[35][35]; 放全局                        // 全局自动清零
```

**⑤ 典型应用**

- 真题：洛谷 P5731 蛇形方阵——把 1..n^2 按蛇形填进 n x n 方阵（方向数组 + 边界转向），是"二维递推填表"方向题，题号真实存在。
- 迁移题（自编）：数字三角形——n 行数字塔从顶走到底（每次左下或右下），最大化路径和。思路：与杨辉三角同构，把"相加"换成 `max(左来源, 右来源) + 本格`，$O(n^2)$。
- 竞赛衔接：二维前缀和（[[前缀和与差分]]）的 `s[i][j] = s[i-1][j] + s[i][j-1] - s[i-1][j-1] + a[i][j]` 与杨辉三角同属"新格由旧格推出"的填表；路径计数与背包二维写法（[[线性DP]]）是下一站。

**⑥ 坑点与边界**

> **【易错】** 边界判断漏掉或写在递推之后。`j==0 || j==i` 的短路求值保证 j==0 时不再看第二个条件；条件错位时递推式拿到非法下标（④对照坑 1）。

> **【易错】** 行内格数数错。第 i 行（从 0 计）有 i+1 个数，`j <= i` 写成 `j < i` 少了行尾的 1；写成 `j <= n` 则越界。

> **【注意】** 杨辉三角数值增长极快：$C(30, 15) = 155117520$ 在 int 内，$C(34, 17) = 2333606220$ 已超 int 上限 2147483647——n 超过约 33 行必须换 long long。

> [!example]-
> **边界数据集（先自己跑一遍，再展开对照）**
> 1. 空输入：n=0 → 循环体零次执行，无输出（预期：空、不崩）。
> 2. 单元素：n=1 → 输出一行 `1`（预期：只有行 0）。
> 3. 全相同：无输入序列，改验 n=2：输出 `1` 与 `1 1` 两行（预期：最小程序结构）。
> 4. 严格递增：n=3..10 逐档加大 → 每行首尾恒为 1、中间对称（预期：对称性逐行成立）。
> 5. 严格递减：不适用：行数只能增，改验 n 从 10 降到 3 每档重跑（预期：结果与首次一致）。
> 6. 极值：n=33 → C(33,16)=1166803110 贴近 int 上限仍正常；n=34 起用 int 则第 17 列起回绕成负数——可直接观察到溢出，正解换 long long（防溢出）。

回扣开场：硬算组合数要阶乘、除法、两处溢出风险，二维递推只用加法——现在你能用 $O(n^2)$ 的填表把杨辉三角任何一行稳定算出来，靠的是知识点 3 的边界 + 递推分工。

### 4. 字符二维数组与迷宫棋盘：把地图装进数组

前置依赖：[[#1. 二维数组与行优先存储：内存视角下的行列平面]]、[[一维数组与字符串]]（字符数组与 '\0' 结尾约定）
后续衔接：[[BFS]]（迷宫最短路的正解入口）、[[DFS]]（网格连通性）

**① 它解决什么问题**

元素类型换成 char，二维数组就成了**字符串表**与**地图棋盘**：一行存一个单词（源 p16：`char arr[3][10] = {"Hello","world","C++"};`），或一格存一个地图符号。素材综合案例 3（13.1 综合案例3.pdf）的迷宫是完整应用：10 行 21 列的 `char map[10][21]`，`#` 是墙、空格是路、`o` 是人物。关键性质：每行按 C 字符串规则以 `'\0'` 结尾，第二维要比最长内容多 1 格；整行可当一维字符数组直接输出。

**② 直觉理解**

模型级类比：**文字幻灯片**。每张片子（行）是一行字，摞起来成册；地图版就是每张片子画一行迷宫剖面。人物移动 = 找到 `o` 的格子，按方向算新格：新格是空地就把 `o` 写过去、老格补回空地——地图状态全在数组里。

用具体数字跑一遍：入口 `map[0][18] = 'o'`，按 `s`（下移）→ 新格 `map[1][18]` 是空格 → 写入 `o`、老格还原，人物落位；按 `a`（左移）→ `map[0][17]` 是 `#` → 撞墙，人物不动。

**③ 原理与推导**

迷宫骨架四件事（源 code.cpp）：地图初始化、读方向、按方向更新候选坐标、合法性检查后落位。推导移动规则：w/s/a/d 分别是行号 -1/+1、列号 -1/+1；`newpr/newpc` 先当试探坐标，检查 `map[newpr][newpc] == ' '` 通过才落位，不通过就回滚。

**设计动机：为什么第二维开 21 而不是 20？** 每行 20 个字符还要存一个 `'\0'`，21 格正好装下；只开 20，`'\0'` 溢到下一行开头，`cout << map[i]` 会一直读到下一行内容，整张地图错乱。这也给"第二维不可省略"（知识点 1）补了一层理由：编译器要知道每行多长才能定位"第 i 个字符串"。

**④ 代码演示**

单词倒排（取自素材 12.1 code.cpp 有效代码段，逐行原样；实测输入 `this is c plus plus` 输出 `plus plus c is this`，与源 p23 用例一致）：

```cpp
#include <iostream>
using namespace std;
char c[100][21];               // 每个单词最长 20 字母 + '\0'，共 21 格
int main() {
    int i = 1;
    while (cin >> c[i++]);     // 按词读入：cin >> 对 char 数组遇空白即停，一词一行落位
    i--;                       // 回退多加的 1：循环退出时 i 多自增了一次
    while (--i >= 1)           // 倒序输出（源 p25 写法为 while(--i)，语义相同）
        cout << c[i] << " ";   // 复杂度：O(总字母数)
    return 0;
}
```

迷宫移动核心（摘自素材 code.cpp 的移动判断段，自编整理；交互程序，编译通过、手工按键验证）：

```cpp
char map[10][21] = { /* 10 行 20 列地图 + 每行 '\0' */ };
int currentpr = 0, currentpc = 18;      // 人物当前位置（行, 列）
int newpr = currentpr, newpc = currentpc;
cin >> direction;                        // 读 wsad 之一
switch (direction) {
    case 'w': newpr--; break;            // 上移：行号减 1
    case 's': newpr++; break;            // 下移
    case 'a': newpc--; break;            // 左移：列号减 1
    case 'd': newpc++; break;            // 右移
}
if (map[newpr][newpc] == ' ') {          // 合法性检查：目标格必须是空地
    map[newpr][newpc] = 'o';             // 新格画人
    map[currentpr][currentpc] = ' ';     // 老格还原成路
    currentpr = newpr; currentpc = newpc;
} else {
    newpr = currentpr; newpc = currentpc;   // 撞墙：试探坐标回滚
}
```

**执行追踪表**（人物在 (0,18)，依次按键 s、d）：

| 步骤 | 当前元素 | 结构状态 | 动作 | 结果 |
|:---:|:---:|:---|:---|:---|
| 1 | 按 s | o 在 map[0][18] | newpr=0+1=1 | 试探 (1,18) |
| 2 | map[1][18] | 不变 | 是空格，落位 | map[1][18]='o'，map[0][18]=' ' |
| 3 | 按 d | o 在 map[1][18] | newpc=18+1=19 | 试探 (1,19) |
| 4 | map[1][19] | 不变 | 内容 ' '，落位 | o 移到 (1,19)，旧格还原 |
| 5 | 按 w（对照） | o 在 (1,19) | newpr=0，map[0][19]='#' | 撞墙回滚，人物不动 |

**错误写法对照**：

```diff
- char map[10][20];            // 坑1：第二维正好 20——'\0' 装不下，整行输出串到下一行（答案错）
+ char map[10][21];            // 素材原样：20 字符 + 1 个 '\0'
- map[newpr][newpc] == ' ' 直接落位，无坐标范围检查
+ 移动前先判 0 <= newpr < 10 且 0 <= newpc < 20，再查格子内容
  // 坑2：边界上按 w/a 会把试探坐标推成 -1 或 20，map[-1][x] 越界读写，
  //   Windows 下常见访问违例 0xC0000005（RE）——素材地图四周全是 '#' 是人肉防线，不是代码防线
- while (cin >> c[i++]); 退出后直接用 i 当词数
+ i--; 之后再使用              // 坑3：while 退出时 i 已多加 1，不回退会多输出一次、错位一个词
```

**⑤ 典型应用**

- 课堂题：单词倒排（源 p23-25 应用 3，二维字符数组解法），实测 `this is c plus plus` 输出 `plus plus c is this`；素材另给 gets 版一维解法，但 gets 已从现代 C++ 标准移除且无边界检查，本篇只采用 cin 逐词版（附录 A-3 登记 3）。
- 课堂综合案例：迷宫游戏（13.1 综合案例3.pdf，code.cpp 单关卡 + code2.cpp 双关卡），地图、入口出口坐标、移动、胜利判定全落在二维数组上；两份代码均编译通过（附录 B-5）。
- 迁移题（自编）：给迷宫加"最短步数"输出。思路：人工贪心走法不一定最短，需逐层扩散探索——这正是 [[BFS]] 的入口；本篇的地图表示与四方向增量原封不动带过去。竞赛衔接：网格类题（连通块、最短路、[[DFS]] 回溯）第一步都是"地图读进 char 二维数组 + 四方向循环"。

**⑥ 坑点与边界**

> **【易错】** 第二维容量忘留 `'\0'` 的位置。20 个字符必须开 21；行尾没补 `'\0'` 的行直接输出会越读越远，打印出后面的内容。

> **【易错】** 读入方式与空白符不匹配。`cin >> c[i]` 遇空格/换行即停，只能读"一个词"；要读含空格的整行必须 `cin.getline(c[i], 21)`。素材单词倒排按词读才用 `cin >>`——两种读法由题意决定。

> **【注意】** 迷宫移动必须"先试探、检查、后落位"，撞墙时回滚试探坐标（④代码 else 分支）。省略回滚则人物没动但坐标已指向墙外，下一步在错误坐标上继续试探，状态与位置脱钩。

> [!example]-
> **边界数据集（先自己跑一遍，再展开对照）**
> 1. 空输入：无任何单词（直接 EOF）→ while 一次不进，i=1，i-- 后 0，`--i >= 1` 不成立，无输出（预期：空、不崩）。
> 2. 单元素：只有一个单词 `x` → i=2 退出，i-- 后 1，`--i` 得 0 不输出（预期：与素材 `while(--i)` 行为一致，属源码既定行为）。
> 3. 全相同：`a a a a` → 输出 `a a a a`（预期：倒序不改变全同序列）。
> 4. 严格递增：`a bb ccc dddd` → 输出 `dddd ccc bb a`（预期：词长不影响逐词落位）。
> 5. 严格递减：`dddd ccc bb a` → 输出 `a bb ccc dddd`。
> 6. 极值：100 个单词、每个恰 20 字母 → c[100][21] 恰好装下（预期：不越界）；单词超 20 字母则溢出——素材 p23 数据范围"长度不超过 100、单词最长 20"明确承诺，竞赛中数组要开到数据上限+5。

回扣开场：开场那个"一维数组装不下的面"，最后连字符地图也装下了——现在你能解决开场问题，也能用知识点 4 的地图表示接着去学 [[BFS]] 的最短路。

## 四、总结与自测

### 核心内容（一页纸速览）

- **二维数组**：数组的每个元素是一维数组；`type a[行][列]`；内存连续、行优先，`a[i][j]` 在 首地址 $+ (i \times col + j) \times sizeof$。
- **初始化**：五行写法，推荐按行括起 `{{..},{..}}`；行数可省、列数不可省。
- **双循环框架**：外控行内控列，$O(nm)$；行列和、边缘和、转置都是"框架 + 一句核心操作"，转置输出 m 行 n 列。
- **杨辉三角**：边界（两端为 1）+ 递推（上一行两格相加）的二维填表，$O(n^2)$；n 超约 33 行换 long long。
- **字符二维数组**：每行一个字符串，第二维留 '\0' 位；迷宫"试探-检查-落位-回滚"，通向 [[BFS]]。

### 竞赛衔接说明

本篇四道素材课堂题均无 OJ 题号，练习以自编迁移题为主（已逐题标注）；可对拍的真实 OJ 入口：洛谷 P5731 蛇形方阵（二维递推填表），之后的网格题走 [[BFS]]。二维数组的高阶去向：二维前缀和（[[前缀和与差分]]，查询 $O(1)$）与网格 DP（[[线性DP]]）。

| `while (cin >> x)` | `while (scanf("%d", &x) == 1)` | 读到 EOF 为止的循环 |
| `using namespace std;` | 每个名字前加 `std::` | 免前缀（C 中无此需要） |
