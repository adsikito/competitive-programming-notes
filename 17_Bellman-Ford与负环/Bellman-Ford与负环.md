# Bellman-Ford 与负环

## 零、知识地图

```text
Bellman-Ford 与负环
├── 1. 最短路问题与边松弛 —— 松弛操作 dis[v]=min(dis[v],dis[u]+w)（依赖：[[图的概念存储与遍历]]）
├── 2. Bellman-Ford 逐轮松弛 —— n-1 轮全边松弛 + flag 提前退出（依赖：知识点 1）
├── 3. 负权边与负环检测 —— 第 n 轮仍能松弛即有负环（依赖：知识点 2）
└── 4. 队列优化初探（SPFA 预告）—— 只松弛"距离变小的点"的出边（依赖：知识点 2；资料未覆盖，属补充）

学习顺序：1 → 2 → 3 → 4。理由：松弛是全部最短路算法的共同原子操作（1），Bellman-Ford 把它用到极致
（2），顺着"轮数上限"的推导自然长出负环判定（3），最后看它浪费在哪、队列优化怎么补（4）——
从原子操作到完整算法到扩展判定再到优化方向。
```

## 一、为什么需要它

先用你大概率碰过壁的方式做一遍单源最短路：图里有负权边（比如某条"折扣航线"倒贴钱），你写 Dijkstra——贪心地把当前距离最小的点"定死"，以后不再改。碰壁数据：边 $1 \to 2$ 权 $2$、$1 \to 3$ 权 $5$、$3 \to 2$ 权 $-4$。Dijkstra 先定死 2 号点（距离 2），之后处理 3 号点时发现经 3 中转只要 $5-4=1$，可 2 号点已经"定死"了，答案错——**Dijkstra 的贪心前提"边权非负"被负边击穿**（A 源 slide 2 明确：Dijkstra 不能处理负边权）。换 Floyd？$O(|V|^3)$，$n=10^4$ 时 $10^{12}$ 量级，必超时。

Bellman-Ford 的破法：**不做"定死"这种赌注，每轮把所有边都试一遍松弛**，$O(|V||E|)$，能处理负边权，还顺手送一个负环检测器。本篇讲 4 个知识点：边松弛、Bellman-Ford 逐轮松弛、负环检测、队列优化初探（SPFA 预告）。

## 二、知识点逐讲（每个知识点一节，共 4 节）

### 1. 最短路问题与边松弛：全部最短路算法的原子操作

前置依赖：[[图的概念存储与遍历]]（有向图、边权、邻接矩阵存图）
后续衔接：[[#2. Bellman-Ford：逐轮全边松弛]]、[[#4. 队列优化初探（SPFA 预告）——资料未覆盖，属补充]]

**① 它解决什么问题**

单源最短路：给定起点 s，求 s 到其余每点的最短路径。A 源 slide 1-2 给出算法谱系：Floyd 多源 $O(|V|^3)$、Dijkstra 单源 $O(|V|^2)$ 但不能有负边权。它们共享同一个原子操作——A 源 slide 3 的**松弛（relax）**：若已知 $dis[i]$，则用 i 做中转缩短 s 到 j 的距离，$dis[j] = \min(dis[j],\; dis[i] + w[i][j])$。本知识点只把这一行代码讲透；性质表融入正文：松弛操作/单次 O(1)/前提：dis[u] 是 s 到 u 的当前已知距离/效果：dis[v] 只减不增。

**② 直觉理解**

模型级类比：**机票中转比价**。dis[v] 是你手上"从家到 v 的最低报价"。每拿到一个新的中转城市 u（报价 dis[u]），就查一遍"从 u 飞到 v 的票价"：若 dis[u] + 票价 比你手上的报价低，就改签。报价单只降不升，且每次下降都来自"某条真实存在的路径"，所以永远不会低于真实最短路。

用具体数字跑一遍：s=1，边 $1 \to 2$ 权 4、$1 \to 3$ 权 1、$3 \to 2$ 权 2。初始 $dis = [0, \infty, \infty]$（下标 1..3）。松弛 $1 \to 2$：$0+4=4 < \infty$，dis[2]=4；松弛 $1 \to 3$：dis[3]=1；松弛 $3 \to 2$：$1+2=3 < 4$，dis[2]=3。中转一次，省 1 元。

**③ 原理与推导**

松弛为什么是对的？归纳依据：$dis[u] + w[u][v]$ 恰好是"s 经某条真实路径到 u，再走边 $\langle u,v \rangle$"这条路径的总长，它若小于当前 dis[v]，就用它替换——替换后 dis[v] 仍对应一条真实路径，且严格更小。反复执行，dis[v] 沿"真实路径的长度"单调下降、有下界（真实最短路），最终停在真实最短路上。

设计动机：为什么各算法差异只体现在"松弛的执行顺序"上？Floyd 允许中转点任意加入（A 源 slide 3 第一个式子），Dijkstra 按"距离最小优先"的顺序松弛（贪心，负边会推翻已定的顺序），Bellman-Ford 干脆不管顺序、每轮全边都松（下一知识点）。顺序决定了正确性前提与复杂度——这就是"同一种操作、三种命运"的原因。

**④ 代码演示**

松弛的代码形态（自编骨架，与 A 源 slide 3 原式对应；完整使用场景见知识点 2④）：

```cpp
const int INF = 0x3f3f3f3f;              // 原因：0x7fffffff 相加会溢出成负数（见⑥）
int n, m, w[105][105];                   // 邻接矩阵存边权，无边记 INF（C 等价：二维数组，同 C）
int dis[105];
void relax(int u, int v) {               // 对边 <u,v> 的一次松弛
    if (dis[u] != INF && dis[u] + w[u][v] < dis[v])   // 守卫：INF 不参与相加
        dis[v] = dis[u] + w[u][v];       // 经 u 中转更近，才更新
}
```

**执行追踪表**（②的三角形数据：s=1，边 $1 \to 2$(4)、$1 \to 3$(1)、$3 \to 2$(2)）：

| 步骤 | 当前元素 | 结构状态（dis，下标 1..3） | 动作 | 结果 |
|:---:|:---:|:---|:---|:---|
| 1 | 初始 | [0, INF, INF] | dis[s]=0 | 报价单就绪 |
| 2 | relax(1,2) | [0, INF, INF] | 0+4=4 < INF，松弛 | dis[2]=4 |
| 3 | relax(1,3) | [0, 4, INF] | 0+1=1 < INF，松弛 | dis[3]=1 |
| 4 | relax(3,2) | [0, 4, 1] | 1+2=3 < 4，松弛 | dis[2]=3，中转省 1 |

**错误写法对照**：

```diff
- dis[v] = w[u][v];   // 坑1：丢了 dis[u]，把"s 到 v"写成了"u 到 v"——起点丢失，答案整体错（答案错）
+ dis[v] = dis[u] + w[u][v];   // 松弛 = 前段路径长 + 这条边
- if (dis[u] + w[u][v] < dis[v])   // 坑2：dis[u]=0x7fffffff 时 +1 溢出成负数，负数 < dis[v] 成立，
+ if (dis[u] != INF && dis[u] + w[u][v] < dis[v])   // 错误更新不可达点（答案错）；先判 INF 再相加
- w[u][v] = w[v][u] = x; 只写了 w[u][v]   // 坑3：无向图只存单向，反方向松弛不到（答案错）
+ 无向图两条方向都要赋值：w[u][v] = w[v][u] = x
```

**⑤ 典型应用**

- 真题：洛谷 P4779【模板】单源最短路（标准版）——边权非负，是 Dijkstra 的主场，但松弛写法与本节完全相同，可以对照体会"操作相同、顺序不同"。
- A 源 slide 1-2 的 Floyd/Dijkstra 复习：两者都是松弛的不同排班表，先认准原子操作再学排班。
- 迁移题（自编）：三城机票问题——城市 1、2、3，票价如②，依次给出"新开通的航班"，每开通一条就输出三城最低价。思路：每读一条边就对其两端各做一次松弛，输出 dis。

**⑥ 坑点与边界**

> **【易错】** INF 取 0x7fffffff 且不设守卫。后果：不可达点两两"中转"时 INF+正数 溢出为负数，被当成"超低价"错误更新（答案错）。正解：INF 用 0x3f3f3f3f（约 $1.06 \times 10^9$，两倍仍在 int 范围内）并在比较前判 `dis[u] != INF`。

> **【易错】** 写成 `dis[v] = w[u][v]`。后果：丢掉 s 到 u 的前段路径，从第一步就错（答案错）。

> **【注意】** 松弛只保证 dis 不低于真实最短路、且每次更新对应真实路径；它不保证"一次到位"——dis[2] 从 4 降到 3 用了两步，这正是 Bellman-Ford 要跑多轮的原因。

> [!example]-
> **边界数据集（先自己跑一遍，再展开对照）**
> 1. 空输入：n=1, m=0 → 无边可松，dis=[0]（预期：输出 0，不崩）。
> 2. 单元素：n=1, 自环 $1 \to 1$ 权 5 → dis[1]+5=5 > 0 不更新（预期：dis[1]=0 不变）。
> 3. 全相同：重边 $1 \to 2$ 权 4 与权 4 → 两次松弛结果相同（预期：幂等）。
> 4. 严格递增：边权 1、2、3 的链 → 松弛沿链逐点推进（预期：dis 依次变 小）。
> 5. 严格递减：边权 3、2、1 的链 → 同上，与递减序无关（预期：松弛不看边的大小关系）。
> 6. 极值：dis[u]=0x7fffffff，边权 +1，无守卫 → int 溢出为 -2147483648，被误判"超低价"（预期：加守卫后不更新；本条专查溢出）。

回扣开场：Dijkstra 输错的那道题，用本节的松弛逐边修正就能算对（dis[2] 最终 = 1）——下一节看"按什么节奏把所有边松完"。

### 2. Bellman-Ford：逐轮全边松弛

前置依赖：[[#1. 最短路问题与边松弛：全部最短路算法的原子操作]]
后续衔接：[[#3. 负权边与负环检测：第 n 轮的判定]]、[[#4. 队列优化初探（SPFA 预告）——资料未覆盖，属补充]]

**① 它解决什么问题**

A 源 slide 3-4 定义：Bellman-Ford（简称 Ford 算法）是**单源**最短路算法，时间复杂度 $O(|V| \cdot |E|)$，**能处理负边权**，不能求"存在负权回路"的图的最短路，但可以用来判断负权回路（判定见知识点 3）。核心做法（A 源原话）："不断尝试对图中的每一条边进行松弛，每进行一轮循环就对所有边尝试一次松弛，当一轮中没有成功的松弛时算法停止"——暴力遍历。复杂度总账：每轮 $O(|E|)$，最多 $|V|-1$ 轮，故 $O(|V||E|)$。

**② 直觉理解**

模型级类比：**全网比价轮询**。你是票务平台，每轮把"所有航线"按固定顺序全查一遍：任何一条能让报价下降的中转组合立刻改签。一轮结束若报价单纹丝不动，说明再也没有更便宜的中转方案，收工。

用具体数字跑一遍（A 源源码注释样例，$n=5, m=5$，边 $2 \to 3$(2)、$1 \to 2$(-3)、$1 \to 5$(5)、$4 \to 5$(2)、$3 \to 4$(3)，s=1）：第 1 轮 $1 \to 2$ 把 dis[2] 压到 -3、$1 \to 5$ 压到 5；第 2 轮才轮到依赖 dis[2] 的 $2 \to 3$ 和依赖 dis[3] 的 $3 \to 4$；第 3 轮 $4 \to 5$ 再把 dis[5] 从 5 压到 4——"路径信息一轮只往前推进一段"，这就是逐轮的含义。

**③ 原理与推导**

为什么最多 $|V|-1$ 轮？（A 源 slide 3 的论证补全中间步）不含负环时，s 到任一点的最短路最多经过 $|V|-1$ 条边（经过 $|V|$ 个点的简单路径）。看 dis 的传播速度：s 的直接邻居在第 1 轮内必然被松弛到"只差一条边的最短值"；第 2 轮内，"只差两条边"的点全部到位——**每完整一轮，最短路信息沿边数至少多传播 1 条边**。因此第 k 轮结束时，所有"最短路恰好用 k 条边"的点已经定型；$|V|-1$ 轮后全部定型。这就是 $O(|V||E|)$ 里 $|V|$ 因子的来源，也是设计动机：逐轮不是随意的暴力，而是"按路径边数分期到账"的确定性过程。

A 源 Ford算法.cpp 的 flag 提前退出：若某一轮没有任何边松弛成功，说明报价单已收敛，后续轮次不可能再有变化，直接 break——这是纯加速，不影响正确性（最坏仍按 $|V|-1$ 轮计）。

```text
第 0 轮：dis[s]=0，其余 INF
第 k 轮：扫全部 |E| 条边做松弛 → "最短路边数 <= k" 的点全部定型
第 k 轮无任何松弛成功 → 提前退出（已收敛）
```

**④ 代码演示**

取自源文件 Ford算法.cpp（相对源文件的改动：inf 由 `#define inf 1001` 改为 `const int INF = 0x3f3f3f3f`，并加 `dis[u] != INF` 守卫——原因与实测证据见知识点 3⑥；flag 由 int 改 bool；变量声明局部化。完整版见源文件 Ford算法.cpp）：

```cpp
#include <iostream>
using namespace std;
const int INF = 0x3f3f3f3f;          // 复杂度：总 O(n*m)，m 条边每轮扫一遍
int n, m, s;
struct Edge { int start, end, w; } e[10005];   // 边集数组存图（C 等价：struct + 全局数组）
int dis[105];
void ford() {
    for (int i = 1; i < n; i++) {    // 最多 n-1 轮（③的结论）
        bool flag = false;           // 本轮是否有成功松弛
        for (int j = 1; j <= m; j++) {          // 每轮扫全部 m 条边
            int u = e[j].start, v = e[j].end;
            // 错：无守卫直接 dis[u]+e[j].w<dis[v]，INF 参与运算会污染不可达点
            // 对：先判 dis[u] != INF
            if (dis[u] != INF && dis[u] + e[j].w < dis[v]) {
                dis[v] = dis[u] + e[j].w;       // 松弛（知识点 1）
                flag = true;
            }
        }
        if (!flag) break;            // 一轮无松弛 = 已收敛，提前退出
    }
}
int main() {
    cin >> n >> m;
    for (int i = 1; i <= m; i++) cin >> e[i].start >> e[i].end >> e[i].w;
    for (int i = 1; i <= n; i++) dis[i] = INF;
    cin >> s; dis[s] = 0;
    ford();
    for (int i = 1; i <= n; i++) cout << dis[i] << " ";
    return 0;
}
```

**执行追踪表**（源文件注释样例：$n=5$，边 $2 \to 3$(2)、$1 \to 2$(-3)、$1 \to 5$(5)、$4 \to 5$(2)、$3 \to 4$(3)，s=1，INF=0x3f3f3f3f；"结构状态"列即 dis 数组逐轮变化，下标 1..5，inf 缩写为 I）：

| 步骤 | 当前元素 | 结构状态（dis 1..5） | 动作 | 结果 |
|:---:|:---:|:---|:---|:---|
| 1 | 初始化 s=1 | [0, I, I, I, I] | dis[1]=0 | 起点 0，其余 INF |
| 2 | 第1轮 e1(2→3,2) | [0, I, I, I, I] | dis[2]=I，I+2 不小于 I | 无变化 |
| 3 | 第1轮 e2(1→2,-3) | 同上 | 0-3=-3 < I，松弛 | dis[2]=-3 |
| 4 | 第1轮 e3(1→5,5) | [0, -3, I, I, I] | 0+5=5 < I，松弛 | dis[5]=5 → [0,-3,I,I,5] |
| 5 | 第1轮 e4(4→5,2) | [0, -3, I, I, 5] | dis[4]=I，守卫拦截 | 无变化 |
| 6 | 第1轮 e5(3→4,3) | 同上 | dis[3]=I，守卫拦截 | 无变化 |
| 7 | 第2轮 | [0, -3, I, I, 5] | e1：-3+2=-1 松弛 dis[3]；e5：-1+3=2 松弛 dis[4] | → [0,-3,-1,2,5] |
| 8 | 第3轮 | [0, -3, -1, 2, 5] | e4：2+2=4 < 5 松弛 dis[5] | → [0,-3,-1,2,4] |
| 9 | 第4轮 | [0, -3, -1, 2, 4] | 全部边不再变小，flag=0 | break，输出 0 -3 -1 2 4 |

**错误写法对照**：

```diff
- for (int i = 1; i <= n; i++)   // 坑1：最短路求解版写成 n 轮——多跑的一轮会把"可达负环"也悄悄
+ for (int i = 1; i < n; i++)    // 松出错误结果；求解用 n-1 轮，第 n 轮留给判负环（知识点 3）
- bool flag = false; 定义在双循环外且轮内不重置   // 坑2：只要历史上松过一次就永远不 break——
+ 每轮开始 flag = false;                        // 不影响正确性但提前退出彻底失效（白跑满轮数）
- for (int j = 0; j < m; j++)    // 坑3：边集数组下标从 1 存、却从 0 扫——e[0] 是垃圾值，可能
+ for (int j = 1; j <= m; j++)   // 拿随机下标访问 dis 越界（RE）
```

**⑤ 典型应用**

- 真题：洛谷 P3371【模板】单源最短路（弱化版）——图含负权边、无负环；朴素 Ford 的 $O(nm) \approx 5 \times 10^9$ 会超时，需本篇知识点 4 的队列优化通过。它回答了"为什么要学优化"。
- 源文件 Ford算法.cpp 注释样例（$n=5, m=5$，输出 `0 -3 -1 2 4`，附录 B-5 实测一致）——负边权使 dis 中间值出现负数，是 Dijkstra 场景看不到的现象。
- 迁移题（自编）：限定边数最短路——n 点 m 边有向图（边权可负、无负环），求 s 到 t **最多经过 k 条边**的最短路。思路：Bellman-Ford 恰好"一轮 = 边数 +1"，只跑 k 轮、取 dis[t] 即可；这是逐轮松弛最贴身的变体。

**⑥ 坑点与边界**

> **【易错】** INF 取值过小。源文件用 `#define inf 1001`，而注释自述 $n \le 100$、边权绝对值 $<1000$——一条 100 条边的路径总权可达 $10^5$ 量级，超过 1001 时"未算完的真路径"与"没路"无法区分（答案错）。正解：INF 按"最长可能路径总权 + 1"取，或直接 0x3f3f3f3f。

> **【易错】** 求解版误跑 n 轮。$n-1$ 轮已定型，多跑的第 n 轮在图中有可达负环时会继续松弛出负值——求解题直接答案错；判定题才故意跑第 n 轮（知识点 3）。

> **【注意】** 边的扫描顺序影响"几轮收敛"：样例里 $2 \to 3$ 排在第 1 条，第 1 轮它还帮不上忙；若把 $1 \to 2$ 排最前、$2 \to 3$ 紧随其后，第 1 轮就能推进两条边。顺序只影响轮数，不影响最终正确性（③的"分期到账"保证最坏 $|V|-1$ 轮封顶）。

> [!example]-
> **边界数据集（先自己跑一遍，再展开对照）**
> 1. 空输入：n=1, m=0 → 外层循环 i=1<1 不执行，输出 0（预期：只输出起点 0）。
> 2. 单元素：n=1, 自环 $1 \to 1$(-5) → 第 1 轮 e1：0-5=-5 < 0 松弛？是——注意本题 n-1=0 轮根本不跑，自环影响被规避（预期：输出 0；若有负自环则该图本身有负环，属知识点 3 管辖）。
> 3. 全相同：m 条重边 $1 \to 2$ 权 -3 → 第 1 轮全部松弛到同一值，第 2 轮无变化退出（预期：dis[2]=-3）。
> 4. 严格递增（链式松）：边按 $1 \to 2$、$2 \to 3$、$3 \to 4$ 顺序排 → 每轮恰好推进一条边，共 3 轮（预期：轮数 = 链长，验证"分期到账"）。
> 5. 严格递减（逆序链）：边按 $3 \to 4$、$2 \to 3$、$1 \to 2$ 顺序排 → 第 1 轮连续推进 3 条边，第 2 轮即收敛（预期：1 轮完成，验证⑥【注意】）。
> 6. 极值：dis=INF=0x3f3f3f3f，边权 +1 且无守卫 → $0x3f3f3f3f+1$ 仍是正数不溢出但属"伪路径"污染，连续松弛会把 INF 逐点抬走（预期：必须加守卫；本条专查 INF 语义）。

回扣开场：现在你能解决"Dijkstra 被负边击穿"的那道题了——用的是知识点 1 的松弛 + 本节的逐轮排班（dis[2] 经 3 中转最终为 1，且不用"定死"任何点）。接下来处理遗留问题：如果图里有负环怎么办。

### 3. 负权边与负环检测：第 n 轮的判定

前置依赖：[[#2. Bellman-Ford：逐轮全边松弛]]
后续衔接：[[#4. 队列优化初探（SPFA 预告）——资料未覆盖，属补充]]、[[拓扑排序]]（差分约束建模视角，资料未覆盖，属补充）

**① 它解决什么问题**

A 源 slide 4 定义：**负权回路**是边权之和为负数的回路；课件例：回路 ②-④-⑤-③-② 边权和为 -3。存在负环时最短路不存在——从起点绕环走一圈路径长就减 3，走无数圈就是无穷小。所以"求最短路"作废，但 Bellman-Ford 给出替代能力：**判定从 s 出发能否抵达负环**。判定方法（A 源 slide 4）：最短路存在时松弛最多 $n-1$ 轮，因此**若第 n 轮仍存在能松弛的边，说明从 s 可达一个负环**。复杂度：判定跑满 n 轮，$O(|V||E|)$，无提前退出。

**② 直觉理解**

模型级类比：**无限刷钱的旅行圈**。三条航线构成一个圈，绕一圈总票价 -3 元——先花 100 元进场，绕 34 圈后进场费就赚回来了，再绕就无限盈利。报价单上圈内城市的报价会一轮轮往下掉、永不停止。而 Bellman-Ford 恰好是"逐轮观察报价单"的仪器：**正常图 n-1 轮后报价单静止；还在动的，就是刷钱圈**。

用具体数字跑一遍：$n=3$，边 $1 \to 2$(1)、$2 \to 3$(-1)、$3 \to 2$(-2)，s=1。环 $2 \to 3 \to 2$ 权和 $-3$。第 1 轮 dis = [0,-2,0]，第 2 轮 [0,-5,-3]，第 3 轮（i==n）仍能松弛 → 输出"有负环"（附录 B-5 实测一致）。

**③ 原理与推导**

为什么"第 n 轮仍能松弛"等价于"s 可达负环"？两个方向各推一遍。正向（有负环则第 n 轮必松）：s 可达负环时，先把路径信息传到环上（有限轮），之后每绕环一圈、环上各点 dis 至少再降"环权和的绝对值"，**松弛永远不会停**，第 n 轮自然还有成功松弛。反向（第 n 轮仍松则无最短路）：若所有 dis 已是最短路，则对任意边 $\langle u,v \rangle$ 有 $dis[v] \le dis[u] + w$（三角不等式），任何松弛都不会成功；第 n 轮还有成功松弛，说明某个 dis 还在下降，与"已是最终答案"矛盾——故该图从 s 出发不存在有限最短路，即 s 可达负环。

设计动机：为什么判定要多跑第 n 轮、而求解只跑 n-1 轮？因为 n-1 轮后的"还能不能松"本身就是信息——正常图它必为"否"，负环图它必为"是"。第 n 轮是刻意的"探测针"，这也是源文件 Ford算法判断负环.cpp 用 `for (i = 1; i <= n)` 且不设 flag 提前退出的原因（提前退出会让探测针永远扎不下去）。

**④ 代码演示**

取自源文件 Ford算法判断负环.cpp（相对源文件的改动：加 `dis[u] != INF` 守卫——素材版无守卫，实测对"负环从 s 不可达"的图会误报，见⑥与附录 B-5；其余逻辑逐行原样。完整版见源文件）：

```cpp
#include <iostream>
using namespace std;
const int INF = 0x3f3f3f3f;
int n, m, s;
struct Edge { int start, end, w; } e[10005];
int dis[105];
bool ford() {                        // 返回 true = s 可达负环
    int f = 0;
    for (int i = 1; i <= n; i++) {   // 注意：n 轮，不是 n-1 轮
        for (int j = 1; j <= m; j++) {
            int u = e[j].start, v = e[j].end;
            if (dis[u] != INF && dis[u] + e[j].w < dis[v]) {   // 守卫（改动处）
                dis[v] = dis[u] + e[j].w;
                if (i == n) f = 1;   // 第 n 轮仍在松弛 -> 探测针扎中负环
            }
        }
    }
    return f == 1;
}
int main() {
    cin >> n >> m;
    for (int i = 1; i <= m; i++) cin >> e[i].start >> e[i].end >> e[i].w;
    for (int i = 1; i <= n; i++) dis[i] = INF;
    cin >> s; dis[s] = 0;
    if (ford()) cout << "有负环" << endl;
    else for (int i = 1; i <= n; i++) cout << dis[i] << " ";
    return 0;
}
```

**执行追踪表**（②的负环图：$n=3$，边 $1 \to 2$(1)、$2 \to 3$(-1)、$3 \to 2$(-2)，s=1；结构状态列展示 dis 永不收敛）：

| 步骤 | 当前元素 | 结构状态（dis 1..3） | 动作 | 结果 |
|:---:|:---:|:---|:---|:---|
| 1 | 初始化 s=1 | [0, I, I] | dis[1]=0 | 起点 0 |
| 2 | 第1轮 e1,e2,e3 | [0, I, I] | e1：dis[2]=1；e2：dis[3]=0；e3：-2 < 1 松弛 dis[2] | → [0,-2,0] |
| 3 | 第2轮 | [0, -2, 0] | e2：-2-1=-3 松弛 dis[3]；e3：-3-2=-5 松弛 dis[2] | → [0,-5,-3] |
| 4 | 第3轮（i==n） | [0, -5, -3] | e2、e3 继续松弛，f=1 | 输出"有负环" |

**错误写法对照**：

```diff
- for (int i = 1; i < n; i++)   // 坑1：判定版照抄求解版的 n-1 轮——第 n 轮探测针没了，
+ for (int i = 1; i <= n; i++)  // 有负环也判不出来（漏报）
- for (int i = 1; i <= n; i++) { bool flag = ...; if (!flag) break; }   // 坑2：判定版加提前退出——
+ 判定版不设 break               // 第 n 轮根本到不了或信息丢失，负环漏报（漏报）
- if (dis[u] + e[j].w < dis[v])   // 坑3：无守卫——s 不可达的点 dis=INF，负边把它拉下来，
+ if (dis[u] != INF && ...)       // 每轮都"伪松弛"，不可达负环也被误报（误报，附录 B-5 实测）
```

**⑤ 典型应用**

- 真题：洛谷 P3385【模板】负环——多组数据判全图负环。注意它要求判"图中是否存在负环"，不保证从 1 可达，常用做法是所有点先入队（等价于加一个连向所有点的虚拟源点）；本节判的是"s 可达负环"，迁移时把初始化改成全部 dis=0 即可覆盖全图。
- 真题：洛谷 P5960【模板】差分约束算法——把不等式组转成图，无解判定恰好是"图有负环"，本节判定是它的核心零件。资料未覆盖建模细节，属延伸提示。
- 迁移题（自编）：给知识点 2 的限定边数最短路加一道保险——若 k 轮后 dis 仍在下降，输出"边数限制内存在下降循环"。思路：探测针从"第 n 轮"改为"第 k+1 轮"。

**⑥ 坑点与边界**

> **【易错】** 无守卫 + 负边权导致**误报负环**。实测（附录 B-5 用例 4）：s 不可达的两个点 3、4 之间有负边 $3 \to 4$(-1)、$4 \to 3$(-1)，dis[3]=dis[4]=INF=1001 时 $1001-1 < 1001$ 成立，每轮都伪松弛，第 n 轮仍"成功"——程序输出"有负环"，而实际 s 可达部分毫无负环。正解：`dis[u] != INF` 守卫；同一根因还会让不可达点经负边得到错误"距离"（实测 dis[3]=996）。

> **【易错】** 判定版误加 flag 提前退出。后果：负环图若在探测前恰好"暂时静止"会被漏报（③的探测针逻辑被破坏）。

> **【注意】** 判定针对的是"s 可达的负环"。s 到不了的负环对"s 的最短路"无害，但在"判全图负环"的题（P3385）里必须换初始化（全部 dis=0 或虚拟源点），两种需求不要混淆。

> [!example]-
> **边界数据集（先自己跑一遍，再展开对照）**
> 1. 空输入：n=1, m=0 → n 轮循环里没有边可松，f=0（预期：输出"无负环"侧，即 dis）。
> 2. 单元素：n=1, 负自环 $1 \to 1$(-1) → 第 1 轮即 i==n，松弛成功 f=1（预期：有负环——自环就是长度为 1 的回路）。
> 3. 全相同：零权环 $2 \to 3$(0)、$3 \to 2$(0) → 权和 0 非负，dis 稳定（预期：不报负环；负环要求**严格**小于 0）。
> 4. 严格递增：环上边权 1、2、3 → 环权和为正，第 1 轮后静止（预期：无负环）。
> 5. 严格递减：环上边权 -1、-2、-3 → 环权和 -6，dis 每轮下降（预期：有负环）。
> 6. 极值：n=2000、边权 $-10^9$、负环长 2 → n 轮内 dis 最低约 $-2 \times 10^9$ 量级，贴 int 下限，有溢出风险（预期：边权达 $10^9$ 量级的判负环题用 long long 存 dis；本条专查溢出）。

回扣开场：现在你能回答"图里有负环怎么办"了——用的是③的探测针（第 n 轮仍能松弛即 s 可达负环）加④的守卫写法。还剩最后一个问题：每轮全边暴力太奢侈，能不能省。

### 4. 队列优化初探（SPFA 预告）——资料未覆盖，属补充

前置依赖：[[#2. Bellman-Ford：逐轮全边松弛]]、[[栈与队列]]（队列的 push/pop/empty 操作）
后续衔接：「Dijkstra 与 SPFA」篇（同批产出，文字锚定）、[[BFS]]（同为队列驱动的图遍历，但语义不同）

**① 它解决什么问题**

A 源 slide 1 把 SPFA 列为四大最短路算法之一；B 源 pdf 第 21 页可辨认出"Bellman-Ford 与 SPFA（Bellman-Ford 算法的队列优化）"的字样——两份资料都只点了名，没讲流程，本节是通识补充。要解决的问题：Ford 每轮扫全部 m 条边，但第 3 轮的样例里实际起作用的只有 1 条边（e4）——**绝大多数边松弛必然失败，因为它们的起点 dis 根本没变过**。SPFA（Shortest Path Faster Algorithm）的思想：只有 dis[u] 刚变小的点，它的出边才可能松弛成功；用一个队列维护"刚变小的点"，只扫这些点的出边。复杂度：一般情况远快于 $O(|V||E|)$，但最坏仍退化为 $O(|V||E|)$，且可被特殊数据卡满。

**② 直觉理解**

模型级类比：**病情广播**。Ford 是"每轮给全城所有人量体温"；SPFA 是"谁刚确诊，只检查他的密切接触者"。刚变小的点 u 是新的"传染源"，只有 u 的出边邻居可能因此变小；邻居变小又入队成为新传染源。队列空了，说明没有新传染源，报价单收敛。

用具体数字跑一遍（知识点 2 的样例图）：初始队列 [1]。处理 1：松弛 $1 \to 2$、$1 \to 5$，2、5 入队；处理 2：松弛 $2 \to 3$，3 入队；处理 5：无出边；处理 3：松弛 $3 \to 4$，4 入队；处理 4：$4 \to 5$ 松弛 dis[5]=4，5 再入队；处理 5：无出边，队列空。共检查 6 条边的尝试，Ford 要 20 条（4 轮 × 5 边）。

**③ 原理与推导**

与 Ford 的关系：SPFA 的每次"处理队首 u、松弛其出边"等价于 Ford 的一次局部松弛，正确性完全继承知识点 1 的归纳依据。为什么用队列而不是把 Ford 的轮次砍掉？因为松弛有依赖（$2 \to 3$ 依赖 dis[2] 先变小），队列恰好按"发现变化 → 立即传播"的因果顺序安排工作，避免了 Ford"整轮空转"的浪费。为什么最坏仍是 $O(|V||E|)$？一个点的 dis 可以被更新多次、多次入队，构造得当的图能让每个点入队 $O(|V|)$ 次、每次扫 $O(deg)$ 条边，总量回到 $O(|V||E|)$——SPFA 是常数级的改进期望，不是复杂度级的保证。

**④ 代码演示**

自编骨架（资料未覆盖 SPFA 源码，属补充；存图改邻接表以支持"只扫出边"）：

```cpp
#include <iostream>
#include <cstring>
#include <vector>
#include <queue>
using namespace std;
const int INF = 0x3f3f3f3f;
int n, m, s;
struct Edge { int to, w; };
vector<Edge> g[105];      // 邻接表（C 等价：每行一个"变长数组"，用链表或定长数组可模拟）
int dis[105];
bool inq[105];            // 是否在队列中（防重复入队）
void spfa() {             // 复杂度：期望远小于 O(n*m)，最坏 O(n*m)
    queue<int> q;         // C 等价：head/tail 两指针 + 数组模拟队列（[[栈与队列]] 的写法）
    memset(dis, 0x3f, sizeof(dis));   // C 等价：for 循环逐个赋 INF
    memset(inq, 0, sizeof(inq));
    dis[s] = 0; q.push(s); inq[s] = true;
    while (!q.empty()) {
        int u = q.front(); q.pop(); inq[u] = false;
        for (int j = 0; j < (int)g[u].size(); j++) {   // 只扫 u 的出边
            int v = g[u][j].to, w = g[u][j].w;
            if (dis[u] + w < dis[v]) {                 // 与 Ford 相同的松弛判断
                dis[v] = dis[u] + w;
                if (!inq[v]) { q.push(v); inq[v] = true; }   // 变小才入队
            }
        }
    }
}
int main() {
    cin >> n >> m;
    for (int i = 1; i <= m; i++) { int x, y, w; cin >> x >> y >> w; g[x].push_back({y, w}); }
    cin >> s;
    spfa();
    for (int i = 1; i <= n; i++) cout << dis[i] << " ";
    return 0;
}
```

**执行追踪表**（知识点 2 的样例图转邻接表，s=1；结构状态列 = 队列 + dis 变化）：

| 步骤 | 当前元素 | 结构状态 | 动作 | 结果 |
|:---:|:---:|:---|:---|:---|
| 1 | 初始化 | 队列 [1]，dis [0,I,I,I,I] | s 入队 | 工作开始 |
| 2 | u=1 | 队列 [] | 松弛 $1 \to 2$、$1 \to 5$ | dis[2]=-3, dis[5]=5，队列 [2,5] |
| 3 | u=2 | 队列 [5] | 松弛 $2 \to 3$ | dis[3]=-1，队列 [5,3] |
| 4 | u=5 | 队列 [3] | 5 无出边 | 无变化 |
| 5 | u=3 | 队列 [] | 松弛 $3 \to 4$ | dis[4]=2，队列 [4] |
| 6 | u=4 | 队列 [] | $4 \to 5$：2+2=4 < 5 | dis[5]=4，5 入队 [5] |
| 7 | u=5 | 队列 [] | 无出边，队列空 | 结束，输出 0 -3 -1 2 4 |

**错误写法对照**：

```diff
- if (dis[u] + w < dis[v]) { dis[v] = dis[u] + w; q.push(v); }   // 坑1：不判 inq 重复入队——
+ if (!inq[v]) { q.push(v); inq[v] = true; }   // 同一点被多个邻居同时更新时塞入多次，队列膨胀（TLE 风险）
- while (!q.empty()) { int u = q.front(); q.pop(); ... }   // 坑2：pop 后忘了 inq[u] = false——
+ inq[u] = false 紧跟 pop                    // 该点之后再变小永远无法重新入队（答案错）
- if (dis[u] + w < dis[v])    // 坑3：判负环时只靠队列不空——图有负环时队列永不空（死循环）；
+ 判负环需另加计数：记录每点入队次数，达到 n 即有负环（详见「Dijkstra 与 SPFA」篇）
```

**⑤ 典型应用**

- 真题：洛谷 P3371【模板】单源最短路（弱化版）——含负权边，SPFA 在此题通过；SPFA 骨架与本节④一致。
- 真题：洛谷 P3385【模板】负环——主流做法之一是 SPFA 加"入队次数达到 n 即有负环"的计数判定（知识点 3⑥的思路搬到队列上）。
- 迁移检验题（自编）：知识点 2 的限定边数最短路改用 SPFA 思想做——给每条队列记录附上"当前边数"，超过 k 的不再扩展。建议先独立做，再对照题解：状态从 dis[v] 扩成 dis[v][边数]，队列元素为（点, 已用边数）二元组，松弛条件 $dis[u][k] + w < dis[v][k+1]$；答案 $\min_{j \le k} dis[t][j]$。标（自编）。

**⑥ 坑点与边界**

> **【易错】** 认为 SPFA 复杂度是 $O(k|E|)$（k 为小常数）就高枕无忧。反例：故意构造的网格/链式数据可把每个点逼到入队 $O(n)$ 次，总量 $O(|V||E|)$——竞赛里"SPFA 已死"的梗就来自被针对性卡死的场景。正解：负权图无更优通用选择时才用，且写法上尽量精简。

> **【易错】** 判负环用"队列不空即有负环"。后果：有负环时队列确实永不空，但你等不到它"不空"的那一天——程序死循环。正解：入队次数计数，某点入队达 n 次即判负环。

> **【注意】** inq 标记与 pop 时清零必须成对出现；这两个 bug（坑 1、坑 2）单独看都"样例能过"，对抗数据才爆，属于最隐蔽的一类失分。

> [!example]-
> **边界数据集（先自己跑一遍，再展开对照）**
> 1. 空输入：n=1, m=0 → 队列 [1] 处理完即空（预期：输出 0）。
> 2. 单元素：n=1, 自环 $1 \to 1$(0) → dis[1]+0=0 不小于 0，不入队（预期：队列空，正常结束）。
> 3. 全相同：m 条重边同权 → 首次松弛后其余重边条件不成立（预期：每点至多入队常数次）。
> 4. 严格递增：链 $1 \to 2 \to 3 \to 4$ 边权递增 → 每点恰好入队一次（预期：队列长度峰值 1）。
> 5. 严格递减：链上后边更优 → 前点会因后点回传而二次入队（预期：入队次数 > 1，验证 inq 清零的必要性）。
> 6. 极值：n=10^5 链 + 交替正负边权构造卡 SPFA 数据 → 退化为 O(nm) 约 $10^{10}$，超时（预期：认识到 SPFA 上限；本条专查复杂度误判）。

回扣开场：现在你能解决开场那个问题了——负边权图先跑知识点 3 的判定排除负环，再用本节的队列优化把 Ford 的浪费砍掉。到这里，A 源 slide 1 的四大算法你已拿下两个的完整实现（Ford 系）。

## 三、全篇坑点总表

| # | 坑 | 正解 |
|---|-----|------|
| 1 | 松弛写成 dis[v]=w[u][v] | dis[v]=dis[u]+w[u][v]（知识点 1④） |
| 2 | INF 用 0x7fffffff 且无守卫，相加溢出 | 0x3f3f3f3f + dis[u]!=INF 守卫（知识点 1⑥） |
| 3 | INF 取值过小（如 1001）小于可能路径总权 | 按"最长路径总权 + 1"或 0x3f3f3f3f 取（知识点 2⑥） |
| 4 | 求解版误跑 n 轮 | 求解 n-1 轮，第 n 轮只属于判定（知识点 2⑥） |
| 5 | 判定版照抄 n-1 轮或加提前退出 | 判定版跑满 n 轮、不设 break（知识点 3④） |
| 6 | 无守卫导致不可达点被负边伪松弛 | 加守卫；实测无守卫会误报负环（知识点 3⑥） |
| 7 | 边集数组下标 1 存 0 扫 | 存扫下标一致（知识点 2④ 坑 3） |
| 8 | SPFA 重复入队 / pop 不清 inq | 入队前判 inq；pop 后立即清零（知识点 4④） |
| 9 | 判负环用"队列不空" | 入队次数达 n 判负环（知识点 4⑥） |
| 10 | SPFA 当成稳定 O(kE) | 最坏 O(VE)，可能被卡（知识点 4⑥） |

## 四、总结与自测

### 核心内容（一页纸速览）

- **边松弛**：$dis[v] = \min(dis[v], dis[u] + w[u][v])$——一切最短路算法的原子操作（A 源 slide 3）；INF 要防溢出、要设守卫。
- **Bellman-Ford**：每轮全边松弛，最多 $|V|-1$ 轮（每轮最短路信息多传播 1 条边），$O(|V||E|)$；一轮无松弛可提前退出；能处理负边权。
- **负环检测**：负权回路使最短路为无穷小、不存在；第 n 轮仍能松弛 $\Leftrightarrow$ s 可达负环；判定版跑满 n 轮、无提前退出。
- **实测坑**：素材 `inf 1001` 过小——不可达点被负边伪松弛出错误距离（996）、不可达负环被误报（附录 B-5 实锤）；守卫是必备写法。
- **SPFA（补充）**：只松弛"dis 刚变小的点"的出边，队列驱动；期望快、最坏 $O(|V||E|)$；判负环用入队计数。
