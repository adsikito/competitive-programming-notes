> **emoji 特许**：复习回顾版按用户 2026-09-24 许可，默认「限量档」（仅 ❌✅⭐⚠️，全篇 ≤ 15 个）；可通过变量切换为「禁用档」。
> **复制范围**：第二节代码块内的全部内容即提示词正文；其余部分是写给使用者的，请勿复制进对话框。

## 三、使用说明

**两种用法**：
1. **独立用**：直接喂源文件提取文本（如某章 PDF 提取结果），一步出复习版。
2. **串联用**：先用《竞赛资料整合讲解_提示词》（v3.0）出讲解笔记，再把笔记喂给本提示词出复习版——两遍口径天然一致（同一套标注体系）。

**与主提示词的分工对照**：

| 项 | 整合讲解提示词（v3.0） | 复习回顾版提示词（v2.0） |
|----|----------------------|------------------------|
| 目标 | 从零学会（讲透） | 学完速记（想起） |
| 主体 | 六步叙事（问题→直觉→推导→实现→应用→坑点） | 框架卡片（识别信号→模板→复杂度→首坑→口诀） |
| 篇幅 | 单知识点 15-90 行 | P0 卡 ≤10 行 / P1 卡 ≤5 行 / P2 一行 |
| 代码 | 核心代码 ≤60 行 + 逐行讲 | 模板骨架 ≤12 行 |
| 图 | mermaid ≤3 + 文本图 | 文本树为主，mermaid ≤1 |
| emoji | 禁用 | 限量（❌✅⭐⚠️，≤ 15）或禁用，变量控制 |

**与 v1.1 旧产物的关系**：`笔记\STL容器与算法手册_复习回顾.md` 为 v1.1 产物（速查树体），已补标 P0/P1/P2 且 lint 通过；用 v2.0 重新生成时可对照，旧版是否保留由用户裁决。

**改进方向**（后续可做）：
1. 跑过 3 至 5 篇后，把「识别信号」的写法质量做一次横向对比，沉淀题型语词典进极限版。
2. 需要批量出复习版时，加「素材清单对账模块」：输入整个目录的文件清单，按主题自动分批。
