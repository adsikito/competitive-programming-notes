# Competitive Programming Notes · 算法竞赛体系化学习笔记

一套从零开始、面向算法竞赛（CCF-CSP / 蓝桥杯 / 百度之星，兼容 ACM-ICPC）的**体系化学习笔记**，共 **59 篇**，覆盖 **11 个批次**：算法入门 → 数据结构 → 搜索图论 → 图论进阶 → 字符串与动态规划 → 高级数据结构 → 学术专题 → C++ 语言线。

> 所有笔记由统一提示词（v3.1 六步叙事）驱动生成，经过**源码编译实测 + 断言程序验证 + lint 门禁**三重质检。最终门禁：**59 文件 / 1316 PASS / 0 FAIL / 0 WARN**。

## 每篇笔记的统一结构（v3.1 六步叙事）

- **零、知识地图**：text 文本树，全篇导航
- **一、为什么需要它**：碰壁题开场（先痛后学）
- **二、知识点逐讲**：每个知识点六步——①解决什么问题 → ②直觉理解（模型级类比 + 小数据推演）→ ③原理与推导（不跳步）→ ④代码演示（核心代码 + 执行追踪表 + 错误写法对照）→ ⑤典型应用（真题优先）→ ⑥坑点与边界（含六类边界数据集）
- **三、全篇坑点总表 / 四、总结与自测 / 五、语法糖对照表**
- **附录 A/B/C**：源文件对账、缺陷实测登记、编译验证记录

## 质量保证

1. **编译实测**：素材源码逐一 `g++ -std=c++17 -O2` 语法检查，失败项实测复现后给出修正版
2. **断言验证**：每个主题配断言程序（官方样例 + 随机对拍），如排序篇 8 算法两两对拍 60 断言、并查集 A/B 双版本对拍、Dijkstra 200 张随机图四方对拍
3. **缺陷登记**：素材代码的真实缺陷（如局部大数组栈溢出、inf 取值过小导致负环误报、malloc 传参错误堆写穿）一律实测复现后才登记，并给出修正版
4. **lint 门禁**：`python tools/lint_notes.py`——36 项检查（frontmatter/六步齐全/callout 规范/表格列数/禁用措辞/N 对 N 对账等），exit 0 方可交付

## 用法

- 按批次顺序阅读，或从 `笔记/_索引.md` 按主题检索
- 复习时先做各篇「自测清单」，再展开折叠的「边界数据集」对照——检索产生记忆
- 质量复检：`python tools/lint_notes.py`
